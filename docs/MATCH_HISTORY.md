# 本地历史战绩

开局面板、牌桌右上角和结算页均可打开「历史战绩」。左侧列出最近 50 场正式对局，右侧显示所选对局的胜负、武将、阵营、行动回合和全员用牌、响应、伤害、承伤、回复、救援、击败统计。统计口径沿用结算页，新手演练不计入。

查看战绩会暂停 AI 推进并隔离底层牌桌、开局面板的输入。`Esc` 或返回按钮关闭后，保留原来的选牌、目标和自动推进设置。浏览旧记录不会载入或改动当前牌局。

## 保存与恢复

- 每场已完成对局保存为 `%LOCALAPPDATA%\CardGame\History\<标识>.json`；换包和重新开局后仍可查看。
- 标识来自最终命令入日志之后的完整 Checkpoint SHA-256。同一终局重复加载只保留原记录；不同结局分别保存。去重依据是已完成命令历史，不是仅按种子或武将判断。
- 战绩文件只保存公开结算数据及其标识，不保存 Checkpoint、种子、手牌或私有询问。战绩格式为 1，既有存档格式和规则版本不变。
- 界面按记录时间显示最近 50 局，较早文件仍保留。单个文件损坏时保留原文件、显示提示并继续读取其他记录。
- 写入失败不打断牌局，进程内保留待写记录，可点击「刷新战绩」重试；退出时也尝试写入。若退出时仍无法写入，可重载该终局存档再次记录。
- 测试及游戏包自检默认使用内存战绩库，只有正常启动窗口注入本机文件库，因此验证不会写入玩家的历史目录。

## 验证

本轮验证为 Core 122/122、WPF 33/33，Release 构建 0 警告、0 错误。

- 两场由真实 UI 命令推进到结束的对局：文件写入、重启读取、最终命令指纹、重复读档去重、全员统计一致。
- 损坏文件隔离、写入失败后跨新局重试，以及 55 个公开统计文件的最近 50 局排序和原文件保留。
- 开局与牌桌上的模态隔离、快捷键边界、真实 DispatcherTimer 暂停/恢复、关闭后继续提交原来的选牌。
- 完整五局回归继续校验身份/队伍结果及模式进入历史。

证据位于 `artifacts/history-review/`，包括 1120×740 和 1440×860 的真实 WPF 控件离屏渲染。这不替代桌面鼠标、键盘、多 DPI 或声音实听验收。
