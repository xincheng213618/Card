# 本机表现设置

开局面板可以设置音效、音量、背景音乐、武将配音和动画；牌桌控件与 `Ctrl+M` 也可调整声音。设置和图鉴中选择的武将皮肤自动保存在 `%LOCALAPPDATA%\CardGame\preferences.json`，无需先开始或保存一局游戏。

- 重启、重新开局、进入或退出教学后，保留当前音效、音量和动画设置。
- 读取存档保持已有本机设置，包括当前静音状态。
- 没有偏好文件时使用程序默认设置：音效开启、音量 40%、背景音乐和武将配音开启；动画默认开启。
- 自动推进与对局速度仍属于牌局设置，继续按存档恢复。本机偏好不修改规则或已提交的游戏操作。
- 滑块连续变化合并为最多每 500 毫秒一次写入，退出时保存尚未写入的最新设置。新手教学中的设置也可保存，但教学局面不会写入正式存档。

## 文件与恢复

`PlayerPreferences` 包含格式、音效开关、有限的 0–1 音量、动画开关，以及可选的皮肤映射和默认开启的音乐、配音开关。偏好独立于 `GameSaveFile` 和 Checkpoint，读档不导入或覆盖本机偏好。

写入先完成并刷新同目录临时文件，再原子替换正式文件；前一份保留为 `preferences.json.bak`。读取失败时暂以静音、无动画启动，保留原文件并在开局面板提示。玩家可重试读取，或调整设置后重新保存；原文件会备份。写入失败时当前设置仍然生效，可在开局面板重试，退出时也会再次尝试，不阻止牌局操作或退出。

正常窗口使用本机文件库。测试和包内自检默认使用内存库，不读取或写入玩家设置。
