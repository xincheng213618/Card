# 本机声音与动画设置

开局面板可以直接设置音效、音量和动画；牌桌右侧原有控件与 `Ctrl+M` 继续可用。设置自动保存在 `%LOCALAPPDATA%\CardGame\preferences.json`，无需先开始或保存一局游戏。

- 重启、重新开局、进入或退出教学后，保留当前音效、音量和动画设置。
- 读取存档不会覆盖已有本机设置，因此不会因为打开旧档而突然解除静音。
- 若本机尚无设置，也没有进行过设置调整，第一次成功读取旧档会导入其中的音效、音量和动画。旧档缺少字段时使用原默认值：音效开启、音量 40%、动画遵循系统设置。
- 自动推进与对局速度仍属于牌局设置，继续按存档恢复。本机偏好不修改规则或已提交的游戏操作。
- 滑块连续变化合并为最多每 500 毫秒一次写入，退出时保存尚未写入的最新设置。新手教学中的设置也可保存，但教学局面不会写入正式存档。

## 文件与恢复

文件格式为 1，仅包含音效开关、有限的 0–1 音量和动画开关。独立偏好不改变既有 `GameSaveFile` 或 Checkpoint 格式；存档中原有字段继续保留，供没有本机偏好的旧档迁移使用。

写入先完成并刷新同目录临时文件，再原子替换正式文件；前一份保留为 `preferences.json.bak`。读取失败时暂以静音、无动画启动，保留原文件并在开局面板提示。玩家可重试读取，或调整设置后重新保存；原文件会备份。写入失败时当前设置仍然生效，可在开局面板重试，退出时也会再次尝试，不阻止牌局操作或退出。

正常窗口使用本机文件库。测试和包内自检默认使用内存库，不读取或写入玩家设置。

## 验证范围

Release 构建零警告、零错误，Core 122/122、WPF 35/35 通过；五场完整界面对局实际用牌 116 次、重铸 6 次、响应 74 次。

真实 WPF 控件和临时 JSON 文件检查覆盖：尚未开局时自动保存、重启读取、不覆盖游戏存档、保持静音与关闭动画、首次旧档迁移、教学往返、退出保存、连续滑块合并、写入失败重试、暂时读取失败重试、损坏文件备份、无效音量和未来版本拒绝。

同时补齐战绩文件中 `InvalidDataException` 的可恢复异常处理，格式合法但不受支持的记录不会阻止其他战绩读取。已有战斗音频测试继续验证读取不重播旧音效、前后台停声和音量传递。

构建日志、测试结果和 1120×740 离屏截图位于 `artifacts/preferences-review/`。离屏控件验证不等于桌面鼠标、键盘、多 DPI 或声音实听验收。
