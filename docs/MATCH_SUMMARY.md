# 终局战绩回顾

结算页在胜负之外展示全员战绩，自己的行使用金色边框突出。身份局显示最终公开身份，2v2 显示青队／赤队，国战显示双将与势力；每行包含存活状态、造成伤害、受到伤害、回复、救援和击败角色数。上方显示行动回合数及自己的用牌、响应和救援次数，下方保留再战与详细战报入口。

## 统计口径

- 用牌按已声明的使用次数统计，群体效果的逐目标通知不重复计数；普通出牌和救援用牌都可能计入。
- 响应按实际打出的响应事件计数，决斗和群体响应的额外通知不重复计数。
- 伤害与承伤按实际伤害点数统计，含对自己或队友的伤害；苦肉等技能失去体力的代价不计作伤害。
- 回复按该角色让自己或他人实际回复的体力点数统计。
- 救援按濒死窗口中用出的桃、酒或转化牌张数统计，包含自救，不把放弃救援计入。
- 击败按规则归因于该角色的阵亡人数统计，包含友方，不含自己阵亡或无归因阵亡；它不是策略评分。

列标题有口径提示。界面没有加入 MVP 或综合评分，避免把伤害数直接解释为团队贡献。

## 状态与存档

`Presentation/MatchSummary.cs` 只在对局完成后从最终快照和已提交事件聚合数值；摘要不保留实体牌 ID、手牌或私有候选。读取存档通过命令重放重建报告。取消再战保留原报告，真正开始新局时清除；进行中的牌局不显示终局统计。
