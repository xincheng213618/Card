核对日期：2026-10-18。山河图是三国杀 OL 的单人 PVE 剧本系列，玩法重点是一次征程内的路线选择、事件与构筑成长，以及征程外的解锁。本项目首批采用“诸侯伐董·本地起步版”口径；原版资料、实现约定和待核实内容分开记录，不能把同名旧活动或不同返场的数值合并成一个“官方规则”。

## 可以复用的征程结构

2024 年的[风起汉中说明](https://my.4399.com/yxsgs/ziliao/62026/)和[军师联盟说明](https://my.4399.com/yxsgs/xinwen/63837/)共同支持以下结构：

- 一次征程先选择武将，经过三章，末章首领胜利结束；任一场战斗失败结束本次征程。
- 战斗之外可以退出并继续征程。单次战斗的游戏状态与整次征程的成长状态需要分开保存。
- 地图事件包括战役、奇遇、集市及营地。奖励涉及额外技能、战法、初始手牌与初始装备。
- 除武将固有技能外，额外技能槽在这两期资料中从两个扩展至四个；这是对应期资料，不代表所有诸侯伐董版本都相同。
- 初始牌与初始装备是每场战斗重新配给的资源。原资料还说明这种初始牌使用后不进入弃牌堆，不能用普通牌堆随机抽牌代替。
- 局外消耗残卷或图册逐步解锁技能、战法、牌及装备，改变下一次征程可能遇到的内容；已解锁的部分战法可以作为初始配置。

上述是架构依据。具体奖励量、恢复量、商店价格、战法槽品质限制、战斗后的体力继承及队友恢复仍应随剧本版本定义，不能从一个时期的说明推为全系列定值。

## 诸侯伐董：2024 年已确认规则

主要依据是紫云西来 2024-12-19 发布的[官方社区原帖](https://club.sanguosha.com/thread-1521041-1-1.html)，本轮已成功读取；[官方运营号转发](https://www.taptap.cn/moment/620426358543093054)亦保留作者、日期、正文及客户端图片。逐项版本与实现对应见 [战法和技能证据表](SHANHE_TACTIC_SOURCES.md)。

可确认三章结构仍在，但章间不再只是固定直线。首章在虎牢关、广成关间随机，通关后可选后续路径。不同路径可能通向洛阳，也可能通向酸枣或河内，后两者仍可正常结算通关奖励，但不一定满足指定洛阳的任务。第二章有对整个战场生效的地形效果，玩家、队友和敌军均受影响。

该来源的战法效果可归纳为：

| 战法 | 对应期可确认效果 | 实现注意点 |
| --- | --- | --- |
| 弱袭 | 手牌数低于当前体力时，伤害增加一点。 | 检查当前手牌与当前体力；铁索传导也需依正确伤害流程处理。 |
| 近身术 | 自己到其他角色的距离固定为一。 | 与依赖远距离的加伤构筑互相影响。 |
| 反刺 | 每个回合第一次受伤后，向全部敌人各造成一点伤害。 | “每回合”不是“每轮”；必须有真实来源、伤害与濒死结算。 |
| 增寿／增寿 II | 战斗初始化增加一点／两点空体力上限。 | 不同时补充当前体力，下一战重新初始化。 |
| 兵反／乐转 | 对应延时锦囊的判定效果取反。 | 重复获得不能反复取反。 |
| 赌术 I | 拼点的牌面点数增加三，封顶为 K。 | 不改变实体卡牌本身的点数。 |

这份攻略还记载了谋命、削命和血刃。本轮把三者接入第二章奖池和集市：前两者各自每轮首次命中时，将牌伤改为扣减体力上限；血刃在每次实际回复后随机伤害一名敌人。具体边界由后文的共享结算能力和对应联动检查约束。

该 2024 来源明确提及虎牢关的张辽及其专版机制；本次没有拿到 2024 原版所有普通、精英与首领阵容的完整表。2026 来源另有吕布、董卓等敌军记录，但不能由此推断 2024 的完整配置。不能把通用同名武将的标准技能当作其关卡专版，也不能拿 2017 年的张济、樊稠等旧活动表填空。

## 本地起步版的落实范围

当前入口是大厅的“山河图 · 剧情征程”，牌桌工具栏也可返回征程。`StandardShanheCampaignCatalog` 提供三档本地难度、八名出征武将、二十个地图节点以及洛阳、酸枣、河内三条结局。故事和路线为本地创作；敌军与同行复用已实现的经典／OL常规武将版本，尚不代表原版关卡专用技能。

当前提供同一诸侯伐董主题的两个独立入口：2024 主题本地版，以及在虎牢路线加入神鬼无前吕布的 2026 专属形态版。后者采用已核实的神躯和动态无双，从该形态直接开战；未知的原版变身阈值没有写成规则。两个入口的地图、剧情和难度成长仍为本地编排，其他剧本留在资料表，待内容、存档与验证完成后再开放。

### 战法与原生技能组合

2026版额外提供精于谋略 II：手牌少于6时，自己使用杀造成的伤害+1。完整客户端面板明确允许无限获得、每份独立触发，故重复奖励、不同商品与后续战斗保留全部份数。2024池不加入该战法，未核其他战法的重复性也不从这一面板推广。商店100钱为本地定价，品级未知。伤害时检查当前手牌、铁索仅继承首段金额、附加伤不计入绝情／削命的替换金额，均为明确记录的本地结算解释；[原图和边界](SHANHE_TACTIC_SOURCES.md)未声称这些组合已有原版实测。

同版增加队·牌与队·甲，完整面板分别确认可重复获得并独立触发。队·牌每份使其他存活公开队友的真实摸牌阶段摸牌数增加2，不增加构造期起手或技能单独摸牌；持有者死亡或失技后停止贡献，已经发出的摸牌请求保持原数额。队·甲每份在本场开战给其他存活公开队友3甲，已获得的护甲不随来源失技撤销。数值护甲逐点承担完整伤害中的支付量，伤害事件、反刺、经典狂骨与铁索继续按各自伤害规则处理；体力变化技能只观察实际减少的体力。新战重置护甲再执行开局赋予，跨战存量属于本地编排。两项只进入2026奖励池；基础本地定义另有明确标注的100钱商品，启用山河册的商店只投放已有公开价格映射的商品，暂不售卖这两项。队·体的上限和回复事件顺序未核，尚未作为可用战法加入。

战法和额外武将技能分别保存：战法不占额外技能槽，每个战法保留自己的奖励来源与程序 ID；额外武将技能使用独立的一至三个槽位，满槽时明确选择替换项。本将固有技能及默认唯一战法不会再次投放；只有内容明确声明可重复的战法可以在征程中再次获得。初始携带仍至多六项且同一战法不重复；征程内获取不以六槽或原先的32份校验作为叠加上限，仍遵守命令日志和同件商品仅购买一次的边界。每份战法在下一场战斗中绑定为独立的永久技能实例，使用现有触发、伤害、转换、状态和技能失效机制。

战法程序包括弱袭、近身术、兵反、乐转、赌术 I、反刺、噬血 I、增寿 I／II、谋命、削命、血刃、内讧和妙技 I／II；增寿 II 与三个高阶战法进入第二章奖池。内讧和妙技 I／II 进入随机奖励；内讧与妙技 I 也可在首章集市取得，妙技 II 列入第二章集市，价格和刷新分布仍为本地设置。额外技能奖池在原有八项基础上加入十七项核实变体，包含界强袭、当前界势斩、慎行、界连营、经典狂骨、清弦、恢拓、散谣，以及绝情、空城、业炎、急救、八阵、极奢、胆守、备战和界武圣，版本由 `StandardShanheOriginalSkills` 明确绑定。界强袭支付真实伤害而非失去体力，因此可以先触发反刺；慎行弃置最后一批手牌可以先完成界连营，再回到本来的摸牌。经典武圣仍作为明确标注的本地旧选项，原作方块杀无距离限制的变体单独绑定界武圣。

本批补充了几项共享能力，后续普通技能与其他剧本也可使用：

| 能力 | 结算边界 |
| --- | --- |
| 来源手牌少于体力时加伤 | 每个真实伤害实例按当前手牌和体力判断，覆盖原生牌、技能与传导；失去体力沿用其原本独立流程。 |
| 第三方公开敌军加伤 | 内讧观察者必须存活且技能启用，双方均是该持有者的公开敌人才贡献附加伤；不按隐藏身份或势力猜敌我，无来源伤害不匹配。 |
| 实际回合内锦囊使用序号 | 妙技读取本次使用声明的历史前缀，非伤害锦囊和使用无懈也占位；转换、虚拟、同牌多目标及重复效果沿用原声明，后续子用牌不改写原序号。 |
| 最终出向距离固定一 | 在座次、装备及其他方向修正后生效；本地按出向距离解释，不能推断为别人到自己的距离也变一。 |
| 延时锦囊判定效果反转 | 在最终改判、花色和点数确定后，只反转对应锦囊的成功结果一次；实体判定牌不变。 |
| 有效拼点点数加成 | 单人对手、多人拼点及 AI 共用有效点数，独立实例可叠加，封顶 K；不改实体牌面。 |

### 存档与实现位置

`Campaigns/ShanheCampaignSession` 以征程命令前缀重建路线、奖励、金币与构筑。每场战斗仍是现有 `GameCheckpoint`；战斗结算须完整重放并核对本次节点、种子、开战配置、包列表、内容指纹及最终胜负，再发放一次奖励。商店每件商品只购买一次；首领结算扩充技能槽，末章奖励选完才显示该路线结局。

桌面将两个命令日志写入独立的 `shanhe-campaign.json`，临时文件写完并 flush 后原子替换，保留 previous；普通对局存档继续独立管理。已保存征程的定义 ID 决定还原哪个版本，界面默认选项不覆盖它；版本与难度不匹配则保留源文件和当前牌局。新增行为通过既有 Core/WPF 的 `Shanhe` 名称过滤检查；例行验证仍使用 `tools/Test-Changed.ps1` 的 routine 范围。

当前商店的 `Snapshot.ShopItems` 保留全部商品，包括已购买、已拥有、资源不足、无技能槽和已达构筑上限的条目；每项携带纯数值价格、完整奖励、修订号及当前合法替换技能。可购买性和真正购买共用同一无副作用的命令准备路径，不能只因余额足够就跳过技能槽或构筑上限。读取快照不扣资源、不增修订；购买仍提交原有节点命令，重复或过期命令被拒绝，冷恢复重建已购状态。山河册分为局外研习树与“本次行装”；后者展示本次已获得的战法、额外技能及初始配给，二者分别保存。
