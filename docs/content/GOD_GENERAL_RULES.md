# 神将规则去重

`GodGeneralRulesCatalog` 保存人工核对的等价映射及实际规则区别。选将池（含单骑无双）、同人物版本组、图鉴共用这份映射。历史武将与技能仍注册，避免删除旧内容身份；不重写存档，不提高规则格式或内容包版本。当前模式池变化正常进入内容指纹，旧存档是否可重放仍遵守现有校验与恢复流程。

不把相同技能名、近似正文或不同平台编号作为等价证明。对照完整技能、初始体力／体力上限、觉醒授技、支付、目标、时序、持续范围与响应窗口。显式空条件、内部绑定变量名和旧最低规则元数据不构成玩法差异。
