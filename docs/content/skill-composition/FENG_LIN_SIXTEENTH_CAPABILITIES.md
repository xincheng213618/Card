# 界孙权、界庞统、界徐庶共享能力

本批采用当前普通 OL 界孙权 442、界庞统 455、界徐庶 304。完整原文、HTTP 时间与三张官方原立绘 SHA 见[来源](../sources/fenglin-sixteenth-2026-10-03.json)，荐言补充依据见[徐庶来源](../sources/xu-shu-derived-2026-10-03.json)。内容注册、图鉴和同步映射一起接入，沿用现有 rules epoch、JSON schema 与内容包版本。

制衡复用已有 HE 选牌、冻结选牌凭据、弃牌、等量摸牌和全手牌额外摸牌；每个实际出牌阶段限一次。涅槃复用限定濒死触发、HEJ 弃牌、解除横置/翻面、摸牌、回复至指定值、选项与获得既有经典技能。潜心复用本人实际伤害后的受伤条件、游戏限一次、减体力上限与获得技能。

2700 `RedirectOwnTurnFactionRecovery` 提供可选回复替代。原回复在确切生产帧上排队，`RecoveryReplacementFrame` 冻结本次回合、回复前体力、候选技能实例与原回复完成凭据；回复者选择保留或替代。回复、HP 观察 children、奖励摸牌及移动 children 按顺序返回。实体桃、程序回复/回复至、白银狮子等生产路径复用此边界；已付牌的续点保存在 `CardUseFrame`，恢复后不重付成本或提前继续伤害。

铁索连环目标组合复用 `CardTargetCount` 查询，普通上限二、连环加一。实际实体使用、转换、发行校验与 WPF 引导读取相同规则。转换重铸支持声明允许的装备区梅花牌，移动使用实际持有位置。

装备连环重铸使用只含标量的 `EquipmentRecastFrame`，将付款引起的回复与移动 children 排在重铸摸牌之前；既有手牌重铸沿原路径。怀柔等程序装备重铸仅在存在待处理回复时把付款凭据留在原 `ProgramSkillFrame`，回复返回后执行一次摸牌与重铸事件。子链令角色死亡或确定胜负后，已付重铸完成且不再摸牌。

势力请求支付装备时，原生产帧持有只含标量的 `PaidFactionRequestCostRecovery`，冻结确切请求、策略实例和已付牌。回复、HP 和移牌子链返回后才发布第一位提供者响应；成本不会重复。胜负确定、请求者死亡或主动杀的固定目标死亡时，完成已付请求；借刀目标死亡沿成熟失败返回处理武器。定向检查使用真实秦王与伪帝投影，覆盖保留、替代、无候选原路径、胜负和目标死亡。

2800 `UseOwnerSlashAgainstTurnOwner` 在他人结束阶段提供本人真实杀使用，固定当时回合角色，保留实体成本、合法转化、势力响应、伤害与使用完成；复用提供杀的 typed parent 返回。诛害此次使用不消耗出牌阶段杀次数，仍检查牌禁用和目标禁用；距离豁免采用官方普通 OL 补充说明。发行前确切技能实例失效则取消且不付牌，发行后由已承诺的真实用牌子链完成，返回原帧后不重新发行。`TurnOwnerDamageDealtThisTurn` 只在使用该事实的内容中采集本实际回合正实际伤害，不把无来源伤害或体力流失计入。

2801 `DeclareDeckCriterionAndGiveMatchingCard` 先声明红/黑颜色或基本/锦囊/装备的打印类别（锦囊包含延时锦囊），再按当前牌堆顶逐张公开并检索首张符合牌，由发动者选择当前存活男性角色获得，可以选择自己。检索和给牌凭据由 owning program frame 持有，每次移动及给牌后的 children 可暂停和冷恢复。工程默认只在初始空堆时按既有方式补充，随后冻结初始堆牌数为检索预算；中途不再补充，无匹配则有限结束。失败牌进入弃牌堆但不是弃置动作；命中牌公开暂存 Processing，给牌前来源失效或没有男性接收者时沿绑定牌清理进入弃牌堆。

新规则事实通过 `AdvanceEventRulesAndQueueFact`，新状态通过 `AdvanceRulesAndPublishState`；集合与嵌套凭据在暴露前冻结，玩家视角使用 `CreateSnapshot`。正式命令/冷恢复与 HOST 来源失效审计分别标注，实际验证见[批次记录](../../benchmarks/2026-10-03-fenglin-sixteenth.md)。
