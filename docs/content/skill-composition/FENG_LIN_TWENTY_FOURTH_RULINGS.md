# 第二十四批工程口径

完整当前官方正文与 API 捕获见[来源预检](../sources/fenglin-twenty-fourth-preflight-2026-10-04.json)。以下属于明确工程解释，没有经过独立当前普通 OL 官方 FAQ 核实；静态整合不等于行为验收。

- 当先的“此阶段”限定强制插入的准确额外 Play；取或不取杀都承担未造成实际伤害的自伤。已发行债务不因失去来源免除，死亡/胜负沿用原停止规则。
- 牌堆取当前顶序首个实际杀，不公开隐藏身份列表或额外消耗 RNG；公开弃牌选择实际实体。单实体距离权限限定该阶段和连续持有轨迹，混材料/零实体不继承。接受用牌后不因来源失效重收成本，离区及阶段结束失效。
- 伏枥激活时冻结活人有效势力 X，包含尚未死亡的濒死本人。伤害阈值是整局本人实际 DamageApplied 点数，含当先自伤、排除失血及无来源伤害。子提示不重算；恢复受 MaxHP 限制，补牌目标不受 MaxHP 限制，限次及已付操作不重复。
- 巧说成功后可再次真实拼点，直到本实际回合首次未赢，平点属于未赢。多次成功只刷新最新一个额度。失败只关闭该巧说实例，纵适独立有效，锦囊禁令按实际回合结束清除。
- 下一次真实使用消费巧说额度，含真实无懈的 Response 语法，普通闪/打出杀/决斗杀响应不消费。合法旧零实体 Use 消费但不制造 Action、实体或花色。未调整也消费；不能删至零目标，不给装备/延时放置/固定救援强造对象。借刀增减完整合法对象对。
- 精确新额度允许正式材料杀增加合法对象、同花色万箭少一个对象、桃增加受伤对象；各对象满足完整材料合法性，多对象只付一次杀额度。成本归真实 Use，逐对象保留成本及 typed return。丈八不虚构程序父帧，奇策用原程序冻结的全手牌成本。
- 巧说付款前来源失效不再提供调整；已接受使用按冻结成本和拥有帧完成。已发行失败禁令保留至实际回合结束，同名来源恢复不撤销。
- 陷阵可在额外出牌阶段依阶段限次再次拼点；实际回合保留多个获胜原对象，每次 Use 至多追加一个。仅所有初始杀对象都有不限次数权利时免额度，普通对象杀再追加仍扣一次。无中生有保留隐式自身，借刀追加完整合法对象对。
- 陷阵未发行查询随当前来源失效，已接受 Use 的点数、对象和防具权限不因付款后抑制重算。死对象不可追加，owner 死亡/胜负停止尚未选择的追加，回合结束移除权利。Action=null 的旧固定目标生产者不伪造追加窗口。
- 禁酒只冻结本人单实体手牌/木牛酒的有效 K 杀身份，实体原点数不变；拼点在确切 Reveal producer、移动前冻结。其他角色酒禁令按真实 actor 判定，醇醪 responder 与 dying victim actor 分开；精确已接受救援权限不泛化到其他救援。

本批没有建立界刘禅451思蜀895或界孙策452派生正文的新来源证明。当前主区已有独立整合的 BoundarySunCeContent，原样保留，不因本批预检缺口宣称当前孙策未注册。
