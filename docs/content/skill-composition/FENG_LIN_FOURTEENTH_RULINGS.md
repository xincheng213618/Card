# 界公孙瓒、界华雄规则口径

依据当前普通 OL 官网[界公孙瓒320](https://www.sanguosha.com/hero/320)、[界华雄446](https://www.sanguosha.com/hero/446)完整正文；原文、API、HTTP时间及原画SHA见[来源档案](../sources/fenglin-fourteenth-2026-10-02.json)。API没有结构化性别，Male沿仓库同角色惯例；initial_hp零值不作实际初始体力。当前义从始终向外距离−1，HP不大于2时别人向其距离+1；旧classic版本保留。

趫猛在造成实际伤害后，对该次最终受伤角色选择区域一张牌弃置，印刷坐骑牌才获得。资格要求本人的真实Use杀来源，保留相同来源的链伤与转移；不把打出或响应杀、无牌伤害作为使用杀。此资格细节为工程解释，当前正文没有完整FAQ。手牌选择沿不透出实体内容的opaque槽，装备及判定牌沿公开槽。

弃置实体与真实movement记录完成后、规则事实及子窗之前冻结精确付款收据；获得只取同一实体且仍在已声明弃牌位置。其他子窗已取走则完成，不抢回。攻防坐骑及手中的印刷坐骑均可获得。未付款来源失效取消；已付款活着的本人在有限尾段来源失效仍获得，死亡终止未发收益，是明确工程默认。

耀武采用真实DamageAppliedBeforeDying窗口，为“受到伤害时”的工程时点解释，未改旧全局红牌判断。每次正实际伤害只执行一次，不随伤害点数重复。拥有真实CardAction时读取早已冻结的有效颜色；没有此action的实体牌取印刷颜色，明确无实体虚拟牌取无色非红。旧直接虚拟决斗仍属于牌伤害，有真实牌的无来源延时伤害也保留牌存在性；真正无牌Program伤害没有耀武收益。

红色牌的真实存活来源摸1，无来源或来源已死不摸；非红由本人摸1，体力0但尚未死亡仍可摸，之后继续真实濒死。来源、牌存在性及颜色在本节点Draw/子窗前固定，不因后续技能变化、回血或牌移动重算；不拿内部占位seat冒充来源。

势斩每个真实出牌阶段限两次，令另一名存活角色成为真正零实体无色决斗的初始使用者、本人为初始唯一目标。候选与提交同源检查真实用牌及目标合法性。声明、指定目标、无懈、集智、杀响应、伤害、濒死与完成沿成熟用牌链；不能用旧直接虚拟决斗替代。真正用牌发出后不因父技能失效撤销，不再次消费次数；合法角色及目标修正继续结算。真实额外出牌阶段重置两次额度。

[能力契约](FENG_LIN_FOURTEENTH_CAPABILITIES.md)规定拥有帧、暂停恢复、输入、旧路径和公开AI边界。正式实现已按冻结整合输入验证；结果与原失败见[本批记录](../../benchmarks/2026-10-02-fenglin-fourteenth.md)。

趫猛当前正文没有“其他角色”，因此实际来源杀的自源火链回传本人也允许选择本人区域牌；真实链伤与零实体Use已命令验证，转移伤害资格仅工程默认/静态路径核对。Source-less闪电的现生产者含延时判定flag及内部占位source；新耀武明确把这类来源归一null，仅新2400的收据与上下文改变，旧facts/producer未改。
