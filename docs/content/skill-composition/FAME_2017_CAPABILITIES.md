## 必须保留的版本边界

薛综升级复难后不必先交出原用牌，仍可获得响应牌；嵇康四种残谱的完整触发与效果由[2.97公告](https://www.sanguosha.com/news/20180314_3303_3110)补全。

徐氏本人发动问卦时跳过给自己牌的步骤，仍须把自己的一张实体牌置于牌堆顶或底，再从另一端摸一张。[2.92公告](https://www.sanguosha.com/news/20170918_7228_3217)明确本人仅摸一张；不能让自己免费摸牌或摸两张。曹节惠民按符合手牌/体力条件的人依座次选牌，[官方调整稿](https://www.sanguosha.com/news/20170704_8550_3716)可补英雄页简写。辛宪英、吴苋优先采用当前英雄页正文，旧调整稿不能覆盖冲突内容。

- 吴苋：福绵仅对合格红色基本牌或普通锦囊提供当回合一次、最多1/2名的可选额外目标；无关牌和未增加目标的使用不消费授权。新增目标免距离，仍遵守其他资格。周期首次或连续同项为1，换项本次为2并复原。怠宴按完整本人回合判断连续目标，从真实牌堆获得红桃基本牌。
- 曹节：守玺整局牌名账本和真实同名弃置付款，拒绝只使该杀对拥有者无效。惠民在摸牌前冻结手牌少于体力的角色集合；真实展示牌仍在手牌区，公共剩余牌面投影和顺时针参与者游标驱动各人选择。获牌触发后续接，非展示手牌保持私有。
- 蔡邕：独立公开书堆拥有实体owner和技能归属，四张封顶；从真实牌堆入堆，交换HE与书的等量实体集合，四花色时强制分完全部书。死亡与失去归属技能清理，压制停触发与上限贡献。新增公共字段与能力保持旧内容默认行为。

辛宪英新增1160比较实际展示手牌、1161持久手牌上限、1162当回合自身目标禁令。`SkillRuntimeStateSnapshot.PublicRuleStates`仅为采用新能力的技能提供实际额度、使用次数、有符号上限贡献及禁令；旧技能默认省略。展示手牌用匿名位置选择，只有实际展示实体公开。禁令按实际用牌目标判断，借刀受杀者不属于该锦囊目标；自身濒死桃/酒受限，其他角色救援与无自身目标的响应照常。

秦宓新增1180全部杀目标替换、1181逐目标拼点，以及可选牌堆顶来源和有效花色点数政策。先保留双方有手牌的拼点资格；双方选择顶牌时各占用不同真实实体，commit前不暴露牌面，红桃有效点数13不改实体牌面。拼点子帧恢复严格绑定新操作、父卡窗、ActionId和结果名称。

薛综1200保留原用牌、直接响应父卡、回应者及实际实体身份；1201按全场有效方块装备/判定牌计数，以此前发动次数执行真实弃置，全部HE弃尽后修改同一技能来源并仅失去对应诫训。`ProgramResponseExchangeStates`与`TurnProhibitedPhysicalCards`为可空公开快照；实体禁令只限制使用/打出，仍允许合法费用与弃置。旧响应父链默认保持，只有新能力进入领取实体续接。

徐氏1220真实把一张HE放到顶/底，并从另一端摸牌；给牌触发结束后重新核验实体。1221按当前牌堆依次使用真实杀，保留Processing、实际响应、死亡/胜负/技能失效与最后洗牌边界。动态顶端扫描和初始人数上限是实现选择；本人问卦不能免费摸牌。

嵇康1240只从当前合法牌堆装备候选消费RNG并真实使用，空集无移动、无随机消耗、无梅花奖励。1241授予真实随机残谱及受赠者下个实际本人回合开始到期的花色保护；来源死亡不撤回已经赠出的技能/保护。借刀仅检查实际持武器者，全局牌按受保护席位排除。牌堆装备来源、失血后真实获救续接记录为推断。父补才识自身目标禁令回归，确保随机装备不会绕过公共合法性。
