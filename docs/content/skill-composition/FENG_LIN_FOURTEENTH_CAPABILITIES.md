# 界公孙瓒、界华雄共享能力

采用的普通 OL 文本、身份、原始立绘及工程解释见[来源档案](../sources/fenglin-fourteenth-2026-10-02.json)与[规则口径](FENG_LIN_FOURTEENTH_RULINGS.md)。资料、规则及展示由对应人物的 boundary 目录注册。

## 义从与趫猛

义从始终提供向外距离 −1，当前体力不大于二时向内距离 +1，合成仍由公共距离查询处理。

DiscardDamageTargetAndClaimMount 在正实际伤害后的来源窗口，验证本人的真实使用杀来源，选择实际受伤者的一张 HEJ 牌弃置。暗手牌用不透明槽，装备和判定用公开实体。真实转换及零实体杀可以具有使用来源；单纯打出和无牌伤害不满足资格。

弃置发生后、移动观察前，原程序冻结精确实体、原区、弃牌位置、移动序号和印刷坐骑类别。子窗返回后只有同实体仍在该弃牌位置才获得；已被其他效果移走则有限完成。费用前来源失效取消，已付尾段由存活拥有者完成；死亡终止未发收益。所有材料只移动一次。

## 耀武

DrawByDamageCardColor 在 DamageAppliedBeforeDying 的受伤者窗口读取已冻结的牌存在性、颜色及真实来源。实际用牌动作使用冻结有效颜色；无动作的实体伤害使用印刷颜色；明确无实体虚拟牌为无色非红。无牌程序伤害不产生收益。

红色牌使仍存活的真实伤害来源摸一，无来源或已死来源不摸；非红牌使仍存活的受伤者摸一。体力为零而尚未死亡仍可完成该摸牌，然后回到濒死流程。每笔伤害一次，不按点数重复。后续回复、技能或卡牌变化不重新计算事实。

## 势斩

UseSelectedActorDuel 是零材料、一个其他目标的实际出牌阶段能力，每阶段限两次。所选角色成为零实体无色决斗的初始实际使用者，技能拥有者为初始唯一目标；候选与提交检查相同的用牌及目标资格。

决斗沿原生声明、目标、无懈、响应、伤害、濒死、完成及程序父返回执行。实际使用已签发后，父技能失效不重新付款或撤回已接受动作；额外出牌阶段具有新阶段额度。AI 使用公开关系、数量及本人合法信息估计决斗风险。

配置与入口见[当前技能配置](RUNTIME.md)，状态及返回见[结算协议](../../RESOLUTION_PROTOCOLS.md)。
