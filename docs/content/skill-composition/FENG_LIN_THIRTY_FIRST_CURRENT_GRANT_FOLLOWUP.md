# 获授技能的版本与资格

派生技能需要稳定 ID、明确规则版本和可追溯来源；官方页面中的数字 `font` 引用是技能引用，不能按数字拼成武将详情页。

当前[界关兴张苞资料](../../../src/Characters/guan-xing-zhang-bao/boundary/Content/boundary-guan-xing-zhang-bao.character.json)及其技能规则已经注册；获授武圣/咆哮采用配置中明确的定义与范围。体力投射和其他动态授予同样保存真实来源及实例资格，不能按中文同名自动取得另一产品线技能。

当前人物目录提供经典于吉，界于吉的来源文本、同时质疑及缠怨版本证据与经典定义分开保存。[2020 年官方界于吉公告](https://www.sanguosha.com/news/20200101_3308_3113)是对应版本资料；具体采用的实现必须有独立人物与完整派生规则，不能由公告标题或同名推断。

资料核对见[来源规范](../BWIKI_CONTENT_BACKLOG.md)，运行时资格见[状态与时间](RUNTIME_STATE_AND_TURNS.md)。
