# 死亡收益与嵌套子流程

死亡收益的摸三张、回复一点以及其获牌/HP 观察子流程沿原拥有帧收据继续。受益者在子步骤后死亡时保留已完成结果，取消尚未发行的后段；来源已经死亡属于 ownerDied 合同，不是任意死亡角色执行许可。

当前人物、程序绑定和规则来源见[规则合同](FENG_LIN_THIRTIETH_BU_LIAN_SHI_DEATH_RETURN.md)；资料未明确的复杂口径见[工程默认](FENG_LIN_THIRTIETH_BU_LIAN_SHI_DEATH_RETURN_DEFAULTS.md)。

实现入口：[GameEngine.OwnedDeathBenefitObservers.cs](../../../src/CardGame.Core/GameEngine.OwnedDeathBenefitObservers.cs)。
