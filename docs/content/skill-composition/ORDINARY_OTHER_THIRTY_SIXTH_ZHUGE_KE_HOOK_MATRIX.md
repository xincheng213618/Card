# 诸葛恪的牌堆请求与所属流程

牌堆请求保留原请求、实际使用/打出方向、真实材料与费用，按明确政策查询牌堆候选。黩武支付实际目标体力对应的材料，等待原生移动及体力子链，再发出原伤害；死亡、终局和失源按已经发行与尚未发行的步骤分别处理。

当前人物、程序绑定和规则来源见[规则合同](ORDINARY_OTHER_THIRTY_SIXTH_ZHUGE_KE_CONTRACT.md)；资料未明确的复杂口径见[工程默认](ORDINARY_OTHER_THIRTY_SIXTH_ZHUGE_KE_ENGINEERING_DEFAULTS.md)。

通用字段、提交、隐私及命令恢复边界见[技能程序运行时](RUNTIME.md)。
