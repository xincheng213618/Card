# 左慈规则版本与来源范围

当前人物目录中的[经典左慈](../../../src/Characters/zuo-ci/classic/Content/classic-zuo-ci.character.json)与官方界左慈是不同规则版本。经典实现的化身数量、技能池和展示投射以其规则文件为准。

保留的[界左慈官方页](https://www.sanguosha.com/hero/447)给出初始三张化身，以及移去至多两张并等量换新的主文；这份主文不能单独证明完整随机池、技能排除继承、回收、重复和短缺处理。当前目录没有据此声明一份完整界左慈实现。

API 的 `initial_hp: 0` 占位不覆盖人物实际体力，API 未给的性别不作为直接字段证据。资料收录数量与有限索引范围也不是官网完整目录或项目完成度。版本来源的核对标准见[来源规范](../BWIKI_CONTENT_BACKLOG.md)。
