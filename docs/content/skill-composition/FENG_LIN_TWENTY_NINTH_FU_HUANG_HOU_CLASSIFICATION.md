# 界伏皇后求援的锦囊分类依据

界伏皇后的求援局部能力采用决斗、火攻、南蛮入侵、万箭齐发四种普通直接伤害锦囊，并与当前原生逐目标用牌结算相接。闪电属于延时锦囊，不在这份局部分类中，也不复制同一实体到多个判定区。

这项分类是参考材料支持的工程解释。[官方武将页](https://www.sanguosha.com/hero/671)及[2025 年活动公告](https://www.sanguosha.com/news/20250416_1697_2417)给出求援正文；[2018 年官网刊载的锦囊教程](https://sanguosha.com/news/20180906_8699_5918)由社区玩家署名，列出上述四种普通伤害锦囊并另列闪电，其证据等级与当前官方技能 FAQ 分开。

原始材料见[分类来源](../sources/fenglin-twenty-ninth-671-damage-trick-classification-2026-10-04.json)。当前规则与目标/材料边界见[界伏皇后](FENG_LIN_TWENTY_NINTH_FU_HUANG_HOU.md)和[工程默认](FENG_LIN_TWENTY_NINTH_FU_HUANG_HOU_DEFAULTS.md)。
