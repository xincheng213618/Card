# 界夏侯惇、界李典共享能力

选用正文、来源与工程默认见[来源档案](../sources/fenglin-tenth-2026-10-02.json)及[规则口径](FENG_LIN_TENTH_RULINGS.md)。技能 ID 为 boundary:ganglie、boundary:qingjian、boundary:xunxun、boundary:wangxi，由人物目录注册。

## 刚烈与清俭

刚烈按每个实际伤害点分别提供可选判定。最终红色对实际伤害来源造成伤害，黑色由拥有者选择并弃置来源的一张合法牌；无角色来源时不提供该判定。判定、实体领取、暗牌选择和子伤害均保持原父关系。

清俭的 outsideOwnerDraw 资格读取移动发生时冻结的实际阶段及阶段角色；只排除本人的摸牌阶段。其他角色摸牌阶段中获得牌，或本人的其他阶段获得牌，分别按实际发生事实判断。

GiveShownBoundCardsAndGrantTurnHandLimit 消费先前实际选择并公开展示的 HE 绑定，赠给一名其他角色。所有实体真实移动并记账后、移牌和体力观察前，冻结实际进入接收者手牌的凭据；按实际基本、锦囊、装备三类去重产生本实际回合手牌上限贡献。移去游戏外或未真正入手的实体不计数。

赠牌凭据和已发贡献保存在所属帧及回合效果存储中；来源失去、后来卡牌移动或恢复不会重复赠牌及加值。实际回合结束到期。额度按拥有者、同名技能及 namedUsageGroup 共享，跳过不消费，额外出牌阶段不刷新。

## 恂恂与忘隙

恂恂使用摸牌开始的加量窗口，私看实际可用的至多四张牌，精确两张置顶，其余置底；两组都逐张排序，完成后返回原正常摸牌计划。短堆要求数为 min(exactTopCount,实际观看数)，只有空堆按原规则补洗。

TopReorder 保存 Viewed、RequiredTopCount、顶/底前缀和选择阶段。选择过程中不移动实体，最后对真实顶片段及完整分区校验后一次重排。牌面与顺序只提供给合法观看者；恢复不再次观看或洗牌。

忘隙按每个实际伤害点提供双向机会：拥有者真实摸两张，再从本次摸牌凭据中仍处于合法来源的实体交一张给另一参与者。子窗移走的实体不可由原手牌替代；没有可给牌或接收者死亡时有限完成，已摸牌保留。
