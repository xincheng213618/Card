# 刘协的原生目标、拼点与返回

天命先结清自己的实际弃牌/摸牌和完整子链，再确定唯一体力最多的其他角色。密诏先原子交付全部真实手牌，完成获牌子链后选择拼点对象。已接受的胜者杀使用精确原生完成返回，来源失效不会重付原交牌；尚未发行的后续才复验资格。

当前人物、程序绑定和规则来源见[规则合同](ORDINARY_OTHER_THIRTY_FOURTH_LIU_XIE_CONTRACT.md)；资料未明确的复杂口径见[工程默认](ORDINARY_OTHER_THIRTY_FOURTH_LIU_XIE_ENGINEERING_DEFAULTS.md)。
