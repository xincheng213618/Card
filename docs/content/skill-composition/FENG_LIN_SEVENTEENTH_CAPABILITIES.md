# 第十七批共享能力

本批冻结普通三国杀 OL 当前官网的界荀彧515、界孙坚458、界夏侯渊453。结构化身份、技能原文、立绘 URL、HTTP 状态和摘要见 [来源台账](../sources/fenglin-seventeenth-2026-10-03.json)。界孙坚采用 API 的体力上限5、初始4；网页社交摘要中的“4体力”不作为上限依据。

| 能力 | 内容消费者 | 结算边界 |
| --- | --- | --- |
| `drawThenDiscardHandToMaximumHp` | 界荀彧节命 | 在摸牌前冻结目标和 X=min(目标体力上限,配置上限)。真实摸X；等待移牌、体力子结算返回后，按当前手牌计算并冻结弃置差额。弃牌提示只对目标公开。死亡拥有者仅在原死亡帧及当前绑定一致时继续。 |
| `payHpToGrantOneUseDamageShield` | 界孙坚武烈 | 一次选择等量其他目标与体力付款。付款回执保留于原 ProgramSkillFrame；濒死、死亡、体力与移牌子帧返回后才授盾。付款者死亡或失去来源技能不重付、不撤销已付效果；游戏结束取消未授盾尾部。 |
| 独立一次伤害盾 | 武烈的“烈” | 标量来源凭据与公开标记计数一致；一次正伤害消耗一个盾，防止整次伤害。凭据持续到消耗，赠与者死亡不清除。原依赖来源存活的橘标记机制保留。 |
| `characterTurnedOver` | 界夏侯渊设变 | 正反两方向均记录不可变的前后状态。程序翻面、设置真实不同朝向及自然翻回正面共用既有 CharacterState 续接；已有仅翻回正面的窗口先处理。没有新窗口依赖的旧内容不产生新增事实。 |
| 翻面子结算的伤害游标校验 | 伤害触发中的设变 | 仅识别连续且身份一致的新翻面窗口、候选程序、移牌/体力观察帧和濒死返回；不放宽所有生命周期帧。原伤害程序在子结算返回后继续。 |
| 摸后弃阈值子结算的伤害游标校验 | 伤害触发中的节命 | 精确匹配已执行指令、冻结草稿、原伤害候选身份和真实摸牌/弃牌账本，允许连续的获牌、体力与濒死观察子帧返回。死亡入口不进入伤害游标白名单。 |
| 对应装备区移动的可选禁止替换 | 设变 | `prohibitReplacingEquipment` 增量允许装备区来源及已选二人引用。选牌时过滤被占用的对应槽，执行时再次校验；没有合法牌则走既有 `skipIfNoCards`。旧手牌来源及未启用标记的冻结行为保留。 |

驱虎、英魂、阶段跳过、无距离虚拟杀、对应装备区移动和标记显示复用现有能力；没有增加武将专用 Host 判断、Runner 开关或重复定义快照。新规则节点为可选增量，版本判断以 Replay.cs、SkillPrograms.cs、StandardClassicGeneralPackage.cs 的来源为准。

新的公开事件只包含标量或嵌套的不可变标量记录。付款与弃牌选择中的集合在原拥有帧冻结；玩家视图继续通过 CreateSnapshot(viewerSeat) 投影，ResolutionStack 只供可信诊断。
