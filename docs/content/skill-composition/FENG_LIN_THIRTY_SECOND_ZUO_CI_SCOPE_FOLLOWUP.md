# 化身范围的来源边界

[2019 年官方界左慈公告](https://www.sanguosha.com/news/20191212_3649_0318)记载初始三张化身、移去至多两张换新，并明确排除限定技、觉醒技和主公技。[2021 年范围扩展公告](https://www.sanguosha.com/news/20210903_6756_2218)列举对应调整的既有和新增界版子集。

这些材料分别支持其公告时点的规则与名单，不构成当前完整随机池，也不能自行证明后续版本继承了全部排除、回收、重复和耗尽规则。

当前项目的[经典左慈](../../../src/Characters/zuo-ci/classic/Content/classic-zuo-ci.character.json)使用独立配置与工程范围；界版当前来源和经典默认保持分开。规则资料规范见[来源核对](../BWIKI_CONTENT_BACKLOG.md)。
