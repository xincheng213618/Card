# 灵雎的拥有帧与私有信息

材料选择、实际支付及伤害修改记录在所属程序帧。候选手牌仅向实际选择者投影，事件只发布规则允许的已支付信息。回复、HP 与移牌子窗口返回原成本，不能以任意祖先或另一次移动作为支付证明。

当前人物、程序绑定和规则来源见[规则合同](ORDINARY_OTHER_THIRTY_FOURTH_LING_JU_CONTRACT.md)；资料未明确的复杂口径见[工程默认](ORDINARY_OTHER_THIRTY_FOURTH_LING_JU_ENGINEERING_DEFAULTS.md)。
