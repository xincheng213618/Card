## 界虞翻

当前纵玄同时覆盖自己因弃置进入弃牌堆的牌，以及上家每个实际回合第一次发生该类弃置的牌；可以把其中任意张置于牌堆顶。当前直言在自己或上家的结束阶段发动：实际摸一张并展示，装备则真实使用后回复；非装备且该角色体力与本人不同则失去体力。[官方正文](https://www.sanguosha.com/hero/603)

`classic-yu-fan.rules.json` 已有本人 HEJ 的 `CardsMoved/PerOwnerBatch/movementDiscardOnly` 及 `PutDiscardedCardsOnDrawPileTop`，也有真实 Draw→Reveal→FilterEquipment→UseBoundCardByTarget→Recover。它不覆盖上家触发、每回合首次或非装备体力比较，不能直接复用完整经典技能。

后续应在实际 owning window 冻结合法来源座位、上家关系、原弃置批次和实际 turn；首次资格应明确发生时消费或选择时消费，避免拒绝后第二批又当首次。死亡改变相邻关系、同一 batch 多个 owner、原牌已被另一孩子取得及多张置顶顺序均需单列工程默认。选牌与公开展示只可使用实际弃牌实体和成熟 movement ledger；直言装备使用、替换装备、Silver Lion、HP、救援与死亡孩子必须真正返回后才推进后继，不从最后一条事件猜测收益。

## 界程普

当前疠火允许非火杀改火杀；该实际牌结算后确实造成伤害，选择弃一牌或失去一点体力，且火杀可多指定一个目标。当前醇醪把自己或相邻角色因弃置进入弃牌堆的杀放到武将牌上；濒死时移去 X 张醇，视为该濒死角色使用酒，X 与本轮用此法使用酒的次数相关。[官方正文](https://www.sanguosha.com/hero/620)

当前经典能力分别位于 `lihuo-program-skills.rules.json`、`owned-zone-storage-skills.rules.json`、`owned-zone-dying-rescue-skills.rules.json`。已有真实转换、火杀额外目标、`CardUseCausedDamage` 完成事实以及实体醇的酒救援链。经典疠火的转换输入及固定失体力后果、经典醇醪在结束阶段存手牌且每次支付一张，均不能代替新当前技能。

新规则应限定同一实际弃置 batch 的邻座杀实体，防止 Processing cleanup、使用或打出杀混入。相邻座位何时冻结、死亡座位是否跳过、同批多来源及同一牌被多人取走要明确。轮次次数必须由已发行的真实酒 Use 记账，而非濒死次数或粗略 Alcohol/Recover 事件；第一杯成本采用前瞻的第1次还是其它解释缺当前 FAQ，应明确工程默认。多材料付款应原子校验并一次转移，实际酒 Use actor 为濒死者，保留护甲、救援、死亡、Completed及来源失效的 typed parent return。新转换还要审计雷杀与其它身份牌，避免放宽旧经典输入或改旧重放。

## 界吴国太

当前甘露每出牌阶段一次交换两人的装备区；装备数量差 X 大于本人已损失体力时，在选择角色时弃置 X 张牌。当前补益在一人进入濒死时选择其一张牌，非基本牌则弃置后回复一点体力。[官方正文](https://www.sanguosha.com/hero/640)

`classic-wu-guo-tai.rules.json` 已有 `equipmentExchangePair`、原子装备交换以及濒死展示手牌→非基本筛选→真实弃置→回复。经典甘露的合法对象筛选与无付款交换、经典补益的仅手牌且他人随机展示语义不足以覆盖当前两项，不能靠修改经典定义扩展。

新甘露须在对象选择处冻结装备差与付款要求，结合真实拥有的可弃实体校验选择，不能先交换再补成本或在孩子恢复后重新收费。付款的移牌、Silver Lion/HP、来源失效子流程回返后，使用同一冻结对象执行成熟装备交换；若目标装备变化，应明确重验或取消的默认。补益“一张牌”的 HE/HEJ 口径及暗手牌选择模式缺当前 FAQ，应显式说明，使用不透明手牌位置、公开装备/判定身份与成熟装备保护；真实弃牌孩子结束后才回复，不用净体力或静态快照代替支付。
