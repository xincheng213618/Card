# 技能标签、执行形态与运行状态

技能标签和执行形态由内容结构化声明，中文描述不产生运行行为。术语依据仓库采用的 [BWIKI 技能概念介绍](https://wiki.biligame.com/sgs/%E6%8A%80%E8%83%BD%E6%A6%82%E5%BF%B5%E4%BB%8B%E7%BB%8D)来源快照。

## 内容字段

| 字段 | 当前含义 |
| --- | --- |
| `Tags` | `Lord`、`Locked`、`Limited`、`Awakening`、`Conversion`，可组合 |
| `ExecutionForms` | `State`、`Trigger`；复杂技能可同时具有两种部分 |
| `ActionForms` | `Active` 表示本应用提供主动选择入口，是交互维度 |

未知位在装载时拒绝；`Awakening` 归一化包含锁定与限定标签。锁定标签不自动提高优先级或生成执行步骤，主动入口也不自动注册实现。条件、候选、询问及效果通过程序或注册运行时明确声明。

元数据进入规范化内容指纹；展示文本、翻译和 UI 标签不替代这些字段。格式和哈希实现取 `ContentRegistry` 与相关定义源码。

## 拥有资格

印刷主公技通过 `Lord` 标签和实际身份统一过滤，规则查询、程序发现、转换来源和玩家技能视图使用同一拥有资格。图鉴保存人物印刷的完整技能列表；具体对局视图显示当前实际拥有技能。

动态授予保留真实来源与技能实例，资格及寿命按授予合同处理。派生技能必须明确其规则版本，不能按中文同名借用另一条线的定义。

## 次数与状态

`SkillRuntimeStateStore` 以拥有者、稳定技能 ID、用途及明确作用域记录次数。支持事件、阶段、回合、轮与整局。真实阶段/回合/轮边界清理对应作用域；整局记录只有明确重置才清理。插入阶段和额外回合依实际调度身份处理。

转换技能有注册的初始面和当前面；执行成功后的切换、永久成长、限定消费和技能重置分别由实际规则触发。失去/重获实例是否继承状态与额度依能力合同，不能自动生成额外额度。

状态投影只展示玩家有权知道的内容。暗将或私有来源不通过技能实例、状态标记或派生技能泄漏。Checkpoint 在当前实现下重放命令前缀重建这些状态；恢复检查与格式见[存档](../../SAVE_AND_RESUME.md)。

当前字段使用与解析见[运行时](RUNTIME.md)，规则修正及到期见[状态与时间](RUNTIME_STATE_AND_TURNS.md)。
