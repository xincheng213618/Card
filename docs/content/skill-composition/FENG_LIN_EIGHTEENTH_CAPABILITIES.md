# 第十八批共享能力

本批采用当前普通三国杀 OL 的界太史慈463、界曹彰599。官方正文、结构化身份、原始立绘与 HTTP 摘要见[来源台账](../sources/fenglin-eighteenth-2026-10-03.json)。此文件描述实现合同；实际验收以本批验证记录为准。

| 能力 | 消费者 | 结算边界 |
| --- | --- | --- |
| `pindianOpponentRandomHand` | 酣战 | 双方按发起者、对手顺序分别选择。接受时只从对方当前手牌抽取一次，将选牌及 RNG 前后状态保留在原 PindianFrame；公开事件仅记录发动来源，不公开未揭示牌或随机状态。随机策略先于牌堆顶预留。 |
| `pindianMaximumSlashClaim` | 酣战 | 普通拼点揭示后，冻结有效点数最大的杀的身份；同点最大杀均可获得。获取过程中不改用较小点数的杀，已有拼点获牌策略仍按参与者顺序结算。 |
| `recastBoundCard` | 将驰重铸项 | 本批仅支持 `drawPhaseEnded`，输入是精确的一张自有手牌或装备牌绑定。原 ProgramSkillFrame 保留支付回执，先完成弃置及体力/移牌子结算，再摸牌并完成获牌观察者，最后继续授予回合效果。 |
| 有符号的杀次数加法 | 将驰摸牌项 | `slashLimit/add` 接受非零负数，沿既有规则查询合成；其他查询和运算的原有边界保留。AI 将负值识别为成本。 |
| `grantTurnHandLimitCardKindExemption` | 将驰摸牌项 | 授予期间动态豁免指定实际牌种，包含后来获得的杀。与既有精确牌号、当回合获得牌豁免取并集；原回合实际结束才到期，发放后不依赖来源继续存活或可用。 |
| 摸牌结束互斥选择组 | 将驰 | 复用既有 `choiceGroup` 选择流程，仅增量允许摸牌结束窗口；摸牌项、重铸项及不发动互斥。 |

天义的胜利加次数、无距离、额外目标和失败使用禁令均复用现有回合能力；杀的响应不被使用禁令误禁。新回合策略的公开列表及其嵌套牌种列表在提交投影和玩家视图中冻结。选牌、支付及随机身份留在拥有帧，玩家可见结果只用 `CreateSnapshot(viewerSeat)`。

未增加人物专用 Host、Runner 开关或内容定义快照。版本依据仍为 Replay.cs、SkillPrograms.cs 和包的 CurrentVersion；本批增量可选能力不按新增人数提升版本。
