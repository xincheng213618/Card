## 版本口径

采用当前 OL 普通版英雄页，历史官网攻略只补充不冲突细节。李严的延迟摸牌按当前“下回合摸牌阶段”，不将旧“下一摸牌阶段”跨过跳过回合积累的版本混入。刘虞末势力死亡只减体力上限，不添加其他版本的摸两张牌。

郭皇后当前殚心正文省略升级详情；[官方2016攻略](https://www.sanguosha.com/news/20161220_8348_1418)列出两次修改。最终修改为出牌阶段限一次直接转化一张手牌，不保留先展示与他人声明流程。该攻略还明确桃园、五谷不使自己受益；排除自身效果必须贯穿目标枚举及实际效果结算。

张让按游戏域限制输出牌名，任何角色濒死期间不能发动。只允许“使用”，禁止用打出杀／闪的流程代替。普通、火焰、雷电杀按同一杀牌名族记录是依据官网攻略列出的四类基本牌名及已有公共牌名语义作出的解释，须由行为检查固定。历史攻略明确木牛流马下的牌可作费用，实体费用来源需要通过公共区域能力合法消费。

## 实施约束

从当前未提交工作与裁剪后的测试构造一致源码副本，不从旧 Git 提交恢复整套测试。新增操作按公共接口、描述符、资源校验、host、AI 和 JSON 接线；不增加人物 ID 分派，不把近似结果当作完整技能。

延迟收益保留来源拥有者、受益者、贡献者、实体区域与到期回合。暂停选择只向决策者公开可见牌；公开武将堆需要独立公共快照和展示，不借用“权”牌堆改变其规则。

必要行为检查覆盖真实费用／区域、全部观察者隐私、暂停 checkpoint、命令 JSON 回放及非法回答原子拒绝。主工作区整合后再记录真实验证结果；不按人物递增规则纪元、schema 或包版本。
