# 第十九批口径与工程默认

本批采用当前普通 OL 的[界庞德462](https://www.sanguosha.com/hero/462)、[界法正610](https://www.sanguosha.com/hero/610)、[界韩当676](https://www.sanguosha.com/hero/676)。完整正文、API身份、HTTP与立绘摘要见[来源台账](../sources/fenglin-nineteenth-2026-10-03.json)。13项新增Core检查及整批Full已通过，实际检查边界见[能力合同](FENG_LIN_NINETEENTH_CAPABILITIES.md)；复杂互动未取得官方FAQ的部分明确作为工程默认。

- 鞬出弃置基本牌后，目标只获得原杀使用冻结的实体材料中仍在处理区的牌；取得实体不取消该杀。真正无实体的虚拟杀没有可获得牌，但原使用继续。转换杀沿实际材料身份获得，多目标后续不能再次取得已经离开处理区的实体，不混入目标弃置牌或其他父结算的牌。
- 鞬出的非基本分支仅禁止当前目标抵消原杀，沿既有黄忠、铁骑对闪及八卦的抵消边界：真实响应仍可支付，但不能终止该杀；并非取消藤甲、仁王盾使该杀无效的其他机制。本回合杀次数+1沿现有回合修正能力。
- 鞬出原生AI仅在新实体领取/抵消能力相邻的弃牌结构中，以公开关系、手牌数量及基本牌占一半的固定先验估价；不看目标隐藏牌种或抽取RNG。该先验为工程默认，旧孟进估价不随本批改变。
- 眩惑交牌区域沿一般“牌”的HE默认；交两牌与取得两张手牌各构成一个原子移牌批次，恩怨按实际单一来源至少两张计数，不将跨手牌/装备区的一次赠与拆成两个单牌获得。
- 眩惑指定与使用杀沿既有实际使用合法性和请求接口，不另造虚拟杀；拒绝后只向法正私密展示所选角色当前手牌，选择并取得实际仍可用的至多两张牌。空手或不足两牌不制造实体，也不从其他区补牌。
- 恩怨偿还由伤害来源自己选择：交一张有效红色手牌，或真实失去1体力。只在付款者自己的私有提示中列出可交牌；使用其当下有效花色判定红色，不直接按未经修正的印刷花色过滤。
- 弓骑在真实弃置前冻结付款牌的有效花色；装备回复、体力与移牌子结算改变技能来源后不重算花色。已授予的同花色杀额度豁免持续到原实际回合结束，与后续获得的实体牌动态匹配，不以数值扩大杀次数模拟无限额度。
- 解烦是否处于第一轮，在发动时冻结。返还义务绑定原实际回合、原限定使用键及原技能实例，只清该键一次，不重置其他额度或转换状态。额外回合沿既有轮数，不自行推进轮；死亡、匹配技能实例失效或游戏结束时取消尚未执行的返还，不转交给新实例。这些取消与来源口径为工程默认。
