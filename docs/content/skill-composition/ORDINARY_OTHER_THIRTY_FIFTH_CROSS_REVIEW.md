# 多材料杀与类别限制的共享边界

多材料杀在接受和消费下一次用牌加成前冻结合法目标上限；后续颜色转换保留原材料与实际动作。手牌类别限制同时应用于发布和支付校验，自己的受限弃牌与他人选牌分开，不能把手牌上限计算变成忽略受限牌。

当前人物、程序绑定和规则来源见[规则合同](ORDINARY_OTHER_THIRTY_FIFTH_SP_MA_CHAO_CONTRACT.md)；资料未明确的复杂口径见[工程默认](ORDINARY_OTHER_THIRTY_FIFTH_YANG_XIU_ENGINEERING-DEFAULTS.md)。

实现入口：[GameEngine.HpLossSlashMaterials.cs](../../../src/CardGame.Core/GameEngine.HpLossSlashMaterials.cs)。
