# 界张郃、界曹冲规则口径

项目采用的正文与工程默认见[来源档案](../sources/fenglin-twentieth-2026-10-03.json)。

当前普通OL正文优先于历史版本。曹冲仁心采用他人濒死时弃装备、翻面、回复至1；不替换为历史版本的伤害前防止伤害。称象的恰好13只影响下一次实际接受的发动；拒绝发动保留额度，连续达成不叠加。

次次发动按现有逐点伤害游标推进，实际公共池与原材料ID决定可选范围。付款和获牌均以真实移动为依据；已提交的事实、公开状态和玩家投影仍受原冻结与隐私边界约束。

普通伤害与绝情替换造成失血的体力边界不同。真实检查分别验证普通实体杀的0体力濒死链，以及绝情失血的负体力恢复至1；不得以直写HP、伪造host调用或更改旧伤害截0语义替代真实命令路径。

巧变的弃牌费用采用拥有者HE，不包含判定区；未知手牌取得沿现有随机盲取模型，玩家先选角色。装备只能移动到空对应槽，判定沿成熟合法目的地区域。结束历史包含所有实际进入结束的自身回合，含额外回合；来源同实例暂失效保留历史，新实例重获从空开始。途中获得巧变不补发GameStarting两枚标记。这些是明确的工程默认，不声称已取得额外官方FAQ。
