# 第十八批口径与工程默认

来源为当前普通 OL 的[界太史慈463](https://www.sanguosha.com/hero/463)与[界曹彰599](https://www.sanguosha.com/hero/599)。两人最大体力均4；API 的 `initial_hp=0` 作为未单列初始体力，沿既有默认从上限初始化。技能正文与以下工程默认分别记录，未核实的复杂裁定不标成官网 FAQ。

- 酣战的“点数最大的杀”先筛选杀，再按拼点冻结的有效点数取最大；火杀、雷杀也属杀。同点最大杀全部作为一个获牌选择，若另一策略已获得其中某牌，仅保留仍在处理区的冻结身份，不补选较小杀。
- 两人都有随机手牌策略时，按发起者、对手顺序选择，每次接受各消费一次比赛 RNG；拒绝前项不影响自己的拼点后获牌项。已随机的牌在恢复后不重抽，提示、玩家视图和日志不包含未揭示身份或 RNG 凭据。
- 随机手牌策略先于秦宓式牌堆顶替代；被指定随机的一方不会再选择牌堆顶。沿既有入口要求双方有手牌，未增加空手角色用牌堆顶参与拼点的资格；空手目标不消费随机数。这些交互为工程默认。
- 将驰的两项及不发动沿同一个互斥选择组。重铸输入沿引擎一般自有牌选择默认允许手牌或装备区一张牌；官网正文未单列区域，尚未取得该细项官方 FAQ。
- 重铸先真实支付，再等待成本和收益观察者。拥有者死亡、技能来源失效或游戏结束时取消尚未执行的收益与效果，已支付成本不回滚、不重付。回执只属于原程序指令；此取消时点是工程契约。
- 将驰摸牌项的杀次数 -1 与既有正向加法叠加；豁免按实际 `Slash/FireSlash/ThunderSlash` 类型动态计算，不以当前杀数量临时扩大手牌上限，也不将虚拟转化材料当作实体杀豁免。
- 已发放的牌种豁免持续到原实际回合结束；来源失效不提前撤销。额外阶段与额外回合分别沿原回合次数及阶段次数机制，天义限每个出牌阶段一次。

以上为当前实现的明确合同；完整行为、冷回放与隐私验收结果另见本批验证记录。
