# 第二十一批当前普通 OL 工程口径

来源为 2026-10-03 冻结的官方界徐晃496、界董卓470、界贾诩484页面正文与API；实现及复验日期为2026-10-04。各技能必须对应这些全文，不用经典版或其他产品的同名技能补充当前正文。三名武将已集成，13项新增定向行为通过，完整与日常范围以本批实际验证台账为准。

## 徐晃

断粮依据实际整回合造成的伤害记录决定距离，不以当前出牌阶段、伤害估值或失去体力替代。黑色基本牌与装备牌转兵粮沿现有实际付款链，卸下装备后的回复、移动及技能暂停继续属于该次付款。

截辎在真实跳过摸牌后选择仍存活的角色。全场最少手牌包含并列；该角色没有辎才发放标记，否则执行真实摸一张牌。已发放的标记及收益归属凭据保留原技能实例，不因来源随后死亡而消失。

辎的消费在对应真实摸牌结束观察者之后；先完成普通摸牌的实际获牌批次和收益观察者，再发布该次结束，消费标记，执行独立额外摸牌阶段。额外阶段同样有起始、跳过、摸牌、获牌及结束链。额外阶段再次跳过时新取得的辎必须等待下一次真实摸牌结束，不能借用此前已经发生的结束付款。

## 董卓

酒池保留未消费酒效果不能叠加的既有边界。酒杀是否消费酒由原CardUse保存真实标记，不能由伤害数值为2推断。造成伤害后仅使本次实际回合的自身崩坏失效；每张不同杀分别签发凭据，在该回合结束后统一到期。来源途中失效不能删除已签发的凭据。非酒增伤、酒杀被闪以及无实际伤害均不能签发此项失效。

崩坏在实际结束时比较存活角色体力最小值；当前回合失效结束后，下一实际回合恢复资格。失去体力和减最大体力是明确的真实选择。

暴虐按其他群势力角色每点实际伤害逐点判定。判定属于当前主公本人，原伤害来源、目标、点序号、技能实例、当前候选和判定结果绑定全部冻结。黑桃判定先回复再取得真实判定实体，回复与获牌子窗口返回到同一个判定及原伤害点。已获牌的实体不得被外层结果清理再次弃置。

醇醪的间接救援须证明原伤害点、判定、收益、濒死以及救援程序的连续父链，再验证真实醇付款和虚拟酒动作。通过完整严格证明的Program→Alcohol子树整体返回；不能把它当成直接Dying→Peach，也不能扩大为任意CardUse豁免。

## 贾诩

帷幕的颜色为该次实际锦囊有效颜色，混合实体与零实体无花色动作不得用一个历史占位布尔值推断黑色。无显式目标的摸牌锦囊按实际使用者接受目标策略检查；闪电转移按实际保留延时锦囊的实体有效花色。自回合防伤收益按已防止的原伤害值双倍真实摸牌，真实逐张获牌批次必须属于同一个收益程序。获牌、失血、濒死及实体桃救援暂停后保留精确原BeforeDamage返回；死亡及其他救援尾部覆盖范围单列。

完杀的用桃限制贯穿自身实际回合。濒死期间的非锁定失效仅属于当前濒死窗口，自己及当前濒死角色豁免；离开窗口即恢复，不写成永久本地禁用。动态资格缓存同时依赖当前来源技能修订、体力与生存状态。

乱武依次冻结参与者距离最小集合，再枚举其中实际合法实体、身份转换和激将付款。付款装备引发的距离变化、转换来源独立距离豁免分别验证。拒绝或无人能提供杀时只支付该参与者一次失血，接着处理下一参与者。末尾视为杀免距离及次数扣减，同时记录实际用杀和出牌阶段用牌历史。两种新杀操作限定主动出牌程序，加载时拒绝触发式组合。

已付实体杀的来源失效检查在实际CardUseCommitted观察窗口执行：断言实体已从手牌进入Processing一次，然后才令原技能来源失效。原杀继续完成，未签发参与者及末尾杀取消；此项不改变旧CardsMoved观察时序。私有选择游标与实际付款动作、失血窗口、精确程序父帧逐层对应，不放宽共享已执行选择检查。
