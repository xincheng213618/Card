# 第十批规则口径

本记录对应当前普通 OL [界夏侯惇](https://www.sanguosha.com/hero/313)和[界李典](https://www.sanguosha.com/hero/317)正文。实现与验收状态见来源档案及批次记录。

- 用户已确认：清俭只排除技能持有者自己的真实摸牌阶段，其他角色的摸牌阶段得牌仍可触发；额外摸牌阶段按实际阶段归属判断。
- 清俭可展示并交出至少一张手牌或装备牌，可含此前已有的牌；不开放判定区和私有保留牌。这是正文未明确区域及零张口径时采用的工程默认。
- 恂恂短堆按实际观看的牌处理，顶牌数为 min(2, 实际观看数)，沿用仅空堆补洗的既有机制。此项是工程默认，尚无当前同版本官方 FAQ 明确不足牌口径。
- 新增能力只由新内容选择启用，既有节点缺省行为、规则版本、JSON schema 和内容包版本维持原有来源。
- 刚烈在判定前要求真实伤害有角色来源。真实闪电虽在旧内部结构保留受害者座位，新技能仍通过真实延时伤害标志排除它；旧技能的内部事实保持原样。黑色分支选定来源牌后有一次单选确认，这是复用现有交互能力的界面限制。
- 忘隙只能选择本次实际摸牌所得、仍在冻结来源区域的实体；剩余零张或受赠者死亡时有限结束，不拿旧手牌替代。摸牌子技能、实体桃与急救转换救援、救活后的技能暂停均沿实际父帧逐层恢复，已摸牌及付费不重复。转换救援读取已付实体及冻结的转换来源，不重新支付或重新判定已完成的转换。

官方立绘保留原始 PNG 字节。离屏 WPF 检查及自动化行为验证不代表官方客户端或人工桌面实测。
