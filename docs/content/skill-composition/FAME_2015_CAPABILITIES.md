# 一将成名 2015 使用的公共能力

本批武将通过公共描述符、handler、资源校验、host 和 JSON 组合接入。操作以规则语义命名，不通过武将 ID 分派。来源和版本取舍见 [来源记录](../sources/fame-2015-2026-09-30.json)。版本来源仍在 Replay、SkillPrograms 及内容包定义中；本批没有为单名武将提高版本。

## 费用、身份和实际使用

ViewAs 的可选 `costDestination: "drawPileTop"` 将冻结的手牌／装备费用直接移至牌堆顶；费用不经过 Processing，也不会在使用结束时误弃置。`unusedOutputThisTurn` 核对实际使用牌名账本，普通杀、火杀、雷杀共用杀的牌名；`useOnly` 区分使用与打出，包括濒死救援中的实际桃／酒使用，以及本人以闪抵消杀。万箭齐发、护驾的打出闪，以及决斗、南蛮的打出杀均不符合该规则，也不计入实际使用牌名。

全手牌普通锦囊允许指定固定输出类型。转换来源、实体提供者与实际使用者分别保留，改换使用者不会转移原转换技能的后续奖励。真实伤害参与者账本按卡牌结算帧记账；主人摸牌限制只累计该技能实际给予主人的牌，原生击杀奖励不计入。

势力响应策略可声明 `discardCost` 和 `providerDrawCount`。先提交手牌／装备实体费用，再依次询问自愿提供者；只有实际成功提供牌才给予一次奖励。暂停状态记录费用和奖励是否已支付，避免续接重复支付。

## 判断、展示和移动

单卡重铸复用实体移动及重铸事件，并按实际阶段累计。双方展示先由各自私下选择实体手牌，随后同时公开，输出命名分支供既有弃牌、伤害及获得牌操作消费。展示不构成使用或打出。

手牌干预使用严格大于／小于比较，暗手以不透明槽位选择。全手展示后的颜色费用一次弃置该色全部真实牌，再按去重参与者逐个获得；实际获得数决定后续失去体力。顺序摸牌置顶每人先摸一再置顶一，可选择手牌／装备；移动触发完整结束后才推进下一位。能力替换只能作为主动程序的末条操作，先获得新技能再移除旧技能。

指定目标后的可选观察覆盖基本牌、装备及锦囊。只在内容声明相应窗口时增加隐含自身目标和延时锦囊窗口，避免改变未启用内容的默认表示。同一实际使用只发布一次接受事件。

## 后续回合、伤害和响应

下一实际执行回合的加成保留授予来源和受益席位，翻面跳过不消耗。手牌上限与杀次数各自进入对应查询，攻击范围不受手牌加成影响。

势力濒死恢复冻结座位顺序逐个询问，即使已恢复至正体力仍完成本次询问。原濒死结束后才逐一结算接受者的无来源伤害；每项先推进游标再结算，可再次进入濒死。Request、Applied、After 伤害事件携带可选 `SourceLess` 标记，死亡无击杀归属，战报及反馈不把内部续接座位当作伤害来源。

伤害前武器选择冻结真实武器及其范围：足额弃置目标手牌后弃置该武器，或增加本次已定伤害。判定收益读取最终冻结花色，红色实际回复，黑色按原伤害值实际摸牌。

本回合按出牌阶段实际造成伤害设置手牌上限；受到伤害及失去体力不累计。永久势力目标效果扩展“在攻击范围内”判定，保留数值攻击范围与距离查询。

最大手牌弃牌提供闪的操作仅发布于真实闪响应窗口。先令当前回合角色实际摸牌，完成移动触发后重新比较；成功需支付最多手牌角色的一张实体手牌／装备／判定牌。唯一最多或无法支付时保留摸牌，恢复原响应，不能凭空提供闪。子程序保留精确 RespondDodge 决定、激活和父 ResponseWindow，并验证移动观察者链；成功响应同时保留虚拟转换来源及实际提供者，适用于杀、万箭齐发和势力提供闪。其允许使用或打出，资格与只允许使用的 ViewAs 分别校验。

新增状态通过命令日志重放重建；可选字段省略默认值。实体守恒、输入原子拒绝、各席位隐私快照和 checkpoint／命令 JSON 回放继续由共享检查验证。
