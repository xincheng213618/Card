## 来源齐备后的具体工程裁定

这些是待明确的工程口径，不是假定已取得的官方FAQ。派生技能身份/版本与当前随机池政策不得被同名经典默认悄悄替代；若选择历史规则或自定封闭范围，必须另作明确规则选择，继续如实保留当前来源缺口。

- **451**：费用基本牌按何种实际身份、手牌付款不足/失效时的无效杀返回；真实跳过出牌后的弃牌阶段付款和额外回合发行；最小体力并列判定、觉醒一次额度、回复至3及来源失效后的授予尾部。先取得两项派生定义，再定完整获技组合。可复用候选是现有实体费用选择、当前目标无效、阶段跳过/额外回合、MaxHP/RecoverTo 与技能授予机制；本次没有重审代码来宣称它们已经满足整套规则。
- **690**：两材料区域、混色的实际有效颜色；“同色手牌响应”是否覆盖所有响应及转换/装备/牌堆材料的原区域；获技发行于真实出牌阶段杀的伤害、额外阶段/回合、来源失效和回合末清理。已有两材料 Slash、冻结动作/完整材料来源、实际回合技能授予可作为复用起点；响应颜色与手牌原区域限制必须单独核对应合同。
- **449**：同时质疑需先私密收集并冻结投票，再公开揭牌；多个质疑者的处理顺序、真牌先获缠怨后的弃置区域/不足与HP/Dying子链、原已付声明精确返回、实际回合额度和来源消失。已有声明付款、揭牌/原动作返回和失血子链仅为复用起点；旧经典顺序不自动等于当前同时质疑。
- **447**：只有当前池/继承政策明确后，才能裁定移去是否回池、短缺/耗尽/重复、已展示化身被移除、展示技能替换与来源失效、RNG次序及私密库/公开展示投射。已捕获的经典实现对照指向 `FengLinZuoCiContent.cs`、`classic-zuo-ci.rules.json` 和 presentation；可复用私密武将库拥有选择、技能/性别/势力投射、逐伤害点获得和回合边界。初始3张与至多2张等量交换需要新的准确拥有帧收据；不能直接把经典初始2张和排除范围改标为当前权威。

## 不重复的推进顺序与完成门槛

1. 先由根选择处理哪一项以及需要的具体材料；只受理真正命中的当前一手正文或明确版本继承，保留正文对照。451已读的 heroDetail/commen/header 脚本、690同一2016攻略、449同一2020公告及447同一2019/2021公告，不作为无新增线索的重复请求目标。
2. 获得候选证据后，逐项标明关闭哪个 font/池/继承字段，哪些仍须工程裁定。不能因主文或历史全文完整就把所有 readiness 字段改成 true。
3. 来源与完整工程合同都确定后，才检查具名共享入口、实现整个人物并安排真实费用/子链/隐私/冷恢复验收；这份计划不登记部分人物，也不启动这些步骤。
