# 于吉、左慈共享能力

项目采用普通 OL 于吉、左慈正文，规则、身份与工程默认见[来源档案](../sources/fenglin-sixth-2026-10-02.json)。[普通 OL 公告](https://www.sanguosha.com/news/20140305_6018_5340)补充缠怨禁止质疑和体力恰为一的资格，[普通左慈攻略](https://www.sanguosha.com/news/20140521_8678_1419)补充私有武将库、公开声明、有效属性及可借技能标签范围；这些补充用于项目选定的普通版。

## 回合结束后窗口

AfterTurnEnded 位于真实回合结束、Finished 清理和返还完成之后、下一回合开始之前，覆盖正常、翻面跳过及额外实际回合。DeferredHandAlignment 到期义务先处理，再冻结结束后候选及上下文。

DeferredTurnEndFrame 保存阶段、候选、游标和当前子帧。返回校验原技能拥有者、实例、绑定、父 ID、实际回合及结束角色；恢复不重复收集或执行候选。

## 蛊惑与质疑

声明转换接入真实使用、打出、响应、无懈、救援和供牌的各自提交边界，复用原生牌型、目标、距离、次数和禁令。费用为本人一张真实手牌；合法声明接受时支付费用并消费该提供者同名技能本实际回合一次额度。真假、无人质疑和后续失败均保留成本及次数。

CardDeclarationFrame 冻结原实体及地址、声明牌名、目标、转换实例和原用途返回。挑战子帧按当前回合角色起的行动顺序询问其他合格存活角色，跳过只前移，首位质疑者结束后续询问。无人质疑成功；有人质疑才公开实体，真假按接受时的印刷牌名与具体声明牌名比较。

成功返回原用途一次；失败按原用途真实清理，决斗/群体不视为成功打出、供牌不成功、无懈不翻转效力、救援不产生回复。真牌为质疑者授予来源明确的缠怨；缠怨的体力资格和禁止质疑读取有效技能绑定。

公开声明快照只给牌名、角色、目标与揭示状态，揭示后才给真实牌面。本人可以看到自己的费用，其他玩家及 AI 不读取隐藏费用、真假或可信结算栈。已接受费用的原用途通过精确父链续接，死亡、终局及父帧失效按有限清理返回。

## 化身与新生

InitializePrivateGeneralLibrary 在 GameStarting 抽两张并选择；AcquirePrivateGeneralAvatar 按实际伤害点逐次提供获得机会；ChoosePrivateGeneralAvatar 在回合开始及结束后选择。抽取结果、随机消耗和选择游标保存于所属程序及来源库，暂停不再次抽取。

私有武将库按拥有者、能力授予与实例保存。候选来自本模式正式武将池，排除仍在场主副将及所有库已持武将，形成全局无重复库。展示将留在库内，允许同一将换技能。来源真正移除或死亡清理对应库及派生关系；暂时抑制保留库，实际资格和属性立即按有效来源查询。

借用候选排除限定、觉醒和主公标签，只接受已注册的可用技能。派生授予保留真实技能 ID 和精确库来源；替换只撤销本来源关系，同名技能使用和转换状态不因此重置。身份、队伍及胜负关系保持各自模式语义。

性别和有效势力由当前合格展示将查询，神将另有独立势力选择；来源失效时按原角色属性回退。多个有效库按稳定来源顺序决定展示。普通查看只公开来源、数量和当前展示将/技能，本人才有完整私库及选择；AI 不读取他人的库。
