# 头像私有牌堆与结束阶段顺序

OL 神诸葛亮的“星”属于 `PrivateReserve`，与手牌分开保存。头像上的 `七星[n]` 公开数量，所有玩家均可点击查看；拥有者看到牌面，其他人只看到对应数量的牌背。查看窗口消费当前玩家快照，并在生成牌面前再次校验拥有者座位，开发者视图也不扩大这个入口的权限。牌背模型只包含显示标签，不携带实体牌 ID 或牌面数据。

界陆逊的“谦逊”暂存整个手牌区，并在当前回合结束时返还。头像上的 `谦逊[n]` 和侧栏公开数量，仅拥有者可见牌面，其他人查看时显示牌背。其他玩家的私有牌堆入口放在各自头像左上部，避开武将名和体力；自己的入口放在头像下部。只读查看不提交游戏命令。

七星交换窗口上排为“星”、下排为手牌。点击或拖动将牌移入另一排，等量后才可确认；未确认的预览不移动实体牌。取消直接跳过当前可选发动。确认通过现有 `AnswerPromptCommand` 顺序提交发动、手牌选择、完成选择和“星”选择，物理交换仍由命令会话完成。

逐张选择过程中保存的存档通过私有提示的 `reserve-mode`、`reserve-required`、`reserve-selected-hand`、`reserve-selected-stars` 恢复已提交选择。已提交的部分不可撤销，“重选”只清除界面新增的选择。更换对局或读取存档会撤销旧按钮参数的权限；既有内容指纹兼容校验继续生效。

结束阶段的可选触发器可声明相同的 `orderGroup`。同拥有者、同优先级、在当前结束帧中连续且仍可执行的成员允许任选其一先发动，剩余成员之后仍可发动；取消跳过本次已提供的成员。它与互斥的 `choiceGroup` 分开，解析器只接受不带 `choiceGroup` 的可选 `turnEnding` 触发器。顺序保存在原 `TurnEndingBoundaryFrame.Items`，选择不创建额外的待处理状态。

狂风和大雾分别在目标头像旁显示“风”“雾”，使用已提交的公开标记，持续到施加者的下回合开始。两技能的成本仍是“星”的真实移动，不使用本地数量替代牌区账本。右侧座位的其他状态标记在“风”“雾”下方排列，避免占用相同位置。

定向检查名称：Core `Private reserve:`、`boundary Lu Xun`，WPF `Private reserve UI:`、`Portrait private piles:`。覆盖等量交换、取消、只读查看、过期参数、两阶段存档恢复、两种发动顺序、AI、逐次付费、标记到期和回放，以及谦逊暂存、连营和返还。头像检查使用八人桌面的 1440×920 和 1120×780 离屏渲染，覆盖左、右、上方座位、拥有者牌面、他人牌背、开发者视图权限、标记避让和牌堆清空。WPF 检查使用实际命令绑定，原生鼠标拖动及多 DPI 需要桌面验收。
