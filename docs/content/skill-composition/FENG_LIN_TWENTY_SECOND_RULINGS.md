# 第二十二批当前普通OL工程口径

依据冻结的官方界典韦526、界蔡文姬505、界张春华625完整正文，实现对应当前普通OL。来源捕获与注册状态分别保存；不借经典版或其他产品同名技能替换。开发及最终验收见[运行台账](../../benchmarks/2026-10-04-fenglin-twenty-second-validation.json)。

典韦强袭的“受到1点伤害”按引擎真实无来源伤害成本处理，不写成失去体力；官方独立FAQ未核实伤害来源细节，属于工程默认。目标先承诺后付款，武器可来自真实手牌或装备；致命成本取消尚未发生的目标伤害。阶段共享两次额度与整个实际回合不同目标限制独立保存。狞恶按实际伤害笔数，且检查该笔受伤者为自己或实际来源为自己；一次两点伤害不计两次。

蔡文姬悲歌按当前正文先判定、后可选弃牌。判定主体使用实际受伤者；判定和支付分别冻结当时有效花色及物理点数。两个匹配判断独立执行，领取只针对仍处于规定区的原实体。弃置移出游戏的实体支付有效，但无法从OutsideGame取回。梅花沿现有逐次选择方式尽可能弃两张HE牌；已死亡来源不再收到输入。

悲歌支付前原技能失效取消支付，支付后按引擎原子收益约定完成已付尾部。第三方判定领取、来源途中失效、空牌堆、有效花色改写、双领取先后及复杂救援边界没有独立当前官方FAQ证明；实现使用现有实体、原子付款和typed子窗口工程约定，不能称为官方裁定。空判定不提供无结果支付。

张春华绝情和伤逝复用与当前全文相符的现有能力。翦灭采用两个私密承诺模拟同时选择；第一次选色不公开，双方选完才以一个实际混合移动批次弃置。数量在移动前冻结，以真实付款数量决定决斗使用者；收益补牌不重新计数。空集合仍可选颜色，平局无决斗且额度已用。支付后来源死亡保留已付成本并取消尚未签发决斗，按既有来源失效约定处理；官方相关独立FAQ未核实。

原生AI只使用 chooser 自己的可见牌、公开关系及公开最终判定，评分是工程先验，不是胜率测量。张春华首次选择不读取对手隐藏颜色或手牌。新公有事件载荷都是标量；暴露的草稿、私密prompt参数及嵌套集合由既有准备投影冻结。

实际新增覆盖与静态复用分列：蔡文姬流离重定向、复杂醇醪/多材料救援和死亡收益子树；张春华已签发决斗来源失效、无懈、目标死亡及有效颜色改写，未作为本批独立新子例逐一实跑。完整检查可以覆盖既有共享路径，但不能替代这些专属场景证据。
