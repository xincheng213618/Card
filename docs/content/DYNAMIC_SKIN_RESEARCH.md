# 静态皮肤与动态资源边界

当前 WPF 图鉴与牌桌使用静态 PNG 立绘。`GeneralArt` 和皮肤目录选择本地图像，图鉴详情显示皮肤原名并允许切换，选择保存在本机偏好。图片按需解码与缓存，界面不加载 Spine 骨骼、atlas 动画或动态皮肤视频。

## 名称与资源身份

皮肤名、人物名、外部皮肤编号与品质属于不同字段。本地 [立绘目录](general-art-catalog.json) 保存已核实的皮肤名称、来源、图像尺寸和哈希；[图鉴素材目录](gallery-ui-assets.json) 保存卡框、徽章等界面资源。皮肤切换只替换图片，不切换武将技能版本。

外部皮肤的品质和动态属性需要明确的产品线与版本来源，本地没有通用品质分级或真实动态播放开关。不能根据名字、立绘配色或其他版本公告推断当前皮肤品质。

## 素材形态

公开网页资源可能把同一外部编号分别组织为静态图片和动态人物／背景骨骼文件。JSON、atlas 与纹理需要对应渲染运行时、合成和生命周期支持，不能直接作为 WPF 位图播放。当前交付目录与界面均按静态素材处理。

来源、同步工具和隐私规则见 [武将图鉴](../GENERAL_GALLERY.md)；音乐与配音的目录绑定独立于立绘播放，见 [资源结构](../RESOURCE_CATALOG_DESIGN.md)。
