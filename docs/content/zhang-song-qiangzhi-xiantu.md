# 张松 / 界张松实现核对

2026-09-27 对照[移动版张松](https://www.sanguosha.cn/pc/hero-detail-179.html)、[OL 界张松](https://www.sanguosha.com/hero/753)和用户提供的[规则集使用流程](https://gltjk.com/sanguosha/rules/flow/use.html)。规则集网页保留历史规则；界限突破文本以对应官方武将页为准。

| 技能 | 当前实现 |
| --- | --- |
| 经典强识 | 出牌阶段开始，随机公开其他角色的一张手牌，牌仍在原手牌区；自己的本回合使用同类别牌时可摸一张。绑定 cardUseCommitted，每张牌一次。 |
| 界强识 | 私密观看目标手牌、自选公开一张；自己的本出牌阶段使用同类别牌时可摸一张。绑定 cardUseCommitted，阶段结束清除类别。 |
| 经典献图 | 其他角色出牌阶段开始，可摸两张，再从自己的手牌或装备中选两张交给该角色；其本阶段没有击杀时，在出牌阶段结束、进入弃牌阶段前失去一点体力。 |
| 界献图 | 可选摸一张或两张，再自选等量牌交给该角色；按实际选出的数量设置阈值，本阶段伤害不足阈值时，在出牌阶段结束失去一点体力。 |

这次修复的错误：装备没有强识摸牌窗口；桃和酒没有通用用牌窗口；多目标杀在逐目标窗口触发强识可能重复摸牌；界强识错误延长到整个回合；献图强制交出刚摸的牌；献图处罚延迟到回合结束。

界强识的搜索缓存曾显示“使用后”，但本次直接读取官方页面原始 HTML 为“使用时”，因此按当前原始页面接入使用时窗口。公共 cardUseCompleted 仍独立保留，并通过无关人物的通用场景验证。

共用实现位于 GameEngine.CardUseLifecycle.cs、GameEngine.CardActions.cs 和 GameEngine.ProgramLifecycle.cs。技能配置没有人物专用执行器。装备先进入装备区再进入使用窗口；装备主动效果、重铸不会冒充装备牌使用。普通桃酒的用牌程序可以暂停，濒死救援父流程等待救援牌的全部窗口完成。

选择原有牌复用 selectOwnedCards 和 moveBoundCards；界献图通过公共绑定牌数条件记录实际交牌数量。选择牌的过程不移牌，不向其他角色公开整个手牌；公开展示只公开最后选中的一张。

引擎规则版本为 175，schema 62，武将内容包为 standard-classic-generals@1.145.0；本次修改了事件顺序和可恢复暂停点，旧开发检查点按已有严格版本规则失效。

验证包含两版强识的装备替换、发动/跳过、私密选择和暂停回放、类别不符不触发、阶段/回合期限；献图选择原有牌、分支数量和出牌阶段结束时扣血。独立公共窗口场景覆盖基本牌、装备、普通/延时锦囊、多目标杀、濒死桃/酒，以及外层杀触发技能失血后嵌套桃救援的续接。定向通过不代表全库迁移检查全部通过。

两版官方立绘随本次内容接入，原始 URL、像素尺寸和 SHA-256 记录在来源清单和 general-art-catalog.json。独立提交副本可编译整个解决方案并通过武将立绘选择/保存测试，不依赖工作区未提交的徐盛内容。

仍需统一的接口边界见[公共时机与规则集对照](../CARD_LIFECYCLE_CONTRACT.md)。尤其不能把 cardResponseAccepted 一律解释成规则中的“使用”：杀响应决斗属于打出，而闪和无懈响应还需要更细的使用语义适配；本次未声称覆盖所有虚拟牌与响应使用路径。
