# 内容侧卡牌移动契约

每张实体牌由牌区存储维护唯一位置。内容操作使用统一移动入口和类型化原因，不通过 UI、宿主通知或私有集合直接改牌区。共享生命周期见[卡牌生命周期合同](../CARD_LIFECYCLE_CONTRACT.md)。

## 实体与区域

内容 ID 标识定义，实体 ID 标识本局中的牌。有效牌型、转换来源和物理牌面分别保存，实体移动不会重建或复制牌。

基础区域包括摸牌堆、手牌、处理区、弃牌堆、装备区、判定区与移出游戏。人物拥有的公开/私有牌堆使用已注册区域及其专门生命周期；不能仅凭“所有牌”将其并入普通三区。装备子槽位和替换规则由核心处理。

## 原子移动

- 单张、同源批量及多来源 `MoveBatch` 在生效前验证完整来源、目标、重复 ID、所有者和槽位；非法移动不产生部分结果。
- 已提交边界保持牌总数与实体唯一位置。处理中材料在实际付款/使用时进入；零实体动作的材料为空，不制造移动。
- 移动账本记录真实实体、来源、目的地、原因和原生因果身份。`CardMoveReason` 不使用 UI 文案作为规则标识。
- 父结算材料被合法申领时，只移动仍在该动作允许来源的实体。父动作继续完成，并跳过已经离开的材料清理。

## 移动事实与触发

真实使用、打出、弃置、获得、置入装备区、牌堆重排和特殊牌区清理具有不同语义。条件使用原生生产入口的事实与明确目的区，不能由相邻移动或同一实体 ID 推断一次不存在的弃置/用牌。

一次语义摸牌或整区弃牌可能包含多个原子移动；按整次调用触发的技能需要对应调用证明，按每牌或每批触发的技能使用各自真实粒度。

移动会开启装备离场、获牌、回复、伤害、濒死或死亡等子窗口。需要这些后果完成后才能继续的操作保留其原生收据和类型化返回；不能把 `MoveBatch` 完成等同于全部规则后果完成。

## 私有信息

自己的牌候选可以包含已授权牌面。其他角色的暗手牌使用不透明牌位和允许的数量；公开装备与判定区牌才可在允许场景用精确公开身份。可信宿主的全移动账本、牌堆顺序和随机种子不进入普通玩家视图。

私有看牌、整手牌展示和公开移动分别声明可见性。绑定的实体来源也不等于有权把该实体牌面投影给所有人。所有外露集合在提交准备阶段冻结。

## 程序绑定与恢复

具名绑定保存实际实体及冻结来源；消费时检查当前位置、原发票和是否已经消费。跨区移动、装备替换和木牛流马粮清理等子批需要准确匹配原支付批次，另一批相同实体不能冒充本次成本。

付款状态与返回点属于其拥有帧。命令前缀恢复重建相同选择、移动、原生子链和账本，已完成成本只结算一次。程序字段与选择/移动合同见[牌绑定与区域](skill-composition/RUNTIME_MOVEMENT_AND_ZONES.md)。
