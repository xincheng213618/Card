## 现行规则要点

隘守在结束阶段可摸等于体力上限数量的牌并将这些牌标记为隘；准备阶段弃置自己手中的隘，实际以此法弃置的数量大于当前体力值时加一点体力上限；自己的回合外失去最后一张隘时减一点体力上限。

扫围在其他角色使用的杀完整结算之后检查原目标：目标须不是桥蕤，并在桥蕤的攻击范围内。桥蕤可将一张隘当杀对目标使用；这次杀实际造成伤害时获得该牌。其效果包含真实用牌、原生目标和应答以及造成伤害后的原实体获取。

## 仓库实现与解释边界

以下是工程上的明确解释，未将其包装为官方专项 FAQ：

- 隘绑定本次摸牌实际进入桥蕤手牌的原实体和入手移动序号。替代摸牌未实际进入手牌的实体不标记；标记在该实体离开本次桥蕤手牌持有后解除。扫围取得原实体不会自动重新发放隘标记，也不为未来持有者保留永久标签。
- 准备阶段通过原生逻辑弃牌支付所有当前可弃置的手中隘，以完成的逻辑弃牌凭证计算数量，随后与结算时实际体力值比较；不可弃置牌遵守原生限制。体力上限通过既有原生修改方法改变，并继续其健康变化子窗。
- 回合外最后标记失去使用实际整回合所属角色和原子移动批次。按移动批次前后的精确标记持有历史确认最后一张真正离手，不以“手牌变空”替代，也不在同批多张离手时重复减体力上限。
- 扫围按原杀整牌结算的一次机会处理，保留其完整实际目标集合。桥蕤可选择其中当前在本人攻击范围内、非本人且满足本人原生杀目标资格的非空组，遵守本人当前目标数能力；不借用原使用者的多目标权限，也不要求原杀所有目标均在桥蕤范围内。目前未找到官方专门说明多目标杀的 FAQ。
- 材料、最终目标、用牌限制、武器与原生杀的逐目标效果均通过已有真实用牌子树执行。伤害判定绑定这次原生 Use 的实际正伤害事件，原实体仍可从结算处理区或弃牌堆取得时才获取；已被其他原生效果取得的实体不复制、不替换成牌堆新牌。
- 新的支付和暂停状态保留在原技能帧，摸牌和原生 Use 使用有类型的返回；卡牌移动、后置观察、健康变化、冷恢复与命令重放沿用既有引擎边界。
