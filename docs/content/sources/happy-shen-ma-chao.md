# 欢乐三国杀神马超：与周年版等价收录

核对日期：2026-10-23。欢乐三国杀的“狩骊／横骛”神马超与当前已收录的 `anniversary:shen-ma-chao` 规则相同，归入同玩法的产品来源与形象记录，不另建 `happy:shen-ma-chao` 可玩定义。移动版 `mobile:shen-ma-chao` 的“驭雳／霆威／寂灭”是另一套规则，继续独立保留。

## 逐项规则对照

以下各项在欢乐一手介绍、现行二级全文和周年现行官方正文之间相同。两技能均无额外主动弃牌、标记或体力成本。

| 项目 | 两产品相同的规则 |
| --- | --- |
| 初始属性 | 神势力、男性、初始4体力／上限4。欢乐静态属性依据上列同产品二级资料。 |
| 狩骊开局 | 从自己的下家开始，所有角色依次随机使用当时牌堆中的一张坐骑。使用的是真实坐骑，保持原生使用、替换及后续触发。 |
| 狩骊转换 | 以场上的一张进攻坐骑转化为杀，或一张防御坐骑转化为闪，用于规则允许的使用或打出。杀不计使用次数，没有额外授予无视距离。 |
| 转换材料与区域 | 消耗被选中的真实坐骑实体；场上包括装备区及判定区，不把暗手牌坐骑纳入场上材料池。横骛的装备计数则只取装备区。 |
| 借用其他角色坐骑 | 原持有人是其他角色时，该角色本实际回合非锁定技失效；自己和该角色本实际回合受到的伤害增加1，并转为雷电性质。 |
| 使用自己的坐骑 | 现行文字限定失去坐骑的“其他角色”，所以消耗自己的坐骑不发行上述失效及受伤惩罚。 |
| 横骛触发 | 自己真实使用或打出牌时，检查当前手牌中是否仍有与该牌有效花色相同的牌；没有时可发动。 |
| 横骛数量 | 按当时场上同花色装备数量摸牌，不统计判定区，不凭空设最低摸一张。 |
| 持续与次数 | 借马的失效和伤害效果属于当前实际回合；没有额外每阶段次数限制，也没有以来源失技为提前终止条件。 |

因此现有周年的 `DealShouliStartingMounts`、`fieldMountConversion` 和 `DrawHengwuFieldSuitEquipment` 已覆盖所需行为，包含原帧实体付款、实际座次、原生摸牌子流程与恢复返回。等价收录无需新效果运算、运行时分支或重复人物专项。

移动版[正式人物页657](https://www.sanguosha.cn/pc/hero-detail-657.html)则使用雷电伤害转换／防止、霆标记及按体力上限造成伤害的三技能设计，与本条无关，不能仅因同名和4体力而合并。
