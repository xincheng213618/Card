# 欢乐三国杀·神关羽

`happy:shen-guan-yu`，欢乐规则 `sanguosha-happy` / `happy-god`，神势力、男，初始与上限体力均为 5。

## 来源与版本

- **正式运营的一手证据**：[欢乐官网《1月21日活动公告》](https://www.xhlsgs.com/news/detail/53)，2023-01-21，神关羽列入正式小猫钓鱼武将奖池；[《3月25日活动公告》](https://www.xhlsgs.com/news/detail/64)，2023-03-25，同样列入神关羽。公告确认同产品正式武将，不提供完整技能。
- **当前完整实装辅助证据**：[墨染空濛《欢乐三国杀神武将技能及获取方式一览》](https://www.bilibili.com/opus/801083728217505844)，标注更新至 2026-09-23，神关羽段明确 5/5、红桃手牌可当杀使用或打出、红桃杀无距离且伤害加一、武魂脱离濒死及阵亡两个时机、判定失败失去五点体力。
- **同产品辅助交叉核对**：[欢乐 BWIKI《神关羽》](https://wiki.biligame.com/hsgs/%E7%A5%9E%E5%85%B3%E7%BE%BD)，列出男、神、5 体力与相同的当前技能。武神没有锁定技字样，武魂有锁定技。
- **历史文本区别**：[2021 年欢乐武将制图汇总](https://www.bilibili.com/opus/505608661102228857) 曾写武神锁定、判定失败直接死亡；它不是当前规则，不能覆盖上述当前同产品全文。

未找到载有当前全技能正文的官网修改公告，因此正式存在与完整规则分别注明一手及辅助证据，不将玩家图鉴冒称官方技能公告或 FAQ。

## 完整规则

**武神**：红桃手牌可以当普通杀使用或打出，保留原牌本来合法的用法；不强制变更牌名，不包含装备区红桃牌。使用红桃杀无距离限制并且伤害加一。后半句适用于实际使用的红桃普通杀、火杀和雷杀，不增加使用次数。

**武魂**：锁定技，每受到一点伤害给伤害来源一个梦魇标记。自己脱离濒死状态或阵亡时，选择拥有最多梦魇的一名其他存活角色进行原生判定；同为最多时由自己选择。判定牌不是桃或桃园结义则该角色失去五点体力，可能再次进入濒死及正常救援，不能把它替换成直接死亡。正文没有技能额外清除梦魇的步骤，脱离濒死结算后保留标记；最终阵亡后仍遵循项目既有的来源归属标记共用清理，不据正文省略步骤推导阵亡清理豁免。

与经典、OL、移动原版的“仅阵亡后判定、失败直接死亡”不同；也不采用十周年当前的双向积累梦魇或红桃杀不限次数、造成伤害后摸牌。

## 实现边界

手牌红桃转换使用既有自愿 viewAs，距离使用既有按花色的杀策略；伤害加一在原生伤害修正点读取真实使用动作的有效花色、杀牌名及当前有效武神来源，不增益无牌伤害或属性连环的二次传播。

两个武魂结算共用既有单目标选择、公开判定及条件失去体力指令；判定原生返回后，结果牌由公开绑定保留在处理中，结算末以既有 `moveBoundCards` 实际置入弃牌堆并消费绑定，沿用恢拓等判定技能的清理合同。不建立人物旁路待办或虚拟直接死亡。新增“最多归属标记的其他角色”目标类型保留原有归属语义，并明确排除自己，旧目标类型不改变。脱离濒死窗口复用原生已完成濒死的类型化返回，核对原始父帧、当前候选、实际回合与唯一存活离濒死事实。新增逻辑没有公开私有候选集合，不额外清除梦魇；技能完成后原生阵亡流程仍按共用合同清理该阵亡来源的标记。

聚合行为检查覆盖红桃手牌的自愿转换、装备排除、真实无距离红桃杀加一、真实伤害积累梦魇，以及脱离濒死和阵亡的原生判定/五点体力损失与代表性冷恢复；不复制既有配置快照、改判或救援组合矩阵。
