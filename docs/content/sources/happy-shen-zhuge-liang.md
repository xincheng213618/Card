# 欢乐三国杀·神诸葛亮

身份：`happy:shen-zhuge-liang`，`sanguosha-happy` / `happy-god`，神势力，男，初始体力/上限 3/3。独立于 OL、移动版的狂风加火伤及大雾多人防伤规则。

## 采用的完整规则

- **七星**：锁定技，游戏开始时额外摸七张牌，选择七张手牌置为私有“星”；摸牌阶段结束时，可以用任意张手牌交换等量“星”。零张交换以跳过表示。
- **狂风**：出牌阶段结束时，可以移去任意张星，对等量角色各造成一点普通伤害。目标可含自身，按当前正文的“角色”处理；选定目标数与实际选择星数严格相等。移星先真实完成，再结算原生逐目标伤害，不视为火杀、不附加火焰伤害标记。
- **大雾**：结束阶段，可以移去一张星，直到自己的下个实际回合开始，自己受到的普通伤害减一。火焰、雷电等属性伤害不减；大于一点的普通伤害只减一点，并非完全防止。已经发行的延期效果持续到期限，失去原技能不提前撤销。相同来源的重复授予刷新期限，不叠加成多点减伤。

## 实现及复用

七星直接组合现有原生摸牌、私有手牌选择、单批私有牌堆移动及等量换星。额外七张先真实进入手牌并结算获得子效果，然后从当下手牌选择七张；不以直接放置牌堆顶七张代替。私有星沿用 `PrivateReserve` 的拥有者可见投影，其他玩家仅看到数量。

狂风组合原有选星、等量目标集合、等待实体移动完成、逐目标伤害及类型化伤害返回；没有新建旁路待决对象。大雾唯一新增操作复用现有公开布尔状态与 `NextOwnerTurnStart` 期限；只读已发行的真实来源 lease 提供普通伤害 -1。付款核对原技能帧、原 Ending 绑定、被选星原位置以及该绑定开始后的真实移牌事实，恢复不重复移星或授予。

聚合定向检查覆盖七星初始选牌及已付移动的恢复、等量换星、狂风真实星数与目标伤害，以及大雾一星付款、普通/属性伤害差别和下个实际回合开始的期限。其余原生选择、私有牌区、伤害返回机制由既有共享检查覆盖，不复制人物配置快照或跨技能矩阵。
