# 夏侯恩（一将成名／原十周年）

采用 `anniversary:xiahou-en`、`sanguosha-anniversary`、`anniversary`，魏势力、男、5 体力。称号为“乌禾同仓”，扩展包为“无双上将”，不把包名写作称号。全仓已有内容、运行代码、测试和来源文档（包括未跟踪文件）核对后，没有相同“持剑／恃武”的夏侯恩实现。

## 正式来源

- [OL 限时地主夏侯恩公告](https://sanguosha.com/news/20250226_6989_0415)：另一产品的 4 体力引锋／负掳，与本页两技不同，不作为本实现的规则来源。

持剑为锁定技：出牌阶段杀次数加一；装备区没有武器牌时视为装备青釭剑。使用现有虚拟装备规则读取青釭剑的无视防具能力，并提供真实攻击范围 2；不生成可以被移动、弃置或获得的假实体武器。有实际武器牌时按该武器处理。技能由其他角色获得后同样生效，不能只按夏侯恩的武将 ID 判断。

恃武在其他角色的实际回合开始可视为对其使用决斗。原生决斗保留真实使用、目标确认、无懈、打出杀、伤害、濒死、死亡和清理后的返回。自己对该角色实际造成伤害时，从牌堆取得一张伤害牌；该角色对自己实际造成伤害时，对方获得持剑，自己失去持剑直到该实际回合结束。防止伤害、转移给第三者、随后无关使用的伤害，不能代替该决斗的双方实际伤害。牌堆没有伤害牌时不会凭空生成牌，也不从弃牌堆补足。

正式原句的期限位置为“其获得‘持剑’，你失去‘持剑’直至其回合结束”。这里把期限只作用于自身失去，受益者获得持剑不附期限；杀死自己的角色获得持剑也不附期限。这是按当前官方正文语法作出的执行解释，尚未找到进一步官方 FAQ 或客户端实测来独立证明，不冒称官方详细裁定。独立来源授技不会因为此前已持有相同技能而叠加杀次数；回合结束只恢复本次实际移除、仍有有效来源的自身持剑，不移除对方永久来源。

实际回合开始包括翻面跳过阶段前的真正回合入口；恢复依精确实际回合结束事实，不以结束阶段代替。原决斗和获得的待处理状态均留在拥有它的程序帧，冷恢复不重复发行决斗或再次取得牌。公开自定义回执只记录公开角色、使用和伤害身份以及获得数量，不公开从牌堆取得的隐藏实体 ID。
