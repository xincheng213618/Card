## 当前正式技能

**归心**：当你受到1点伤害后，你可以获得每名其他角色区域里的一张牌，然后你翻面。

**飞影**：锁定技，其他角色计算与你的距离+1。

## 规则与版本边界

当前移动版归心没有“随机”二字。仓库现有 `classic:guixin` 是从其他角色所有区域牌中随机取一张；不能仅换 ID 便当作本版本。移动版按本次技能开始时的真实席次冻结其他角色顺序，逐人从当前合法的手牌、装备、判定区选择一张获得；暗手牌仅公布牌位，公开装备与判定牌可直接选择，没有合法区域牌或已死亡的角色跳过。每次支付都走真实原生卡牌移动，并等该次移动的子结算返回，再访问下一人；全部完成后才按原生语义翻面，暗置者会翻回正面。每点实际伤害的可选发动机会由既有 `perDamagePoint` 原生窗口独立提供，不把两点伤害合成一次发动。

飞影直接复用 `incomingDistance +1`，不改变神曹操计算与其他角色的距离。

[2016-12-13 OL 2.83 正式调整公告](https://www.sanguosha.com/news/20161207_6342_3611)另行明确“随机”，以及一次选择优先区域、缺牌时按优先级回退。该公告属于 OL，不用于覆盖当前移动版正文；本内容也不采用山河活动中随机获得整区域所有牌的归心。

新指令仅组合原生牌位选择、卡移动、卡移动子窗与翻面。私有实体支付回执和冻结席次均在原 `ProgramSkillFrame` 上；公共自定义事件仅含标量来源、席次、批次和计数，不包含暗手牌 ID 或 RNG 状态。定向检查覆盖公开装备/判定牌选择、暗手牌位、两点伤害独立发动、中间已付款获得子窗的冷恢复与命令重放，不添加重复定义快照或组合矩阵。
