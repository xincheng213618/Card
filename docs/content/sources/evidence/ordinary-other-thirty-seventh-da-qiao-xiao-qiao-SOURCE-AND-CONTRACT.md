# 大乔小乔的来源与当前边界

保留的[普通 OL 武将页](https://www.sanguosha.com/hero/117)及实际 API 提供吴势力、基础三体力和星舞、落雁主文。`initial_hp: 0` 是占位；API 没有性别字段，女性身份属于人物传记的语义依据。

星舞主文包括弃牌阶段置牌、移去三张星舞或翻面并弃两张手牌，再弃目标装备并按性别造成伤害。落雁在有星舞牌时提供天香和流离；页面关联技能引用为对应数字标记，并非同号武将 URL。

当前人物目录提供独立经典大乔、经典小乔和界小乔，未登记大乔小乔的完整人物。现有同名天香/流离不能自动证明本条落雁应授予的具体版本，也不能据此声明星舞牌堆、费用及派生行为已经实现。

原始页面、API、素材与关联来源记录保持各自证据等级。规则产品线、来源完整性与工程默认的区分见[来源规范](../../BWIKI_CONTENT_BACKLOG.md)。
