# 周年服张横

核对日期：2026-10-24。群，男，8体力，称号“戾鹘枭鹰”，扩展包“文和乱武”。

- [当前官网武将页](https://x.sanguosha.com/hero/608.html)：粮绝按每张黑色牌进出本人判定区、装备区触发，先摸两张牌，再判断当前体力值是否大于一以失去一点体力；挡灾在出牌阶段开始时选择另一名角色，将其判定区的任意张牌移入本人判定区。
- [正式可获得公告](https://www.sanguosha.com/news/20210824_4121_4915)：2021-09-06发布，2021-09-07更新后公会贡献商店增加张横宝箱，可概率获得永久武将张横；公告列明群、男、8体力及称号、扩展包。该公告的技能文字是首发旧版，不能代替当前规则。
- [2024-06-27正式平衡调整](https://www.sanguosha.com/news/20240624_3020_0118)：明确将粮绝从“体力大于一才先失去体力、再摸牌”改为每张先摸牌、再判断体力；挡灾从一张改为任意张。当前官网与这一修订一致。
- [官方经典形象](https://web.sanguosha.com/10/pc/res/assets/runtime/general/big/static/160801.png)。

粮绝复用原生逐牌移动、摸牌和失去体力指令。真实移动记录冻结两侧所见花色，来源区和目的区均按本人装备区、判定区核对；不把手牌或特殊堆移出作为粮绝。每个真实实体独立发行一次，两张同批黑牌需要两次摸二与两次动态体力判断。先等原生摸牌及其移动观察者返回，才判断是否失去体力；体力为一时仍摸两张且不自行失去体力。单个实体在本人两个场上区域之间的一次原生转移去重为一个移动机会，此点为按“每有一张”作出的执行解释，未声称为官方专项FAQ。

挡灾属于真实出牌阶段开始的原生父窗口。先选择另一名角色，再选择其当前判定区的合法实体子集，确认后以一个真实原子移动批次进入本人判定区，随后才结算粮绝等原生观察者。转移保留延时牌的实际判定名，按已有原生对应区转移资格检查判定区废除、已有同名牌、目标限制及琴等受支持实体。不能把原本无法移动的判定牌伪造成先丢弃后重新放置，也不克隆实体。

待选子集及已付移动状态保存在原技能帧，集合冻结。冷恢复保持原阶段父、原来源角色与同一批实体，不重复移动，不重付摸牌或体力费用。没有新增全局玩法版本、checkpoint版本或内容包版本。
