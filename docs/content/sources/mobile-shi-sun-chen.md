# 势孙綝：正式来源与执行口径

核验日期：2026-10-24。武将为吴势力、男性、4体力，区别于其他版本的孙綝。

- [三国杀移动版正式武将页 660](https://www.sanguosha.cn/pc/hero-detail-660.html)：逆固与戮连的当前正式技能描述。
- [移动版 BWIKI 势孙綝](https://wiki.biligame.com/msgs/%E5%8A%BF%E5%AD%99%E7%B6%9D)：页面标记 2026-10-01 更新，核对性别、势力、体力和两技能。
- [BWIKI 逆固](https://wiki.biligame.com/msgs/%E9%80%86%E5%9B%BA)、[BWIKI 戮连](https://wiki.biligame.com/msgs/%E6%88%AE%E8%BF%9E)：交叉核对技能。
- [BWIKI 技能概念介绍：乘势](https://wiki.biligame.com/msgs/%E4%B9%98%E5%8A%BF)：所有分支条件满足时，完成分支效果后强制执行乘势。

逆固在每个实际出牌阶段可发动一次。先多选不同花色的手牌或装备牌，并在确认后支付一次原生逻辑弃牌；“任意张”按包含零张处理，这是对未规定正下限的执行解释。弃牌及其子结算完成后，冻结当时攻击范围内的其他存活角色。每个角色私下独立承诺是否交牌；全部承诺收齐后才公开，随后逐个由愿意交牌者选择自己的真实手牌或装备牌交入孙綝手牌区。不给或最终没有成功交入的角色计入 X；最后签发本实际回合接下来 X 次实际造成伤害各增加 1 的额度。未能实际造成正伤害不消耗额度，无来源伤害也不使用占位来源座号的额度；失去技能不撤销已签发额度，原实际回合结束后失效。额外实际出牌阶段的独立额度顺序消费，每次伤害至多消费一份。

戮连以正式页的“使用手牌结算后，若没有此类别的手牌”为准。BWIKI 概括为某类别最后一张，但实现不会在使用时预判为最后一张：原牌的全部效果、奖励和伤害结算完成后，才检查技能拥有者当前真实手牌中的基本、锦囊或装备类别。例如，无中生有结算中获得新的锦囊，便不因之前用出最后一张锦囊而触发戮连。好施授权的原物理手牌通过本次冻结授权票据证明使用资格；他人的手牌不计入孙綝自己的当前手牌类别。

按原生完成使用保存的真实目标分别判断两项存在条件，满足体力条件便使所有原目标连环，满足装备数条件便原生摸一张，两项可以由不同目标满足。两个条件都满足时，完成连环、摸牌及其子结算后，强制选择当前体力不为全场最低的一名存活角色造成 1 点火焰伤害。描述没有排除自己，故自己合法且不为最低时可选；并列最低均不能选，全场体力相同则没有合法乘势目标。针对杀使用闪、使用无懈可击沿既有 typed completed-response-use 边界识别，保留原 native parent；无角色目标时不虚构目标。决斗或南蛮中打出杀、万箭中打出闪仅是打出，不计为使用。

所有待续选择、支付游标、私下承诺与原生子结算均存于原结算帧，实际伤害额度的消费由原生 DamageApplied 正伤害事实证明；没有把额度替换成下一张杀的伤害增益。
