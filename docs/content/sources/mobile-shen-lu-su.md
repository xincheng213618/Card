# 神鲁肃：移动版正式版

核对日期：2026-10-22。`mobile:shen-lu-su`，`rulesetId=sanguosha-mobile`，`variantId=mobile-god`，男性神势力、3体力。

[大陆移动版当前官方武将页](https://www.sanguosha.cn/pc/hero-detail-581.html)为主要来源。页面的 `ul.skill-info` 有三个 `li`：第二项带 `class="hide"` 的定州虽被正文阅读器漏掉，原 HTML 仍明确为“出牌阶段限一次，你交给一名角色X张牌（X为其场上牌的张数），然后你获得其场上的所有牌。”X不加一，没有欢乐版的第二选项。

榻谟的身份场分支固定主公，只调整其余角色；斗地主分支固定三号位；团战分支可重排所有角色。智盟位于本人的真实回合结束后，身份场不限对方手牌数；斗地主、团战要求目标手牌数不大于本人手牌数加一。双方手牌随机平均分配，奇数时发动者多分一张。

[2025-02-27 台湾移动版正式上线公告](https://www.sanguosha.com.tw/newsinfo_1212.html)另列3体力及身份场三技能，定州的X同样等于场上牌数。此公告仅交叉印证大陆当前页，不将地区或模式分支混成另一个版本。2024公测论坛中的X加一与当前两处官方正文不同，未采用。

场上牌指装备区与判定区；“交给”使用本人的手牌、装备牌，目标为其他角色，符合官方当前页“给他人牌获得其区域牌”的玩法说明。定州先完成真实等量交牌及其子窗口，再获得届时目标场上的所有牌。智盟冻结双方实际手牌实体并使用引擎随机数一次决定分配，只有改变持有者的实体进入同一原生移动批次，不公开随机后各人的隐藏牌名。

榻谟沿用真实TableOrder和既有TableSeatMovedEvent，参与者Seat与身份不变；距离、下一行动者及公开座次均读取同一原生顺序。运行中的选择、实际支付与移动回执保存在原ProgramSkillFrame，并沿用typed return与内容哈希边界。版本、规则格式及内容包版本不因本将提高。

身份模式采用身份分支，普通Team模式采用团战分支；Boss、虎牢、神武、年兽、地府、龙舟、官渡、文和及带特殊TeamActivity的模式不自动视为普通团战。目前引擎没有斗地主模式，因此保留其官方文本作为出处说明，不伪称已支持该模式。团战重排同时改变真实公开首位，并仅在完整原生GameStarting父窗口返回后设置首个行动者；不在仍结算其他开局技能时更换窗口所属者。

随机分配的逐卡去向、原持有人及支付实体只保存在原程序帧的冻结私有回执中；新增公共事件只报告目标、总数量、批次及序号区间，不携带隐藏牌ID或逐卡归属。实际手牌转移沿用原生背面移动披露。
