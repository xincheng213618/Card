# 神姜维（一将成名正式版）

产品线：《三国杀：一将成名》（原十周年），`sanguosha-anniversary` / `anniversary-god`；武将 `anniversary:shen-jiang-wei`。不采用手游“星魂、天涛、回天”版本或实体版九伐置牌版本。

官方来源：[一将成名官网武将详情：神姜维](https://x.sanguosha.com/hero/213.html)，核对日期 2026-10-22。页面“武将展示”在四组皮肤下重复刊载相同的“天任、九伐、平襄”完整正文；经典形象为默认立绘。

- **天任**：锁定技，基本牌或普通锦囊牌非因使用进入弃牌堆后，每张获得一个天任。标记达到体力上限时移除等量标记，增加1点体力上限并摸两张。
- **九伐**：每次使用或打出九张不同牌名后，可亮出牌堆顶九张，选择并获得其中每个重复点数的一张，其余弃置。
- **平襄**：限定技，出牌阶段可减9点体力上限，视为使用至多九张火杀，然后失去九伐，本局手牌上限改为体力上限。

规则实现遵循原生用牌/打出、实体移动、亮牌、摸牌与火杀结算。元素杀按【杀】的同一牌名计九伐；每轮九种牌名完成后清空，是否发动亮牌不影响下一轮。平襄须有大于9的体力上限以实际支付9点；每张火杀重新选择合法目标，可提前结束，遵守距离与禁止使用/目标规则，连续发行不受出牌阶段杀次数约束。失去九伐与持久手牌规则在连续火杀结束后应用。

天任的“使用”依据原生处理区付款、用牌清理与响应语义凭据区分；响应【杀】所使用的【闪】、【无懈可击】不计，决斗中打出的【杀】则计入。重铸、判定结算、亮牌剩余弃置等非使用移动按实际牌类别计数。九伐在真实用牌或打出完成时冻结牌名进度，先于同窗口的技能子结算，以保持原完成顺序。天任的摸牌、九伐的公开选牌及移动、平襄的每张火杀均保留在各自原所属帧，支付和原生返回分别有回执，恢复后不重新支付。
