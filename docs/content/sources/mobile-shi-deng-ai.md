# 势邓艾：正式来源与执行口径

核验日期：2026-10-24。本条目为移动版当前正式势邓艾，魏势力、男性、4体力，技能为屯田、凿险、急袭。

- [三国杀移动版正式武将页 643](https://www.sanguosha.cn/pc/hero-detail-643.html)：核对当前三个技能、蓄力初始值与上限均为零、凿险阈值 3/5/7，以及急袭的一张多目标顺手牵羊。
- [移动版 BWIKI 势邓艾](https://wiki.biligame.com/msgs/%E5%8A%BF%E9%82%93%E8%89%BE)：页面标记 2026-09-23 更新，补足屯田每失去一张非伤害牌分别获得蓄力、红桃牌可来自牌堆或弃牌堆，以及当前性别、势力与体力。
- [BWIKI 武将修改记录：兵势篇](https://wiki.biligame.com/msgs/%E6%AD%A6%E5%B0%86%E4%BF%AE%E6%94%B9%E7%9B%B8%E5%85%B3%E8%AE%B0%E5%BD%95%E9%A1%B5%E9%9D%A2%EF%BC%88%E5%85%B5%E5%8A%BF%E7%AF%87%EF%BC%89#%E5%8A%BF%E9%82%93%E8%89%BE)：早期爆料的凿险阈值是 2/4/6，急袭目标数曾受蓄力上限约束；正式版改为 3/5/7 并解除该人数限制。本条目采用当前正式版，不使用峥嵘废案或早期爆料。
- [官网原画 86100.jpg](https://www.sanguosha.cn/storage/uploads/images/86100.jpg)：使用 `mobile-shi-deng-ai` 肖像键。

屯田的蓄力按技能拥有者分别记录，初始为 0/0。真实失牌批次只进入一次处理流程，但批内每张符合条件的非伤害牌分别提供 1 点蓄力，累计不超过当时上限；不会把混合手牌、装备与判定区的一次失牌重复处理，也不会把多张合并误算成只增加 1 点。获得牌、区域内未实际失去的牌不增加蓄力。伤害牌按既有伤害牌类别判断，不以该牌本次是否实际造成伤害替代类别。

原生使用自己手中的装备时，手牌到处理中、处理中到自己的装备区可能分属不同真实移动批次。原用牌帧冻结精确付款序列、实体、原区域、用牌及技能来源；在该用牌终结时，凭同一用牌的真实落装与装备变更事实区分内部转区和实际失牌。成功落入自己装备区不增加蓄力；未完成自身落装而实际失去该实体时只结算一次。普通失牌仅排除这笔精确原生付款，不按实体永久排除，也不以之后的最终所在地或独立取回抹掉先前失牌；旧装备被替换弃置仍按其自己的真实移动结算。

每个实际出牌阶段可发动一次屯田，选择消耗点数和至多等量名存活角色，确认后只支付一次；“任意点”按允许零点处理，零点时不指定获得牌的角色。每名接收者分别从当时牌堆和弃牌堆里的红桃实体中随机获得一张，候选为空则该名角色没有获得牌；这属于指定花色获得，不作为普通摸牌，也不为搜索主动重洗牌堆。随机结果与付款、游标存于原结算帧，恢复不重复随机或扣费。任意角色的实际回合开始时，按当时是否蓄满决定屯田的摸一张与上限增加效果；0/0 也属于蓄满。

凿险按单次实际消耗的蓄力数判断，而非历史累计消耗。3、5、7 三个条件独立且累加：一次消耗达到 7 点时依次尝试从弃牌堆获得无中生有、无懈可击、五谷丰登各一张；对应牌不存在则该项没有获得。原消耗帧冻结本次凿险来源与阈值，已支付的消耗及其奖励在原帧完成。

急袭的历史范围是当前实际回合内，技能拥有者使用牌时真实指定过的其他角色；按原生用牌的有效目标事实记录，打出牌不虚构使用目标。回合结束时，可选择弃置当前回合角色的一张真实区域牌，再从合格且仍可作为顺手牵羊目标的其他角色中选取任意名。支付弃牌及其子结算完成后，签发同一张无实体、无距离限制的顺手牵羊，全部目标保存在同一原生用牌帧，逐目标执行原生无懈、选牌、获得与完整用牌返回。目标人数不受蓄力点数或蓄力上限限制；没有牌可获得、用牌禁令等原生目标限制仍然生效。

公开进度以屯田的当前蓄力数和上限、急袭本回合可选目标数展示；牌堆候选、随机内部状态和私下选牌不会作为技能进度公开。
