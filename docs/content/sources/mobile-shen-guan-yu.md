## 当前正式技能

**武神**：锁定技，你的红桃手牌只能当做【杀】；你使用红桃【杀】无距离限制。

**武魂**：锁定技，当你受到1点伤害后，你令伤害来源获得1枚梦魇标记；当你死亡时，你令拥有最多该标记的一名其他角色进行判定，若结果不为【桃】或【桃园结义】，则该角色死亡。

## 实现与版本边界

本版本与仓库经典版的上述原生规则一致，使用独立移动版武神、武魂 ID。武神复用强制手牌身份，使红桃手牌只能作为杀使用或打出，保留原生的每阶段杀次数约束；距离使用该红桃身份的无限距离贡献。没有照搬仓库 OL 武神的红桃杀无限次数、不可响应两项额外政策。

武魂复用既有归属梦魇标记及原生死亡窗口：每点实际伤害分别给伤害来源记一枚，在致死伤害进入濒死之前保留该次真实伤害的标记；死亡时从持有本来源归属梦魇最多的存活其他角色中选择，进行真实判定，只有判定结果不是桃或桃园结义才进入原生直接死亡。无伤害来源不制造梦魇持有者；没有归属标记者没有虚构的判定目标。标记归属、判定实体、改判、死亡子结算与冷恢复均沿用既有机制。

本批人物只增加三份内容 JSON，复用现有 loader、注册、强制牌身份、归属公开标记和死亡判定检查，不新增运行时机制、专属 pending、枚举或重复人物测试矩阵。既有地狱模式的武魂直接死亡返祖证明同时识别 `mobile:wuhun`；原始死亡、原候选与绑定、判定结果、直接死亡与实体付款证明保持原协议。
