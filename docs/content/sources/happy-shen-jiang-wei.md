# 欢乐神姜维：与周年版等价收录

核对日期：2026-10-23。产品线为《欢乐三国杀》。本条记录正式开放证据、当前规则及原画来源；规则等价于已实现的 `anniversary:shen-jiang-wei`，不新增可玩 ID、技能实例、Runtime 或重复专项。本文不把周年官网当成欢乐产品的官方技能公告。

## 来源及证据层级

- **欢乐官方正式开放证据**：[2024年6月8日活动公告](https://xhlsgs.com/news/detail/150)，发布于2024-06-08；6月8日至14日小猫钓鱼奖池列出神姜维，并明确350端午锦鲤可兑换。由此可确认当时已正式实装，不能据此称该日为首发日。
- **较近的欢乐官方开放记录**：[8月29日九月开学季活动公告](https://www.xhlsgs.com/news/detail/291)，发布于2026-08-28；8月29日至9月4日仍列神姜维为正式奖池武将，350活动锦鲤可兑换。该公告的技能加强对象是神庞统，不是神姜维。
- **欢乐完整规则，二级资料**：[欢乐三国杀神武将技能及获取方式一览](https://www.bilibili.com/opus/801083728217505844)，正文标明更新至2026-09-23；神姜维段落给出4/4及天任、九伐、平襄三项完整规则。该文为玩家整理，不能标成欢乐官方全文或官方FAQ。
- **静态属性交叉补证，二级资料**：[欢乐三国杀BWIKI：神姜维](https://wiki.biligame.com/hsgs/%E7%A5%9E%E5%A7%9C%E7%BB%B4)，页面更新日期2025-06-21，列男性、神势力、4体力及相同三技能。欢乐活动公告不提供完整体力、性别元数据，故这两项仍明确采用二级补证。
- **周年对应版的一手全文**：[一将成名官网神姜维详情213](https://x.sanguosha.com/hero/213.html)，经典形象及其他皮肤下均列天任、九伐、平襄；与上述欢乐合集逐项一致。对应仓库来源说明为[周年神姜维](anniversary-shen-jiang-wei.md)。

本轮未找到欢乐官网单独刊载的神姜维完整技能源或技能修订公告。正式奖池可证明存在，不能单独证明技能从未修改；“当前等价”的结论依据当前欢乐完整二级文本与周年官方文本的逐项比对，不把没有搜到公告当作没有修订的证明。

## 完整规则对照

以下按条件、费用、执行顺序和后续效果完整转述，不逐字转载技能正文。

| 项目 | 欢乐当前规则 | 周年现有规则与仓库落点 |
| --- | --- | --- |
| 静态体力 | 初始体力与体力上限均为4。 | 相同。 |
| 天任 | 锁定效果。基本牌或普通锦囊因“使用”以外的原因进入弃牌堆时，按牌获得天任标记。标记达到当前体力上限后，支付与该上限相同数量的标记，将体力上限增加1，再摸2张牌。 | 触发牌类别、非使用来源限制、达到阈值、扣标记、增加上限和摸牌均一致；不改成只计算本人弃牌，也不包括装备牌。 |
| 九伐 | 本人使用或打出牌，每累计九个不同牌名便可发动一次：公开牌堆顶九张；按重复点数分组，从每组选择一张获得，未被选择的亮出牌全部进入弃牌堆。 | 既计算使用也计算打出；累计九种牌名、可选发动、亮九张、每个重复点数取一张与剩余弃置均一致。不是实体版其他九伐规则。 |
| 平襄 | 游戏内限定一次，在出牌阶段可以支付9点体力上限；支付后连续视为使用火杀，最多九张。整段结束后失去九伐，并将本局手牌上限计算方式改为体力上限。 | 时机、限定次数、真实减上限费用、至多九次火杀、技能失去顺序和持久手牌规则均一致；不存在欢乐专属的另一套结算。 |

沿用周年已实现的原生规则解释：九伐按牌名归类，元素杀归入同一杀牌名；每完成一组九种牌名即开始新一组，拒绝亮牌不保留已完成的那组进度。天任依据真实用牌、打出与弃牌移动事实区分来源；平襄逐张选择当前合法目标，可提前结束，保留原生距离及禁止使用、禁止目标规则。上述执行解释不是本轮新增的欢乐官方FAQ。

移动版 `mobile:shen-jiang-wei` 不等价：[移动官网645](https://www.sanguosha.cn/pc/hero-detail-645.html)为星魂、天涛、神霈、回天，分别涉及顶牌交换和展示后实体杀、区域弃牌及失去体力、濒死回复并雷伤、额外回合与后续轮首死亡。不得借移动版四技能取代本条天任、九伐、平襄。

## 既有机制及收录边界

周年内容位于 `src/Characters/jiang-wei/anniversary-god/`。现有三个操作 `ResolveShenJiangWeiTianren`、`ResolveShenJiangWeiJiufa`、`ResolveShenJiangWeiPingxiang` 已承载全部本体规则：

- `Runtime/GameEngine.ShenJiangWei.cs` 的 `CaptureShenJwDiscardOrigins`、`CaptureShenJwCompletedName` 保存真实弃牌来源和已完成用牌、打出牌名；原帧继续处理阈值、原生摸牌、公开亮牌及选择移动。
- `Runtime/GameEngine.ShenJiangWei.Native.cs` 的 `IssueShenJwSlash`、`ReturnShenJwSlash`、`ReturnShenJwAttack` 保留平襄逐张原生火杀及类型化子返回。
- `Runtime/GameEngine.ShenJiangWei.Proofs.cs` 保留支付、实体移动、源实例和所属帧证明；不为等价产品另建 pending 或替代结算。

因此本轮只登记来源与等价关系，不新增内容定义、能力、版本号或人物行为检查。这里没有把周年技能ID自动改名成欢乐技能ID，现有静态组合校验保持原样。
