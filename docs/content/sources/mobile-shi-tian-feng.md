# 势田丰（移动版）

- 规则主来源：[三国杀移动版官网，势·田丰 623](https://www.sanguosha.cn/pc/hero-detail-623.html)，核实日期 2026-10-24。
- 官网原画：[84100.jpg](https://www.sanguosha.cn/storage/uploads/images/84100.jpg)，官网 DOM `heroInfo1` 使用同一原画，群势力。体力 3、男性；官网正文未单列体力/性别，移动版武将资料中的三枚勾玉与男性设定交叉核对。
- ID：`mobile:shi-tian-feng`；技能 `mobile:shi-ganggeng`、`mobile:shi-sijian`。

刚鲠按出牌阶段各限一次实现，使用已有多选手牌与单目标赠牌指令，不限制只能给两张。每次赠牌的受赠者在原生回合事件中记录；本回合结束时按当时所有存活角色的手牌数比较，并列最多也满足摸牌分支。否则田丰选择弃置受赠者手牌、装备区或判定区的一张合法牌，手牌保持不透明牌位。不同额外出牌阶段可以分别留下待结算的赠牌，结束时逐项结算。

死谏的失去最后手牌、进入濒死共用每回合两次额度。第一项为指定其他角色留下跨回合的下一次实际使用牌后弃牌义务；普通“打出”杀不消耗此义务，实际“使用”闪、无懈等响应计入。记录发出时已有的真实动作编号，不把已经开始的牌错误算作“下一张”。多项义务可在同一次下一使用后逐项结算；义务与结算凭据记录在规则事件中，选择与支付子状态留在其原始原生技能帧。

无人濒死时可选背水：依次执行选定其他角色的下次使用后弃牌、当前回合角色原生摸两张，再真正失去体力。累计次数在本次选择背水时递增，因此依次失去 1、2、3……点体力；此口径按官网“此技能发动过背水的次数”，不采用其他转载中的“此前背水次数”。次数不随回合重置。有人濒死时不提供背水选项，原有两个单项仍可发动。濒死与失去最后手牌入口共享额度。

界面显示两次额度、背水累计次数/下次失去体力数、未结算弃牌义务数与刚鲠待结算目标；已支付的原生摸牌/弃牌/失体力均保留在原帧后续阶段，保存恢复不会重复支付。
