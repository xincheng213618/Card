## 当前完整规则

**笃君**：游戏开始时，你选择一名其他角色，你不能响应其使用的牌。你与其每回合首次造成或受到伤害后，你可摸2张牌，然后将这些牌交给一名角色。

**济困**：每当你累计失去5张牌后，你可令一名其他角色随机获得手牌数最多的角色的1张牌。

## 执行口径

- 笃君游戏开始选人使用真实开局窗口和技能拥有者候选；公共开局窗口的 `SourceSeat` 不等同技能拥有者。选定关系绑定该真实技能实例。
- “你与其每回合首次造成或受到伤害”按两名角色各自的首次造成、首次受到分别处理，共四种资格。以实际伤害事件、实际回合及角色身份判首次，不按伤害点数触发，也不只计算夏侯徽自己的回合。跳过首次机会后，同回合后续伤害不会再补问；同一次双方相关的伤害可以各满足一项。
- 不能响应只针对所选角色实际使用的牌。原生闪、决斗杀及无懈链分别依当前真实用牌来源判断；反无懈以当前同一无懈窗口和链深的实际无懈响应者为来源。濒死救援用桃、酒不是对那张伤害牌的响应，不由该禁令排除。
- 摸2由原生 Draw 指令与实际摸牌回执结算，结果绑定本次实际实体；这些牌全部交给同一名角色，可以选择自己而保留。摸牌子效果已移走的实体不会用旧手牌替付；没有实际摸到牌时不制造交牌。交给其他人使用真实 Give 付款、移动批次及其原生子效果；冷恢复不重复摸牌或交牌。
- 济困“失去你的牌”复用项目原生手牌、装备区域口径，按真实实体移动张数累计，非按移动批次数、伤害次数或回合计数。手牌进入自己的装备区也是原手牌失去，判定区牌不计为“你的牌”。一批跨越多个五张阈值时，每个实际阈值独立保留机会；拒绝一次不会抹去累计数。
- 济困在实际选择时比较所有存活角色的手牌数，允许选择并列最多者；获得范围按“角色的一张牌”的通用 HE 口径，不包括判定区。受益者须为夏侯徽以外的角色，供牌者可以是夏侯徽。如果受益者本身也是最多手牌者，仅其可获得装备能形成 Equipment→自己的 Hand，不能把 Hand→同一 Hand 伪造为获得。这些区域细化属于沿用引擎通用所有权／获得语义的实现解释，不声称另有本将官方 FAQ。
- 随机候选、选中的实体及确定性 RNG 前后状态只保留于原技能帧私有回执；新增公共事件仅含来源身份、序号、数量、参与者等标量，不公开隐藏候选或全局 RNG 状态。所有新 pending 均在原 ProgramSkillFrame，原生移动／生命值子窗按 typed return 返回。
