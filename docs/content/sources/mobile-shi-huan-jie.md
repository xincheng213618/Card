# 势桓阶（手杀势）

- 主规则：[大陆移动版官网武将页 644](https://www.sanguosha.cn/pc/hero-detail-644.html)（2026-10-24 查阅）。官网共谋为准备阶段与一名其他角色交换手牌，本回合自己获得奇策、对方获得看破。官网有正朔技能名但正文漏项。
- 完整正式版与历史区分：[移动版 WIKI 势桓阶](https://wiki.biligame.com/msgs/势桓阶)、[正朔](https://wiki.biligame.com/msgs/正朔)（2026-10-24 查阅）。正式版魏、男、4 体力；正朔为限定技，出牌阶段令全体弃置全部手牌、洗牌，然后各摸四张。旧测试服的“无角色手牌数为 4”以及“弃置所有区域的牌”不采用。
- 官方旁证：[台湾官网 2026-05-01 公告](https://www.sanguosha.com.tw/newsinfo_1552.html)同样给出正朔的完整手牌弃置、洗牌、各摸四张流程；该地区共谋及护甲不同，不混入大陆规则。

共谋复用经典奇策与看破的既有实现。双方原手牌实体在同一原子移动批次中双向交换，暗手牌牌面不对其他观察者公开。支付的移动子结算全部归还后，借助共享技能变更层签发本实际回合的独立临时技能来源。交换已支付后丢失共谋不会取消已经签发的后续授予，临时来源到期不会删除原有的同名技能。

正朔只支付一次限定次数。先冻结全体存活角色的原手牌，在同一物理批次中弃置，并为各原持有人记录原生逻辑弃牌。等待弃牌子结算后，把当前弃牌堆并入摸牌堆，确定性地洗混完整牌堆，等待该移动子结算，再按当前角色起的行动顺序逐名请求原生摸四张。摸牌替代和其子结算仍由原生摸牌生产者处理；冷恢复不重复弃牌、洗牌或已经完成的摸牌请求。
