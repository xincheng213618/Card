# 周年服袁胤

核对日期：2026-10-24。群，男，3体力，SS，称号“载路素车”，扩展包“代汉涂高”。

- [当前官网武将页](https://x.sanguosha.com/hero/1907.html)：墨守为成为黑色牌目标后可摸体力上限张牌，后续次数逐次减一，摸一张的次数结算后重置。运柩当前为有角色死亡时，可交给一名其他角色一张该角色的牌，成功后增加一点体力上限并回复一点体力。
- [正式上线公告](https://x.sanguosha.com/news/20241121_2473_3015.html)：2024-11-22发布，明确“新品武将袁胤上线”，2024-11-23至11-29纳贤活动可获得永久袁胤。公告列明群、男、3体力及品质、称号、扩展包。首发运柩写的是死亡时弃置的牌，当前官网则写该角色的牌；实现按当前文字核对原生死亡时机和牌的真实来源，不能任取死者曾经弃置的牌。

墨守没有“其他角色使用”限制，本人使用黑牌且成为实际目标时同样具备资格。目标与黑色以原生最终目标事件及冻结的实际用牌颜色为准；不将未知颜色等同黑色。选择不发动不推进循环。请求数量与该次原生摸牌结果保存在原技能帧，恢复不重复请求；循环按该次冻结的请求张数推进，不以实际入手牌张数替代被替换的原生摸牌请求。

墨守循环从首次发动的当前体力上限开始，递减中的数量不因后来增加上限而突变；请求一张后的下一次重新读取当时体力上限。该上限变化与替换摸牌的口径是按当前文字给出的执行解释，未声称为官方专项FAQ。

运柩在死亡角色已确认为死亡、但其牌尚未经过死亡清理的原生阶段发行。复用原死亡帧和角色死亡技能窗口，通过真实发行、完成事实约束清理前返回；不借用旧版清理后的弃牌堆检索。由存活的技能持有者选择其他存活角色，再以不透明手牌位或公开装备牌选择死者当前真正拥有的一张牌，原生交付后才依次增加自身体力上限、回复体力。普通“角色的牌”按手牌、装备牌处理，判定区和特殊堆不属于该选择；未制造死者对手牌的自行选择，也未自行扩展为死亡后的复活。其他技能仍在各自原有死亡窗口中结算。

交付保留原生目的地替换、装备离开及牌移动观察者；以实际进入所选角色手牌的交付为成功，不以虚假同手牌出入或被阻止的转移换取健康收益。已交付实体与健康收益阶段均属于原技能帧，冷恢复不重复给牌、增加上限或回复。
