# 神庞统（一将成名／原十周年）

- 内容：`anniversary:shen-pang-tong`；`rulesetId=sanguosha-anniversary`，`variantId=anniversary-god`。神势力，男，基础体力一。
- [当前官方武将页](https://x.sanguosha.com/hero/222.html)，核读于 2026-10-22。经典形象与臻华福天两栏技能相同。
- [正式上线公告](https://x.sanguosha.com/news/20250122_5601_2110.html)，页面日期 2025-01-27，活动及新将自 1 月 28 日上线。表格注明神、男、一体力，三技能正文与当前武将页一致。

## 正式技能

**鸾锁**：锁定技，你的回合内，所有角色不能弃置手牌且当前手牌与本回合进入弃牌堆的牌花色均不同的牌视为【铁索连环】。

**凤燎**：锁定技，转换技，当你使用牌指定唯一目标后，阳：你令其摸一张牌；阴：你对其造成一点火焰伤害。

**鹍浴**：锁定技，你的体力上限始终为1，当你死亡时，你将牌堆中的一张火属性伤害牌移出游戏，然后复活并将体力值回复至一点。

## 规则落地

- 鸾锁是自己的回合持续生效的强制手牌身份；判断当前每张手牌的花色与本回合进入弃牌堆的实体牌花色是否相异。进入弃牌堆不限于弃置；使用、打出及死亡清理均计入。手牌获得、失去和弃牌堆增加后重新查询。其“当前手牌”不含木牛流马储牌。
- “不能弃置手牌”同时约束自己与他人发起的实际弃置，不阻止使用、打出、交给、获得或死亡区域清理；弃牌阶段只支付真实可弃置的牌。
- 凤燎依真实用牌的最终指定目标集合判断；借刀杀人的被要求出杀角色才是借刀的目标。重铸、纯打出和无目标牌不发动。一次真实用牌只切换一次阴阳，先冻结原极性与目标，再走原生摸牌／火焰伤害、铁索传导及濒死流程。
- 鹍浴保留真实死亡、身份揭示及死亡清理，在原死亡帧上支付移出牌堆实体牌；原死亡技能窗口退休后才恢复存活，随后进行同一原生死亡的奖惩与胜负检查。无火属性伤害牌时不能支付，不复活。复活本身不生成“回复体力”的原生恢复事件，不重新发起初始摸牌。
- 当前牌种中的火属性伤害牌为【火杀】与【火攻】；从现有有序牌堆取首张符合条件的实体，不观看或重排其余牌。官方正文没有“随机”字样，不混入测试稿中的随机支付或“濒死求桃结束后”时点。

未检得替换上述正式正文的后续官方修订。部分二手资料标作“测试服版”，把鸾锁写为回合开始发行、把鹍浴写为濒死求桃结束后触发；均未用于本实现。
