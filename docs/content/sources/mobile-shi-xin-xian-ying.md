# 势辛宪英（手杀）

规则主来源：[三国杀移动版官网，势·辛宪英](https://www.sanguosha.cn/pc/hero-detail-633.html)，核对日期 2026-10-24。魏，女性，3 体力。

技能全文见角色内容及技能展示定义。辅助核对：[移动版 WIKI](https://wiki.biligame.com/msgs/势辛宪英)；[官方咸话社区的势辛宪英攻略](https://xianhua.sanguosha.cn/postDetails?id=11607001)（2025-11-09）明确说明“清识”比较实际身份阵营，而非魏蜀吴群势力；选择自己摸两张。规则以当前官网文本为准，攻略不是规则扩展依据。

实现要点：

- 诫节使用已有原生主动技能及 `OtherCharactersOnly` 共享主动入口，实际回合角色提供观看，每个角色每个实际出牌阶段对每个技能拥有者限一次。只有辛宪英本人收到当前实体手牌的私有观看视图和花色选择，其他角色不得代选。
- 选择已包含的花色时，所有其他花色手牌作为同一原生逻辑弃牌组移动；先结算这组弃牌产生的子结算，再授予实际整回合的花色次数豁免。仍保留距离、目标、材料、技能自身等限制；所选花色的杀与酒不占用普通次数。
- 选择缺少的花色时，从真实牌堆和弃牌堆的匹配实体中随机获得一张，完全不存在时不生成新牌。此操作是获得，不是假冒摸牌或使用牌。
- 每个辛宪英各自记录本轮每名角色以诫节观看过的花色集合；重复出牌阶段合并同一角色的集合。当前角色所含花色数须严格多于其他所有角色，且本轮通过诫节发动清识未满两次，才视为对该角色发动清识。该轮次数与实际受伤后主动选择目标的清识分别计算；不选择花色仍已完成观看。
- 清识按真实阵营结算：身份局主公与忠臣、反贼分别同阵营，各内奸独立；公开团队局使用真实 TeamId；国战使用实际阵营；生存模式各自为营。自行选择自己摸两张，选择同阵营其他角色双方各摸一张。异阵营由辛宪英选择双方各一张手牌或装备牌，其中对方手牌使用暗槽位。
- 异阵营双方原实体选定后统一弃置，产生的装备、回复、技能和牌移动子结算保留在原指令帧；摸牌使用原生 draw-attempt/typed return，冷恢复不重复费用或奖励。

有代表性的检查覆盖：本人及他人主动入口、私有观看、同组多牌弃置后的子结算与冷恢复、整回合花色次数、杀与酒的普通次数隔离、真实获得缺少花色、同势力不同阵营及清识选择自己。共享装载、输入、冻结和回放契约沿用既有机制检查。
