# 势国渊

规则依据：[三国杀移动版官网，势·国渊](https://www.sanguosha.cn/pc/hero-detail-631.html)。魏，男性，3体力；体力图标可与[移动版 Wiki 的修耕页面](https://wiki.biligame.com/msgs/修耕)核对。使用当前正式版三技能清蹈、修耕、陈赦，不采用旧测试服记录三人的版本。

清蹈只在其他角色对本人使用的伤害类牌完整结算结束后触发。按这次原生使用的身份查找本人实际受伤事实；多目标伤害到其他人不算本人受伤。搜牌只移动牌堆或弃牌堆已有的真实实体，不制造指定牌。未受伤分支允许选择一张实际手牌执行原生使用，并保留其实际使用、响应、支付与后续子结算；距离豁免只归属该次获准使用。

修耕按最后一次完成确认的记录覆盖旧记录，最多两名角色。未发动则保留既有记录。每次被记录者的摸牌阶段开始时，冻结其当时手牌数与记录值的比较结果；相等时，摸两张与手牌上限增加均执行，不能先摸牌再比较。正文未规定记录和手牌上限增益的临时持续时间，因此记录持续至下次替换，已生效的手牌上限增益永久累计。

陈赦的顺序是本人、濒死者、伤害来源；同一角色占不同位置时逐项各弃一张，不能合并为一次付款。没有来源或某位置无牌时跳过该项并继续，只有三项实际弃置且有效花色相同才回复至上限并失去技能。第三人暗手牌只显示牌位；有效花色在牌离开原区域前冻结，支付后等待真实移动触发和装备离场子结算。失去技能复用共享的技能变更层；失败时不失去技能。
