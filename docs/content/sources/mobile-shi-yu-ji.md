符济出牌阶段限一次：展示至多其他存活角色数的牌并交给其他角色，这些实体牌被标记为“符济”牌；任何角色使用符济牌时获得一张同花色牌，符济杀基础伤害 +1，符济闪结算完毕后使用者摸一张牌。若发动后手牌数为全场最少，摸一张牌并强化本人直至下回合开始：期间本人使用的第一张杀和闪同样带符济效果。

道转在需要使用基本牌时，允许将一张牌置入弃牌堆视为使用该基本牌：杀、火杀、雷杀、桃、酒仅限主动使用，闪仅限响应使用；额度按“每回合限一次、每轮每基本牌名限一次”的事件账本执行，普通杀与属性杀同名。

## 实现解释边界

截至核对日，官方页面未公布势于吉的专门 FAQ。以下为本实现的解释性取舍，不标为官方逐事件裁定：

- 展示的符济牌交给单一接收者（发动时选择一名其他角色获得全部展示牌），未按“等量名其他角色”逐名分发；展示数量上限取固定值 4，未随存活其他角色数动态收紧。
- 道转的置入弃牌堆只支付于吉自己的手牌或装备区牌，不支持当前回合角色的牌；“若当前回合角色本次失去过牌则本轮失效”实现为于吉在自己回合内发动过道转后本轮禁用，下轮开始恢复。
- 决斗、南蛮入侵中“打出”的杀不是使用，不触发符济效果；与官方“使用”措辞一致。
- 已使用过的符济牌再进入手牌后再次使用不重复结算标记效果（标记在使用时消耗）。
