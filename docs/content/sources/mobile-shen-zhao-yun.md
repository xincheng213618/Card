## 当前正式技能

**绝境**：锁定技，你的手牌上限+2；当你进入或脱离濒死状态时，你摸一张牌。

**龙魂**：你可以将至多两张同花色的牌按以下规则使用或打出：红桃当〖桃〗；方块当火〖杀〗；梅花当〖闪〗；黑桃当〖无懈可击〗。若你以此法使用了两张红色牌，则此牌回复值或伤害值+1。若你以此法使用了两张黑色牌，则你弃置当前回合角色一张牌。

## 版别与实现边界

不采用仓库经典神赵云的“手牌数始终为四”、斩将或高达一号规则。绝境复用既有手牌上限加二、原生进入及脱离濒死各摸一；龙魂复用一张、两张同花色手牌/装备的原生转换支付、真实火杀与桃的加值、闪和无懈可击以及子结算返回。

仓库已有 OL 配置的双黑分支是可选且观察所有接受响应的窗口。移动版依现行正式正文改为强制弃置，并观察已存在的 `cardUseCommitted` 窗口，包含原生响应使用：防御杀的闪与无懈可击能触发；万箭齐发中的纯打出闪、代打出的闪不会借此获得使用收益。对当前回合角色使用原生选择及真实手牌/装备弃置；没有合法区域牌时走原生空支付分支。

人物 Runtime 只增加无状态的 `IProgramCommittedUseContract` 定义期组合校验，以接入已有的响应使用窗口，不增加运行时副本、事件、规则枚举、pending 帧或支付机制。双红实际恢复整组与子窗恢复、双黑强制付款、响应使用与纯打出的区分沿用现有共享机制检查；不添加重复人物定义快照或行为矩阵。
