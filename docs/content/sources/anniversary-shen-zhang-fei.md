## 规则细化与牌面词表

官方简短正文中的“已有标记则改为修改”，结合[十周年神张飞攻略的详细判例](https://my.4399.com/yxtouch/ziliao/49381/)和[2025-01-21 技能结算分析](https://www.bilibili.com/read/cv22254031/)，细化为：

- 判定命中四类关键词时，清除受判者原有的笞、杖、徒、流，再同时赋予本张牌命中的所有类别；不是单类别优先选择，也不是旧效果累计升级。丈八蛇矛会同时赋予杖、徒。
- 死独立叠加；获得死不清除四罚，四罚的覆盖也不清除死。当前手牌上限减当前死标记数；不是每次按总数再次累减。死的直接死亡检查位于受罚者真实回合结束后，严格使用当时存活人数。
- 已经赋予的标记及效果不依赖原神张飞继续存活或保有技能。四罚的发动主体为受罚者。
- 徒按一次实际失去手牌的批次随机弃一张手牌，排除神裁本身造成的拿牌、弃牌，防止徒自递归。
- 巡使每次真实使用无色牌后提高本局每个出牌阶段的神裁次数上限，初始一、最高五；多目标一次使用只计一次。回应中的真正“使用”（如八卦的无色闪）和仅“打出”按引擎原生类型及 typed return 区分。

标准／军争的四词表为：体力对应桃、酒、桃园结义、白银狮子；武器对应所有武器及借刀杀人；打出对应南蛮入侵、万箭齐发、决斗、八卦阵、丈八蛇矛；距离对应坐骑、顺手牵羊、兵粮寸断。以上词表是牌名／牌类别／正式效果文字的元数据，不包含背景文句，也不搜索项目中概括性的运行说明。共用 `CardPrintedInfo` 存储词位；扩展牌按各自明文信息显式登记。

[2019-06-18 官方木牛流马改版公告](https://sanguosha.com/news/20190618_4148_1016)仍明确装备下的牌可如手牌使用或打出。因此木牛流马牌面本身包含“打出”，判定命中徒；其储存的多目标锦囊也属于巡使的合法使用来源，使用时同样强制转为无色杀，不能因实体位于木牛储牌区而保留原锦囊身份。

## 引擎落地

神裁保留原生判定的改判窗口。付费父帧发行最前的判定牌获得子结算，先实际移动判定牌，再给天妒等判定后技能保留其正常机会；后续以原判定帧的最终结果返还父程序，执行覆盖、死和区域拿牌。隐藏手牌使用既有槽位选择；移动、随机数和手牌变化均走原生规则窗口。

若原发动者在改判子结算中死亡而未能获得判定牌，父帧仍接收完整判定结果，仅将该次判定原生转入处理区的未获实体弃置，并等待实际移动子窗；不会将其他处理区实体一并清理，也不会在死亡后继续赋予新罚。

笞使用真实伤害结算后的实际伤害量，另开原生失去体力／濒死链；杖禁止对杀的响应；徒实际随机弃手牌并等待移动子窗；流使用原生翻面事件；死使用原生直接死亡子链。目标上的已发行效果通过历史来源和内容哈希确认，独立于原发动者的当前技能与存活状态。

巡使的五种标准多目标锦囊为南蛮入侵、万箭齐发、五谷丰登、桃园结义、铁索连环；借刀杀人不属于这一牌面类别。强制身份保留原实体作为支付材料，将真实使用外观改为无色杀；不保留铁索重铸。双色丈八和零材料原生使用依照实际无色外观参与距离、次数和合法额外目标规则。

本模块不提高全局规则格式或内容包版本。定向检查覆盖新增判定获得顺序、关键词覆盖／重叠、罚的真实结算、来源死亡后持续、原生多目标无色杀、次数成长和死的真实回合边界；代表性冷恢复位于真实判定获得子窗及区域拿牌选择。
