## 当前完整规则

**开济**：转换技，出牌阶段限一次，阳：你可以摸等于体力上限张数的牌；阴：你可以弃置至多等于体力上限张数的牌（至少一张）。

**平袭**：结束阶段，你可选择至多 X 名其他角色（X 为本回合因弃置而进入弃牌堆的牌数），弃置这些角色各一张牌，然后视为对这些角色各使用一张〖杀〗。

## 实现边界

- 开济复用已有转换状态，初始阳；复用每个真实出牌阶段一次的程序用量。阳走原生摸牌指令，按发动时真实体力上限确定本次数量；阴选择一至上限数量的手牌／装备牌，动态验证可弃资格并真实支付，复用 `CommitProgramConversionPolarity`。原生摸牌、付款及其子技能返回原程序帧，不重复转换或支付。
- 平袭 X 直接复用已有 `YangBiaoDiscardCount()` 的原生逻辑弃牌完成凭证：`NativeLogicalDiscardMaterialCompletedEvent` 对应当前回合的 `NativeLogicalDiscardInvocationRecordedEvent`，且实际终点为弃牌堆。操作声明已有原生逻辑弃牌事实依赖，单独王昶局也会记录；不另外维护一份人物专属弃牌账本。使用／打出、重铸、死亡清理、装备替换以及最终移出游戏不计作本技能所需的实际弃牌。
- 本次 X 在平袭开始时确定，选择至多 X 个不同的其他存活角色并确认整组。先依次完成这些角色的弃牌及真实移动子窗，再依次对原选各角色发行独立的原生虚拟杀；不会交错成“弃第一人、杀第一人、再弃第二人”。无可弃牌的原选角色跳过弃牌步骤，仍保留在后续杀的原组中。
- 弃牌使用手牌／装备牌的现有动态保护及逻辑弃置路径，暗手牌只向选择者显示牌位。实际杀使用既有 `UseTriggeredProgramVirtualSlash`，逐人重新核对原生目标、距离、使用禁止及目标禁止等资格，不能发行时跳过该次杀，不更改先前整组弃牌。完整经过原生使用、响应、伤害、完成及原帧返回，不以直接伤害代替杀。
- 目标组、私有选牌、真实移动记录及原生返回收据均挂在拥有它们的 `ProgramSkillFrame`，集合在写入时冻结。公共自定义事件只包含来源、公开目标与标量数量／序号，不新增暗手牌身份日志。声明／使用／完成与 typed native return 绑定原帧、当前组游标、使用 ID 和动作 ID，防止恢复时重复发动已完成的杀。
- 静态程序形状在 loader 中校验，续接复用现有内容哈希守卫及动态支付、拥有者与父帧身份；不在每个恢复点重复完整静态定义检查。
