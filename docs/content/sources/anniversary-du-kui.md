## 当前完整技能

**泛音**：出牌阶段开始时，你可从牌堆亮出点数最小的一张牌并选择一项：使用之（无距离限制）；或令你本回合使用的下一张牌可额外选择一个目标。然后从牌堆亮出点数翻倍的牌并重复此流程。

**配器**：当你受到伤害后，你可移动场上一张牌。然后若所有角色均在所有角色攻击范围内，你可再移动场上一张牌。

以上全文来自当前官方详情，并由正式首发公告相互印证；不是欢乐三国杀或其他产品同名武将的规则。

## 执行解释与证据层级

- 泛音从当前真实牌堆选择最小的印刷点数；同点数有多张时，使用游戏 RNG 选择其中一张并真正公开亮出。后续寻找恰为上一点数两倍的牌，牌堆没有该点数或超过 K 时停止；不从弃牌堆补足，不把公开牌先伪装成获得到手。
- 官方只写“无距离限制”，没有“不计入次数”或“无次数限制”。因此以原生实体 Use 执行，保留实际次数和使用／目标禁止；普通杀也正常消耗该出牌阶段的杀次数。未选择使用的亮牌按公开处理区的原生清理流程进入弃牌堆。
- “下一张牌”的增加目标沿用既有真实 Use 额度。下轮亮出的牌若实际使用，也会消耗先前授予的这次额度；只允许增加一个合法目标，不提供减少目标选项。
- [百度百科杜夔条目的“玩法分析⑤”](https://bkso.baidu.com/item/杜夔/62043236)明确说明选项二不叠加，并举出后续泛音使用的牌可消耗这次额度。这是二级玩法分析，**不是官方 FAQ**。本实现依据该补充采用单次、不叠加的既有额度；该条目对杀次数写有作者个人理解的保留语句，不把它当作官方已实测结论。
- 配器的第一张牌实际完成场上移动及其原生后续结算后，重新查询所有存活角色彼此的真实距离、攻击范围；满足条件才给出第二次移动的可选机会。不是只检验杜夔自己的攻击范围，也不是在移动前冻结真假。
- 场上移动复用装备区的真实空闲／有效装备栏和判定区的原生合法迁入规则，不将手牌视作场上牌。第二次仍可选择合法场上牌，官方正文没有另写“不能再次移动同一实体”的限制；不将二级分析中的额外限制冒充一手规则。

## 实现与恢复边界

- 泛音的原始出牌阶段触发帧拥有点数游标、当前已公开实体、真实牌堆移入处理区的付款收据、当前原生 Use 身份及其子窗返回。亮牌在处理区直接使用，保持实体 ID／印刷类别，不构造假手牌或零实体替代。
- 所有牌型沿既有原生使用能力：杀使用原生攻击，基本牌使用原生简单牌效果，普通锦囊使用原生目标／无懈／锦囊结算，装备和延时锦囊沿各自原生入口。额外目标复用既有下一次真实 Use 目标调整，泛音只授予“加”而非“增减”。
- 真实移动可能发行原生移动、健康、回复替换等子窗；原帧等待这些子窗完成后才推进下一点数或第二次场上移动。已付处理区实体和原生 Use 使用精确发票及类型化返回验证，恢复后不重复支付。
- 新事件只记录公开亮牌、公开场上移动和标量原生 Use 身份；牌堆候选和 RNG 内部状态不写入公共自定义事件。集合状态保存在原帧并冻结。
