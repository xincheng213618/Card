# 移动版界伊籍

核对日期：2026-10-24。采用[移动版官方界伊籍页（257）](https://www.sanguosha.cn/pc/hero-detail-257.html)身份规则；原始 HTML 的第二个隐藏技能条目也已核对。蜀势力、男性、3 点体力。

官网的机捷与急援正文和既存 OL 伊籍相同，但本条目保留移动版界武将身份、独立技能 ID、立绘及选将注册，不改写 OL 版本。

机捷先发动、私看牌堆底的实际实体，再选择任意存活角色（含自己），最后通过既有原生给牌操作移动该实体。限次按实际出牌阶段计算。观看期间牌留在牌堆，不公开身份，不产生额外摸牌或牌移动；目标选择使用现有所属帧，保存恢复沿用命令重放。

急援的濒死分支使用已有进入濒死时点和原生摸牌。给牌分支使用原生 Give 生产者已记录的实际赠与及接收者，同一次交给多张牌只询问一次。机捷明确使用“交给”，急援明确使用“你交给……牌时”，因此机捷交给其他角色也触发，交给自己不触发。被其他角色夺取、交换或自行摸牌不能仅凭手牌移动冒充赠与；赠与被替换而没有实际交付时不凭空产生收益。

给牌凭据复用 `NativeCardsGivenEvent` 和既有原生 Give 收据，只为目录包含本技能时启用记录；不从原因字符串推断赠与。选择之后与移动之前没有新的等待窗，因而私看的底牌与随后移动的底牌保持相同。
