## 正式技能及实现边界

**夺锐**：锁定技，你对其他角色造成伤害时，你废除其一个装备栏直到你的下个出牌阶段开始。

在原生伤害应用前的来源窗口选择对方仍有效的装备栏，真实移出栏中装备，保留装备离区产生的回复等子结算，再继续原伤害。临时废栏记录以原技能实例、原伤害窗口和实际出牌阶段 token 为据；到来源的下个实际出牌阶段开始恢复，不以自然回合计时，也不要求届时仍拥有技能。期间原生装备栏状态被其他效果更改时，不以过期临时记录覆盖后来的状态。

**止啼**：锁定技，摸牌阶段你多摸X张牌（X为场上所有被废除的装备栏数，至多为5）；其他角色弃牌阶段结束时，若其有被废除的装备栏，你弃置其区域内等量张牌。

额外摸牌修正真正的正常摸牌数量。弃牌阶段结束时冻结该角色废栏数，再逐张选择其手牌、装备区或判定区内可弃置的实际牌；暗手牌使用公开选择合同的匿名槽，原帧保存已付移动。牌不足时执行所有仍可合法弃置的牌。

**猝袭**：其他角色回合开始时，你可以弃置一张牌，然后令其选择一项：1.跳过摸牌阶段并令你摸两张牌；2.其受到你造成的1点伤害。

复用真实其他角色回合开始窗口，弃置来源自己的手牌或装备牌，完成支付子结算后由回合角色选择。第一项使用可挂起的原生摸两张牌，并将该实际回合的摸牌跳过接回原生阶段流程；第二项发行来源明确的原生一点普通伤害，可正常触发夺锐。付款、选择、原生摸牌及子结算均由原技能帧拥有，不建立独立待结算旁路。公开自定义事件只含来源、游标、批次范围等标量；暗牌实体移动证明留在可信帧内。
