# 势鲁肃（移动版正式服）

来源核对日期：2026-10-24。

- [官网武将页 638](https://www.sanguosha.cn/pc/hero-detail-638.html)：现行好施、缔盟全文。
- [移动版 BWIKI 势鲁肃](https://wiki.biligame.com/msgs/势鲁肃)：吴、男性、3体力及现行技能。
- [移动版 BWIKI 兵势篇修改记录](https://wiki.biligame.com/msgs/武将修改相关记录页面（兵势篇）)：好施历经体力限制、补至体力上限、固定四张等测试版本；正式版取消受益者体力限制、前两次补至三张，缔盟牌数差固定至多3。
- [官网原立绘](https://www.sanguosha.cn/storage/uploads/images/85200.jpg)。

好施授权任意一名其他存活角色。授权到鲁肃的下一个真实回合开始（包含额外回合和翻面回合），不以自然轮次或正常摸牌到来判断。授权后的实体牌仍在鲁肃手牌区，受益者私下可见并可使用或打出；实际行动角色与实体提供者分别保留，不会将鲁肃手牌先移给受益者。授权范围不包含弃牌、拼点、重铸或主动技能的普通牌费用。技能失去后，已发出的时限授权和前两次补牌效果持续到原定期限。

补牌仅由本次授权产生的真实使用或打出支付、并实际使鲁肃失去最后手牌时触发。使用牌保留原生使用编号和付费前移动序号；打出牌保留本次确切的移动发生序号，不能借同一实体的历史授权重触发。每份授权前两次将鲁肃当前手牌补至三张。

受益者可以通过自己的视为能力使用获授权手牌，例如武圣与闪袭；转换技能归属受益者，物理牌仍来自鲁肃原始手牌区。普通锦囊及这些转换使用均在原生支付子结算内补牌，先结算失去最后手牌的补牌，再继续原牌效果。

缔盟两名目标可包含鲁肃自己；选择时两人实际手牌数差不能超过3。先交换真实手牌，完成移动子结算后才选择效果。摸牌目标按本次交换后的较少一方确定，X在选择效果时读取鲁肃已损失体力。弃牌由鲁肃本人从手牌和装备选择，受现有禁止弃置规则约束；不足X则全弃可弃牌，支持多选后一次确认并以一次真实逻辑弃牌支付，已付子结算恢复不会再次扣牌。

官网与现行BWIKI没有补充“交换后双方牌数相等”的FAQ。按“较少”这一严格比较解释，等量时没有摸牌目标，可选择本人弃X张；不擅自改成任意一人或两人均摸。此项是文本推断，若后续官方FAQ明确另有裁定，应据来源调整。
