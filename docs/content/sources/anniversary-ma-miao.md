# 周年服马邈

核对日期：2026-10-24。蜀，男，4体力，SS，称号“退路自有”，扩展包“天下归心”。

- [当前官网武将页](https://x.sanguosha.com/hero/1037.html)：当前仗关为“每个回合开始时，你可以将手牌数调整至体力值，若你的手牌数没有因此变多，你回复一点体力，然后获得当前回合角色一张牌。”从风为“你/其他角色不因此技能获得其他角色/你的牌时，可额外随机获得1张。”
- [冬至礼遇季正式上线公告](https://x.sanguosha.com/news/20251218_2313_0916.html)：页面2025-12-19发布，2025-12-20开始，充值活动正式获得马邈；首发仗关旧文按“不变回复、减少获得”分支结算。当前官网已将其改为未变多时依次回复、获得，本实现采用当前文案，不使用首发旧规则。

仗关绑定每个真实回合开始的原生父帧。以发动时当前体力值调整真实手牌，通过原生摸牌或拥有者真实弃置支付；等待其子结算完成后检查实际手牌是否变多。未变多时先发行一次原生回复，再获得当前回合角色的一张手牌或装备牌。满体力仍继续获得；自己的回合可以取得自己的装备，不制造手牌移入原手牌的假支付。

两段“角色的牌”均按项目通用拥有牌术语处理为手牌和装备区牌；判定区的区域地址含角色座位，不代表其中实体被该角色拥有，因此不属于仗关候选、从风的原获取资格或额外随机池。该范围与已有高翔及侯成等普通拥有牌操作一致，是通用术语的实现解释，未找到马邈专项区域FAQ。不可将它扩大解释为“区域里的牌”。

从风以真实移动批次中的“持有者→获得者”配对发行资格，每个批次同一配对只发行一次，不按牌张重复。获得是实际进入另一角色手牌的原生拥有区转移；纯失去、弃置后再从弃牌堆取得、本人手牌临时出入等不伪装为获取其他角色的牌。马邈获得他人牌时由马邈决定；他人获得马邈牌时由实际获得者决定，可拒绝，拒绝不推进随机状态。

原生顺手牵羊及选取拥有牌交给目标的指令可能通过处理区中转。此时先证明实际持牌区离开事件的原生使用者或当前技能生产帧及目的角色，再将同一实体的紧邻真实移入手牌与该来源对应；顺手还核对原生取牌事件。不会仅沿历史牌址向前追溯，因此已使用牌进入处理区后被取得不冒充“获得前持有人牌”。这些来源收据只记录移动序号、角色和生产帧身份，不公开原手牌实体编号。

接受从风时，从原持有者当时仍可被获得的手牌和装备牌中随机取得一张，使用对局原生随机源及真实原子获取请求。候选顺序、随机前后状态与已付收据保存在原技能帧上，冷恢复不重复抽样或支付。本技能直接产生的获取批次不再触发从风；其后其他技能产生的独立真实批次仍可触发，不按祖先帧或整段结算一概屏蔽。上述配对与拥有区口径是当前文字的执行解释，未声称为官方FAQ。

复用原生牌移动与目的地替换、回复替换、HP变化和移动观察者；不抑制从风引发的其他技能链。所有带集合的待续状态冻结，资格事件仅记录标量身份，不公开随机候选手牌。没有新增玩法版本、checkpoint版本或单将内容包版本。
