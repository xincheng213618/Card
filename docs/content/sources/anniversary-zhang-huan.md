实现口径：以下是依据当前文字与现有引擎的实际弃置操作账本所作的规则解释，并非官网另行发布的FAQ。

1. 义拒复用原生用牌指定目标完成窗口：使用者必须为其他角色，实际指定目标只有张奂；真实转化牌和虚拟牌也走该窗口。选择本人手牌或装备牌实际弃置，空区域跳过，多目标和自己用牌不触发。
2. 戍国在真实回合结束事件之后的 `AfterTurnEnded` 窗口发动，不提前到结束阶段开始。直接父为原来的 `DeferredTurnEndFrame`，必须保留已完成实际回合、当前候选及子帧身份。它只承认真正完成的逻辑弃置入弃牌堆凭证。用牌结束、打出结束、普通判定清理、移交、重铸以及装备在游戏外销毁不计为弃置。归属取弃置操作的执行者；现有引擎将主动弃置他人牌与令他人自己弃牌分别记录，不能把原牌所有者当作执行者。
3. 可用牌池在每张完整原生使用及其子结算返回后更新。原牌必须当前仍在弃牌堆，且最后一次真实移动就是该次弃置完成；每次使用固定原实体、原弃置序列、执行者和合法目标。保留基本牌、普通锦囊、延时锦囊与装备的原生使用，不能主动使用的闪、无懈可击没有用牌方案，铁索重铸不属于使用。正常距离与目标限制保留，回合结束使用杀不占出牌阶段次数。
4. 同次戍国已成功使用的实体ID不再使用。使用本人执行弃置的牌后可继续，第一张其他角色执行弃置的牌须完整结算，然后停止。可主动停止，也可在没有合法用牌方案时结束使用部分。
5. 摸牌计数与当前可用牌池分开。在最终结算时计算本实际回合所有已证明真实弃置入堆的完成序列次数，包括已经被别人取得的牌，以及本次戍国用牌造成的后续弃置；同一实体真正再弃置按新完成序列另计。扣除此戍国已完成使用次数，若当时手牌不是存活角色中唯一最多，发起至多5张的原生摸牌。该口径沿用已有实际回合弃置计数机制，不通过当前弃牌堆的剩余张数替代历史弃置数。

暂停状态、已完成使用、原生摸牌与返回都保存在原来的程序帧；未增加全局规则版本或按武将递增的内容包版本。
