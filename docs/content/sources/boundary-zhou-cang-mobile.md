官网当前忠勇以**出牌阶段内使用的整张杀结算结束**为时机：未有闪响应可以获得原杀；有闪响应则选择获得响应闪、随后可以给出原杀，或给出响应闪、取得本回合杀次数上限+1及下一张杀伤害+1。忠勇获得的牌本回合不能使用。保留旧`classic:zhongyong`独立版本；旧版赠出红牌后令受赠者使用杀的规则不适用于此版。

实现记录原生声明的实际出牌阶段，等待整张杀完成，依据实际完成的闪响应归属判定分支（包括虚拟闪、供闪和多次响应）。可获得或交出的实体仅来自该原杀或对应完成的闪；实体离开处理区或弃牌堆后，即使之后再次进入弃牌堆，也不能由该次忠勇重新认领。虚拟闪足以改变分支，不能凭空产生可交出的实体闪。响应闪已无法获得时，第一项仍可继续尝试交出尚在公共结算区域的原杀。

“另一名其他角色”按排除杀使用者及该次杀的实际目标处理。获得/交出均通过原生完整移动请求及其增益替代结算；付款及后继子窗留在原技能frame，恢复后不重复移动。实际进入忠勇拥有者手牌的实体，在原实际回合内不能作为原生或转化使用的材料；纯打出保留原生语义，转交他人不会将禁用状态扩散给受赠者。

杀次数加成复用回合规则修正；下一杀加伤复用既有下一张杀储备、整张牌冻结、消耗和回合到期路径，连环传导不重复加伤。核心行为检查覆盖三项完整主路径、一次已付款原生移动子窗冷恢复、禁用及到期、额外杀次数和下一杀加伤的独立消耗。
