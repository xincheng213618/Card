## 逐项等价核对

| 项目 | 欢乐当前文字与周年正式文字的共同规则 |
| --- | --- |
| 体力 | 初始及上限均为4。 |
| 裂穹触发 | 对其他角色造成一次伤害后，可选一部位击伤；不是按每点伤害重复。 |
| 力烽 | 从受者手牌随机弃掉一半，向上取整。 |
| 地机 | 受者下一次受伤增加1；未用效果在其自己的回合结束到期。 |
| 中枢 | 受者下一张使用牌的效果无效；未用效果在其自己的回合结束到期。“打出”不因此被改成“使用”。 |
| 气海 | 至受者自己的回合结束，限制红桃牌的使用与打出。 |
| 天冲 | 本实际回合已被该神黄忠击伤的角色，后续再次击伤时才有此项；使其失去当时全部体力，因而死亡才为神黄忠增加1上限。走体力流失及濒死，不改成直接死亡。 |
| 斩决时点 | 出牌阶段开始时，自愿选两个分支之一。 |
| 斩决第一项 | 按当前体力摸牌；本出牌阶段下一张杀忽略距离且不能响应。 |
| 斩决第二项 | 按已损体力摸牌；本出牌阶段下一次伤害造成后，按实际伤害量回复。 |

欢乐把天冲列为第五项并把再击资格写在括号，周年先列四项再说明再击时出现天冲，逻辑相同。未发现同产品正式修订赋予另一套次数、伤害倍率、区域选择或期限规则；不凭攻略中的模式推荐、配将或PVE装备制造新的武将定义。共享运行时已记录的叠加等实现解释继续适用，不宣称这些推断获得欢乐官方独立FAQ认证。
