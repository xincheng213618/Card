# 周年服侯成：来源与规则落实

官方当前武将页：[侯成（gid 1209）](https://x.sanguosha.com/hero/1209.html)。核对于 2026-10-24，群势力、男性、5 体力，SS，称号“猢威挽骊”，所属“天下归心”，技能为“献酿”。

正式上线来源：[3.1–3.9 闪闪盛典公告](https://x.sanguosha.com/news/20250226_3631_5618.html)。正文日期为 2025-02-28，活动自 2025-03-01 开始，明确宣布新品武将侯成上线，并列出与当前武将页一致的技能和基础属性。URL 中的 20250226 不是正文日期。

经典原画：[官方 1120901.png](https://web.sanguosha.com/10/pc/res/assets/runtime/general/big/static/1120901.png)，574 × 761。

技能按官方全文实现：每轮每项限一次，自己的牌被其他角色弃置后、受到伤害后分别有一次发动机会；获得一名手牌数不小于自己的角色至多两张牌，再可交给另一名其他角色至多等量张牌。因此获得或交出的基本牌只能当酒使用。本轮因此技能实际获得牌数超过两张时失去 1 点体力。

以下是仓库对规则细节的解释，并非另有官方 FAQ 裁定：

- 两项发动次数独立按轮累计。伤害按每次实际伤害结算后触发；弃置须有其他执行者的原生逻辑弃置收据，使用、打出后的弃牌堆清理与自身支付弃牌不满足条件。“自己的牌”沿用手牌、装备区牌的所属定义，不把判定区牌算作自己持有的牌。
- 获得对象按选择时当前手牌数比较，实际付款前重验；文字未排除自己，故可选择自己，但自己的手牌原地停留不是“获得”，不增加实际获得数，也不产生新酒标记。获得、交出使用手牌和装备区实体；交出对象既不是侯成，也不是本次获得对象。至多可以为零，交出上限以本次实际获得数为准。
- 每次发动的获得移动完成后，先等待这批移动产生的子结算，再决定是否交牌；交牌完成并等待子结算后再检查本轮累计数。通过原生体力流失结算，付款收据在进入濒死之前写回原技能帧。恢复不会再次扣已付的体力。
- 基本牌标记在实际获得或交出移动完成后生效，通过原技能身份及真实移动收据确定。标记跟随牌实体保留，不因后来转交、进入弃牌堆、换持有者、跨轮或侯成失去技能而消失。实体的印刷牌名、花色和点数不被改写。
- “只能当酒使用”限制真实的 Use：标记的闪不能作为真实使用的闪响应；标记的桃不能救其他人；实体或多素材参与的非酒真实使用均不允许。决斗、南蛮等纯 Played 杀，技能支付、弃置与重铸不被冒充为 Use。当前持有者可通过原生转换入口将标记基本牌作为酒使用或在自己濒死时自救，保留通常酒次数、花色目标禁制与所有原生付款、濒死及响应边界。

新增规则沿用现有包版本、规则 JSON 格式、内容指纹、每轮使用次数、逻辑弃置账本、原生移动、酒使用及体力流失设施。待选择、移动收据和扣血状态全部保存在原技能帧；公开的新事实仅包含数量及移动边界，不加入隐藏牌实体 ID 列表。
