# 周年服马铁

## 正式来源

- [官方武将页 gid 1353](https://x.sanguosha.com/hero/1353.html)：男、群、4 体力、SS，群雄伺动；技能为驱险、追击。
- [10.17—10.24 霜降活动：新武将马铁](https://x.sanguosha.com/news/20251015_7193_3911.html)：正文发布日期为 2025-10-16，活动自 2025-10-17 00:00 开始，明确“新品武将马铁上线，可通过参与纳贤活动获得”。称号为“紫骊奔北”。公告与当前武将页的两技能全文一致。
- 官方武将页经典原画地址：<https://web.sanguosha.com/10/pc/res/assets/runtime/general/big/static/1135301.png>。

正式规则：

> 驱险：回合开始与结束时，你可从牌堆中获得一张【杀】并选择一名其他角色，若其在其他角色的攻击范围内，这些角色可依次对其使用【杀】，每有一名角色使用【杀】你摸一张牌。然后若其未以此法受到伤害，未使用【杀】的角色各失去X点体力（X为以此法使用【杀】的角色数量）。

> 追击：锁定技，你对其他角色使用牌结算后，本回合你计算与其距离视为1。

## 版本与去重

这是周年服单独马铁，不是已有 `ol:ma-xiu-ma-tie`。后者为马休马铁，技能“马术、垦伤”，其多牌当杀及伤害后摸牌规则与本将不同。其他版本同名“追击”的体力比较、弃置或重铸规则也不属于本将。本将不引入全局规则纪元、存档版本或内容包版本变更。

## 仓库规则解释

以下为依据正式文本作出的仓库解释；未发现官方补充 FAQ，不能作为官方裁定引用。

- “回合开始”采用实际回合 `TurnStartBeforeNormalFlow`；“回合结束”采用 `AfterTurnEnded`，不是结束阶段或 `TurnEnding`。
- “其他角色”以指定目标为参照，范围内参与者包括马铁本人。选定目标时按当前实际回合行动顺序冻结攻击范围内的在场角色；每次真正发行时仍检查付款和目标合法性。死亡者跳过，不把没有可用杀的参与者预先排除出未使用者。
- 从现存牌堆获得第一张符合杀类别的实体牌，包含普通杀、火杀、雷杀，不将视为牌当成牌堆实体，不为此洗回弃牌堆。没有符合牌时继续选择目标及后续效果。
- 每名参与者获得一次自愿用杀机会，原生的合法转换、丈八、多材、零材、技能成本及势力供牌仍由既有原生流程结算。普通出牌次数不限制这次由技能要求的杀，正常禁用、目标禁止与实际付款限制仍有效。
- 实际提交的原生 Use 才计数；仅选择动作、未成功供牌或未发行的付款不计数。对应摸牌在该次杀的 `CardUseCommitted` 窗口、响应之前进行。已发行驱险的奖励按原技能实例补发候选，中途失去技能不丢失原指令中的奖励。
- 只认指定目标受到的正数实际伤害，且伤害必须归属于该驱险发行的精确 Use。体力流失、其他目标受伤或无关技能伤害不免除惩罚。额外目标、目标变化及原生伤害防止仍由牌本身结算。
- 无此法伤害时，冻结参与者中的未使用者各失去实际使用人数点体力。X=0 不制造零点体力流失。付款收据先冻结，再进入原生濒死；恢复原帧不会重复扣血。
- 追击只记录真实 Use 最终指定的其他角色目标。打出牌或仅被响应的牌/角色不伪造成本牌目标。距离仅从马铁到目标为1，不改变反向距离；标记按实际回合结束失效。回合结束后触发流程不延长上一回合的距离有效期。

## 实现边界

驱险的队列、付款、原生牌身份、摸牌与体力流失返回都保存在原 `ProgramSkillFrame`。`CardUseFrame` 只保留绑定该指令的原生发行来源。公开新事实均为标量或无集合的来源记录，不将暗牌库存或隐藏牌选择写入公开事件。追击复用距离查询贡献；升级与授技共享机制不参与本将。
