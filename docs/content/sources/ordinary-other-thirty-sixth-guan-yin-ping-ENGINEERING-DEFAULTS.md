# Defaults without current official FAQ

- Snow cost uses legal HE and effective red suit. It cannot start without a legal red entity. X is read after cost children at actual target selection, not when the activation button is published. At least one target is required by the later “one of them”; self and already-chained targets remain eligible. State changes are set-true, with all queued original character-state children drained before fire. If none of the originally chosen targets remains alive, cancel unissued fire.
- Snow is a paid chain/fire commitment only for the exact seven-node 7400 composition. Source loss before payment still cancels. A single real red HE→Discard (or generated equipment→OutsideGame) ledger commits the original effect; source loss in cost/chain children does not cancel or repay it. Dead owner/winner cancels unissued tail after draining. Receipt holds no material ID publicly before actual discard. This continuation default is not an official FAQ.
- The fire right is promised when the exact fire-damage instruction begins and issued **after** the recipient's Draw and all children return. Lost/suppressed source does not cancel that promise or later issued right. Dead owner/game winner cancels unissued right after draining children. A recipient killed during draw children may retain an unusable target right until expiry; it does not make a dead target legal.
- “No use limit against this character” bypasses the existing finite target quota gate; it does not suppress ordinary Slash use history/debits. Mixed targets must all pass their own quota gate. Existing count-exempt forced/borrowed/response producers retain their own semantics. Alcohol only receives the finite self-target quota exception; an already active alcohol effect is not stacked. No unproved new quota for other card kinds is introduced.
- An actual turn, including an extra turn, receives its own exact allowance stamp and expiry. An extra Play phase in the same actual turn retains the right while Snow receives its normal new phase quota. Removing Huxiao in Wuji does not prematurely expire an issued right. Source loss/reacquisition does not refund game awakening usage.
- Wuji's dealt damage is the mature actual turn attribution, including actual chain propagation credited to that source. It excludes prevented/replaced-HP loss and bare accepted-card history. MaxHP/recovery occur before skill loss and weapon search, with their real children returning first.
- “On the field” means publicly present E/J of living characters. Foreign Hand, private piles, Processing and generated general weapons are excluded. Public/deck/discard are all offered without a mandatory source priority. Multiple public entities are selectable; deck resolves first matching printed kind without leaking its ID/order before movement. No match still loses Huxiao, completing acquisition with Obtained=false. No fake card is produced. Dead owner/source loss/winner cancels unissued search, while real already-issued move/children drain before cleanup.
- The generic named-card op supports actual Silver Lion removal recovery/replacement as a tightly proven equipment-loss child. That combination, nested gain Damage/Dying/rescues, and beneficiary death were statically reviewed and not executed here.
- The current API has no gender field. Female derives only from current official biography calling her Guan Yu's daughter. Current page classification is ordinaryOther; neither historical SP branding nor an old classic skill definition substitutes for this current text.
- These are engineering defaults and deferred practical acceptance points, not quotations of an official FAQ. All compilation/loader/game/check/native/UI/benchmark states remain false.

Draft source-loss variants use the existing legal ReplaceSkillsOnAwakening observer producer, actual owned-skill selection and finish commands. Its real MaxHP reduction is retained: post-Silver-Lion Snow still freezes X=max(1,lostHP); no fake state is written. LoseOwnerSkillsAndGrant is activation-only and is not used in observer fixtures.
