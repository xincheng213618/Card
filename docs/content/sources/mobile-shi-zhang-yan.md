# 势张燕（三国杀移动版）

核对日期：2026-10-24。资源标识 `mobile:shi-zhang-yan`，群势力、男性、4体力，规则产品线 `sanguosha-mobile`，版本 `mobile-shi`。

官方依据：[移动版武将详情 hero-detail-622](https://www.sanguosha.cn/pc/hero-detail-622.html)。已直接读取原始HTML的 `ul.skill-nav` 和 `ul.skill-info` 两个节点；骁戈在 `li.hide` 中，正文抽取可能遗漏。正式技能是飞径、骁戈，不能套用OL张燕的肃济、朗蹈。

飞径：你的伤害类锦囊可以当【杀】使用或打出。每回合限两次，你使用【杀】指定唯一目标时，可以选择你与其之间的一条路径，此路径上的所有角色须同时展示并依次弃置一张手牌。然后你可以选择一种颜色，弃置此颜色牌的角色成为此【杀】的额外目标。路径：使用（发动）者与目标（选定）者之间的，单向遍历其间所有角色的一条路线。“路径上的角色”不包括首尾角色。

骁戈：锁定技，你使用的【杀】：对因“飞径”成为额外目标的角色造成伤害时，防止之，然后你回复1点体力并获得其弃置的牌；若仅指定了一名角色为目标，结算结束后，你视为对其使用一张【决斗】。

## 规则与结算边界

- 飞径转换只接受引擎中实际实现伤害效果的锦囊：决斗、火攻、南蛮入侵、万箭齐发、闪电、奇正相生、水淹七军、出其不意；不按描述文字猜测，也不把所有锦囊泛化为伤害牌。
- 杀触发配置沿用引擎的完整三杀兼容集合；既有 `ProgramCardKindMatch` 将它同时匹配寒冰杀，运行时仍按全部四种原生杀资格处理。
- 路径按当前真实桌面座次的两个方向计算，排除发动者、原目标及已死亡的角色。每个实际回合共用两次机会，插入出牌阶段不会重置。
- 各路径角色先在自己的冻结手牌中私下承诺一张可弃置手牌。其他人的承诺和原手牌身份不会进入公开快照；全部承诺完成前不提前展示或移动。没有可弃置手牌的角色不凭空支付。
- 全部承诺完成后一次公开展示，再按所选路径顺序逐人执行真正的自身手牌弃置及子结算。原实体已离开手牌时不替换另一张牌重付。
- 颜色选择只读取已经实际弃置的实体及其已公开颜色；可不增加目标。额外目标保留真实杀的使用者、提供者、材料、原目标和原生多目标顺序。
- 骁戈只防止这次杀对飞径所增加角色的真实伤害，随后原生回复1点体力，再取得该角色当时弃置的确切实体；此牌已离开弃牌堆时不换取其他牌。已支付的弃牌、回复和获得子结算均保留原frame及冷恢复返回。
- 原杀完成时仅有一个实际指定目标，才另行视为对其使用决斗。复用共享 `ProgramVirtualOrdinaryTrickOrigin`，保留独立原生Use、零实体、原使用者与目标、无懈、决斗响应和类型化返回；原杀的物理付款不会再付一次。
- 原杀完成窗与攻击游标留在原帧上；发动时把当时的 active 值与目标游标写入本地收据和标量事实，决斗执行时挂起该旧游标。独立原生决斗完整返回后先恢复确切旧值，再结束骁戈原帧，使原杀的后续完成候选仍能正常暂停与恢复。
- 手牌承诺投影接入既有原生选牌草稿与确认；技能区显示本回合飞径次数、路径承诺进度，以及骁戈防伤和决斗次数。
