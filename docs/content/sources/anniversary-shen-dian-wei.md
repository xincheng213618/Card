## 当前正式技能

**捐甲**：锁定技，游戏开始时，废除你的防具栏，然后你获得一个额外的武器栏。

**挈挾**：锁定技，准备阶段，你在剩余武将牌堆中随机观看五张武将牌，然后选择其中任意张当武器牌置于你的装备区中，此类武器牌拥有如下规则：1.无花色点数且攻击范围为牌上的体力上限；2.武器效果为牌上描述中含有“【杀】”的无类型标签或仅有锁定技标签的技能；3.此牌离开你的装备区时你令其销毁。

**摧決**：每回合对每名角色限一次，出牌阶段，你可以弃置一张牌，然后对一名攻击范围内距离最远的其他角色造成1点伤害。

当前武将页与上线公告的语义一致；保留当前武将页使用的“挈挾”“摧決”字形。未采用早期斗地主限时版本、欢乐专属改写或二手测试稿。

## 与已有 OL 版的关系及能力复用

仓库另有 `ol:shen-dian-wei`，其来源是 [OL 官方武将页](https://www.sanguosha.com/hero/229)，并不把两条产品线合并为一个内容身份。十周年三技能使用独立技能 ID、武将 ID、版别及来源；三个结算能力与现有正式 OL 版等价，因此直接复用原生指令。

- 捐甲复用 `alterEquipmentSlots`：防具栏容量设零、武器栏容量设二。
- 挈挾复用 `equipSampledGenerals`：按实际当前将池排除场上主副将与已被消耗为武器的武将来源，随机抽取至多五张。可选零张；选中的武将生成真实无花色、零点数武器实体，攻击范围来自武将基础体力，装备出入通过既有真实移动、技能授予及销毁流程。
- 技能筛选仍按正式规则要求检查武将技能正文的“【杀】”。当前 `SkillTag` 仅有 `None`、`Locked`、`Lord`、`Limited`、`Awakening`、`Conversion`；排除后四者正好等价于十周年“无类型标签或仅有锁定技标签”，不需要另造过滤器。
- 摧決复用 `discardSelected` 后的 `damageFarthestCharacter`：真实弃置后按当前攻击范围、实际席次距离重新选择最远角色；每目标每回合的次数使用当前技能 ID 独立记账，伤害走原生伤害、濒死及返回流程。

本次是既有能力的纯内容复用，没有新增帧、事件、枚举或待续状态，也没有提高格式、规则或内容包版本；不复制人物定义快照或既有武将武器机制的恢复检查。
