## 规则落实

妙略开局获得两张游戏外的实体瞒天过海，由共享原生卡牌能力处理真实实体注册、移动、用牌、无懈可击和手牌上限排除。受伤按一次伤害事件提供一次选择，不按伤害点重复；摸两张，或指定智囊牌名后从牌堆搜索一张，牌堆无匹配时检索弃牌堆。两处都无匹配时不制造实体、不改为摸牌。搜索是获得，并不作为摸牌。

瞒天过海被丰姿等能力增加结算时，每轮先完成所有目标的获得，再依次完成该轮赠牌及其子结算，之后才开始额外一轮；每轮独立处理各目标的无懈可击。真实用牌与实体支付仍只有一次，赠牌中途恢复不会重复支付。

迎驾复用共享实际回合锦囊使用账本，再按有效牌名分组检查至少两张；实际使用无懈可击计入，单纯打出不计入。任意实际回合结束后检查，限定技一次。弃置一张当前合法手牌的真实支付和后续子结算留在原帧；子结算完毕后选择存活受益者并签发原生额外回合。该回合真正开始前，精确匹配最后生效的额外回合签发票据后摸两张，再进入新回合，不提前在选择受益者时摸牌；受益者不必拥有迎驾。已支付的签发义务不依赖原技能仍在。

技能栏展示本局迎驾是否已用，以及本实际回合同名锦囊最高使用张数。持有而未使用的瞒天过海不增加进度。
