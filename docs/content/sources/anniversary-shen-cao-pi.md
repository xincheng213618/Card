## 规则落实

阴鸷在每个实际出牌阶段限一次。按发动者对目标的本局真实发动次数确定 X，上限3；先完成本次原生摸牌及其子窗口，再签发至目标回合开始失效的非锁定技压制和手牌使用／打出收益。每个真实行动仅计一次，闪等兼具使用含义的回应不会重复发放。目标下一个实际回合内只可使用或打出本回合真正获得的实体牌；以已有实际手牌获得口径追溯 Processing 前来源，自身装备或私有牌堆进入手牌也可构成获得。目标对发动者实际造成伤害后，解除对应的回合限制。

刻名的受伤分支读取伤害来源武将牌上的同一受伤时机技能，包括双将的两张武将牌；没有时才在已注册的标准／十周年曹姓武将技能中随机选取。技能作为原 `DamageTriggerWindowFrame` 的真实一次候选执行，保留原伤害帧、伤害牌实体、触发绑定、费用、次数与子帧，不永久授予技能。随机状态只保存在原技能帧的私有冻结收据。

造成伤害的分支预订目标在准备／出牌／结束阶段内**下一次真实技能发动**；无收益的那次发动同样消费机会。源技能实际完成后才结算，原技能直接产生的真实摸牌和使用牌名冻结在原帧与 typed echo 子帧内；曹丕可从牌堆匹配同名实体摸牌，合计至多5。没有匹配实体则不凭空造牌。转换与原生装备真实发动复用既有统一发动边界；受标记技能嵌套其他技能产生的收益分别归于其真实原子发动，不冒充外层的直接收益。公共事件只记录数量、来源与完成边界，不公开私有牌名、实体结果或内部随机状态。
