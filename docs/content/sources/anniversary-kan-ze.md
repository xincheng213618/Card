# 周年／一将成名阚泽：现行官方宽释

核验日期：2026-10-23。可玩 ID `anniversary:kan-ze`，`character:kan-ze`，`rulesetId=sanguosha-anniversary`，`variantId=ordinary`；吴势力，男，3 点初始体力／体力上限。

## 一手来源与版本选择

- [当前官方武将页：阚泽，hero548](https://x.sanguosha.com/hero/548.html)：两套皮肤的技能栏均给出完整下书、宽释，宽释结尾明确为“每回合限触发一次”。本实现采用此现行文字。
- [同产品运营频道 2021-11-26 正式首发公告](https://sanguosha.game.360.cn/211282862/211282866/211449452.html)：标题“[感恩热力] 11.26-12.2 新将阚泽 刘禅&樊稠动态 登录领阚泽宝箱！”，发布时间 2021-11-26 11:28:28。其“新品武将阚泽”表列吴、体力3、男、慧眼的博士、天下归心，出现于身份模式和欢乐成双；注明首周正式上线，通过感恩热力活动或阚泽宝箱获得，概率表也实际列出阚泽。此为正式开放证据，不是测试公告。
- 首发公告宽释尾句是“限触发一次”，当前 hero548 已明确为“每回合限触发一次”。没有另行找到该尾句调整的独立修订日期；不把首发的歧义尾句覆盖现行武将页，更不擅自声称两版完全一致。

## 当前完整技能

**下书**：出牌阶段开始时，你可以将所有手牌交给一名其他角色，然后该角色亮出任意数量的手牌，你选择一项：1.获得其亮出的手牌；2.获得其未亮出的手牌。

**宽释**：结束阶段，你可以选择一名角色，直到你的下回合开始，该角色于同一回合内受到第2点伤害后，其回复1点体力。（每回合限触发一次）

原文来自上述当前官方详情。句中“每回合”指实际回合，而不是阚泽自己的回合，亦不是每份授权总共一次。

## 与已收录 OL 版的区别及复用

- 下书的给牌、受赠者展示任意数量、阚泽选择获得展示或未展示一侧，与现有 `ol:xiashu` 相同，直接复用 `GiveAllHandAndResolveXiashu` 的原生整手给出、私有展示选择、公开亮牌和实际取得流程；不另写一套引擎或重复人物定义快照。
- 现有 `ol:kuanshi` 处理“大于1点的单次伤害”，防止该伤害并欠下阚泽下个摸牌阶段。周年版没有这些防伤、跳摸语义。它在同一实际回合累计实际受到的伤害跨越第2点后，执行真实回复1。
- 累计依据实际 `DamageApplied` 数值，不是损失体力、当前血量差或受到伤害的次数。1+1 与单次2都可越过阈值；单次3也实际经过第2点，只触发一次。授权前在该实际回合已经受到2点或更多，再受到第3点不能冒充第2点。
- 宽释不提前回复来伪装防伤或免死。原生伤害、濒死／死亡完成后，再在 `afterDamageApplied` 结算；死亡者不会被该回复复活。当前官方未给更细的特殊时序 FAQ，这里遵循既有原生伤害后窗口。
- 授权在阚泽下个真实回合的 `TurnStarted` 事实处失效，该事实早于翻面跳过整回合的分支。每个实际回合独立限制一次；插入回合也有各自实际回合编号。

## 运行边界

- 授权公开记录仅含来源技能／实例／内容 hash、原结束阶段帧、目标和实际回合；不包含私牌。
- 在实际伤害发生时冻结伤害前后累计值、原生 DamageFrame、授权及实际回合；原生伤害后窗口只发行对应候选，不根据后续嵌套伤害重算旧机会。
- 回复的已绑定见证保存在其原 `ProgramSkillFrame`；该指令编译为既有 `RecoverProgramInstruction`，实际执行原生 `Recover1`，复用原有回复替换、健康子窗和类型化返回。已发行的见证不因后续来源失技而被重新支付或改写。
- 本次不改通用规则 epoch、技能 JSON schema 或内容包版本。
