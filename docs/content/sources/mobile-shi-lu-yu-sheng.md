## 规则与结算边界

- 原始发动可指定任一存活角色，包括本人。X使用这次所选颜色实际进入受益角色手牌的实体数量，不能使用展示总数代替。
- “每阶段限一次”使用实际阶段标识，与回合历史分开记录。达到X张真实失去牌后，本阶段只退还一次使用次数；第二次收益不会再次重置退款标志。同一回合的另一个实际出牌阶段有独立机会。
- 解锁后再次发动，才排除本回合已经通过润微获得过牌的角色；回合历史不会随新阶段清空，但新阶段的正常首次发动可以重新选择该角色。
- 阶段末仅处理本阶段由陆郁生本人通过润微获得、此时仍在本人手牌且可以弃置的原实体。其他受益角色不会被强制弃牌；已使用或移出本人手牌的牌不付第二次费用。阶段末义务使用既有实际阶段末框架，原技能实例失去后仍保留已发出的义务。
- 展示数在1至min(5,当前牌堆数)中选择，按牌面颜色分组；所选同色牌同时交付，未选择的展示牌置入弃牌堆。官网未另列未获得牌的处置FAQ，此项沿用展示牌结算的处理区去向。
- 霜怀使用真实战斗距离及每实际回合一次的原生技能次数。跨回合记忆上次已发动的受害角色；第一次无记录视为不同目标。
- 获得桃使用弃牌堆中的真实桃，不防止原伤害；防止分支只影响它原本绑定的待结算伤害。同目标双方分开进入原生摸牌尝试及其子结算；不同目标进入真实体力损失、显现替代或濒死流程。
- 支付后的颜色交付、桃获得、阶段末弃牌、摸牌和体力损失均保留原指令帧、实际来源、内容哈希和实际阶段/伤害身份。代表性检查包含冷恢复与命令回放，不用吞掉额外提示掩盖重复支付。
