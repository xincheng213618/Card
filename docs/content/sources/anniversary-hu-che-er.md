# 周年服胡车儿：正式版本与实现说明

核验日期：2026-10-24。内容标识 `anniversary:hu-che-er`，群势力、男性、4体力；技能为盗戟、负重。仓库已有的谋胡车儿使用孔武，属于不同正式版本，不复用其技能。

首发公告的负重规则与当前武将页不同。首发版本为一重增加手牌上限、二重减一距离、三重增加摸牌，四重在回合开始时伤害并移除全部标记。本次不采用该旧规则：当前版依次为摸牌阶段多摸一张、向外距离减二、手牌上限加三，四重在结束阶段造成伤害后仅移除四枚。当前改版的独立上线日期尚未查得；当前正式官网武将页作为规则依据，首发公告仅作为正式开放与获得方式依据。

## 真实时机与实体

盗戟查询原生 `CardUseDeclaredEvent`，按实际声明的使用者分别认定本局第一张武器；装备牌付款后的 `CardUseTargetsFinalized` 在装备落槽之前提供发动机会。拒绝发动也不会把下一次使用变成第一次。初始装备、直接置入装备区、普通转移与纯技能付款均不冒充真实武器使用。

选择获取时，由原用牌帧的真实付款素材进入原生获取请求，获取完成凭证和移动子窗均留在发动盗戟的原程序帧。原武器离开处理区后，原使用照常完成，不重复安装已被获得的实体。多实体转换所得的武器按原生用牌素材整体获取；零实体虚拟武器没有可获得的实体时只提供禁杀选项。这是仓库对转换牌的实现解释，未冒称官方补充裁定。

禁杀绑定当时的真实回合与武器使用者，同时限制普通杀、火杀、雷杀的真实使用和纯打出；真实请求杀、响应杀亦遵守该限制。技能支付、弃置等未被当作使用或打出。此已发行效果持续至本回合结束，不因发动者随后失去盗戟而提前失效。

## 负重的逐批结算

负重以原生获取批次为单位：同一批真实获得多张手牌只增加一枚重，不同真实子批次分别增加。一次原生摸牌调用可能因底层逐牌移动产生多个物理批次，复用 `NativeDrawInvocation` 的完整逻辑摸牌凭证，在其经过验证的最后一个批次结算一次，不按每张牌增重；各次独立摸牌调用仍分别计算。获取的原始来源通过处理区连续移动回溯；自己的手牌经过处理区回到自己的手牌不算新获取。直接获得、真实转移、原生摸牌均可符合条件，单纯请求但没有实际手牌获得不会产生标记。

回合外依据批次冻结的真实回合拥有者判断，不使用临时阶段操作者代替真实回合拥有者；自己的回合已经正式结束后的获取也属于回合外。开局发牌不补造回合外获取触发。以上属于仓库在原生回合与获取模型上的解释。

达到一、二、三枚时分别启用普通摸牌阶段数量加一、向其他角色的物理距离减二、手牌上限加三；各效果累计，距离仍遵守原生最小值和其他距离规则。自身距离、其他角色向胡车儿的距离不受减二影响。

至少四枚时，在自己的真实结束阶段选择一名其他存活角色，经过原生伤害、伤害观察者、濒死与后续子窗，返回同一原程序帧后移除四枚。伤害使用正常防止、转移及濒死流程；按先发行并完成伤害步骤、再移除四枚的顺序解释，即使伤害被防止也完成后续移除。超过四枚的余量，以及伤害子窗中新获得的重均不清零。此项顺序解释未发现官方独立 FAQ。

## 验证范围

聚焦实际武器使用与两选、第一张机会消耗、真实杀使用及打出的禁止和失效时机、真实逐批手牌获取、四档动态数值，以及结束阶段原生伤害后扣除四枚。新状态的代表性恢复点设在盗戟已付获取的原生子窗。验证沿用现有 Core 名称过滤与恢复工具，不增加专用运行器或静态定义快照。
