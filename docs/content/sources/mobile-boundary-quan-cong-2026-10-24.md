# 移动版界全琮

核对日期：2026-10-24。产品线为《三国杀移动版》身份模式，采用[官方界全琮武将页](https://www.sanguosha.cn/pc/hero-detail-496.html)当前充能版「邀名」。人物为吴势力、男性、4体力；独立身份 `boundary:quan-cong-mobile`，技能 `boundary:yaoming-mobile`。这与仓库已有 OL 经典全琮的每回合一次邀名分开登记。

官网正文规定：剩余次数初始2、上限4；在出牌阶段或受到伤害后，可弃置手牌数不小于自己的其他角色的一张牌，或令手牌数不大于自己的一名角色摸一张牌。选择不同于上次记录的选项时返还一次并清除记录，每受到1点伤害补充一次。

工程裁定与实现：

- 发动消耗一次。首次选择记录该选项；重复同项继续消耗；选择异项先支付本次，再返还一次、清除旧记录。清除后下一次选择重新记录。所有补充均封顶4，跨阶段、回合保留，按真实技能实例隔离。官网没有说明失去后重新获得的状态继承，项目为新实例重新初始化。
- 「受到伤害后」按一次实际伤害事件提供一次可选发动机会；事件的实际伤害点数先一次性补入余量，再显示可跳过的选项。这是将「受到伤害后」与「每当受到1点伤害后」两段文字结合的工程解释；不是把3点伤害扩展成3次可选发动。失去体力、被防止的伤害不补充。
- 选项和目标在作出选择时按当前真实手牌数核对，等于时同时满足两种比较。弃置仅能选择其他角色，范围为手牌、装备区；摸牌允许自己。技能不把判定区当可弃的「牌」。后者沿用身份技能默认手牌/装备牌范围，官网未单列牌区。
- 牌区、目标和选项通过共享命令校验。暗手牌沿用匿名槽位，装备展示真实实体。实际弃置通过原生逻辑弃牌记录，发起者和执行者为全琮；摸牌走原生摸牌子帧。已支付的选择与其原生子窗保存在原 `ProgramSkillFrame`，恢复不重复消耗次数或移动实体。
- 公共状态输出 `yaoming-remaining`（0至4）与 `yaoming-pending-option`（0无记录、1弃牌、2摸牌）；提示同时说明余量和记录。状态由公开标量事实派生，没有额外待决对象。

针对检查 `BoundaryQuanCongChecks.ChargedOptionsEqualHandsDamageRechargeAndPaidDiscardCold` 覆盖等手牌、自己摸牌、耗尽次数、单次多点伤害补充、异项返还和清除、实际装备弃置、已付移动子窗的冷恢复与上限4。沿用共享内容注册、命令、隐私、回放和移动机制的既有检查。
