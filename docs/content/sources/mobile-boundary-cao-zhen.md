# 移动版界曹真：司敌秘密预测

核对日期：2026-10-24。采用[移动版官方界曹真页（435）](https://www.sanguosha.cn/pc/hero-detail-435.html)当前完整技能正文。魏、男性、4点体力，独立身份为 `boundary:cao-zhen-mobile`；不复用经典司敌的牌堆、颜色或出杀限制。

本人实际使用非延时牌结算完毕后，可选择一名尚无本人待验证预测的其他角色，再秘密指定一名存活角色为其预测目标。记录没有回合期限；已经消费的角色可以重新预测。目标选择、待验证人物和目标对应表只提供给该技能拥有者，公共席位不放预测标记。界面自己的技能进度和详情来自同一份私有视图。

被预测角色下一次真正使用非延时牌时，以该次原生使用记录的实际指定目标集合判定：只有唯一目标且等于预测对象才命中；延时锦囊不消费记录，首张未命中也消费，不能等待以后再命中。闪、无懈等规则上属于“使用”的响应经过现有原生响应使用管线；单纯打出杀等不冒充使用，零目标的使用不能凭空制造命中。

原生无中生有、酒和装备的指令参数省略自身目标；司敌在核对原使用声明、原帧与实际使用者后，将它们原本的自身效果视为指定自身，而不改写已经接受的公共用牌记录。真正没有角色目标的闪和无懈不套用此规则。

预测自己时摸1张且保留原牌效果。预测其他人时可摸2张且保留原牌效果，或者取消原牌。取消后仅在当时没有任何角色处于濒死状态时对原使用者造成1点伤害。取消证明留在原 `CardUseFrame`，原实体、移动、用牌完成和子结算依旧沿用原生流程；收益和伤害使用普通程序节点，不新增另一套摸牌、伤害或濒死 pending。

原生无中生有、酒和装备以空命令目标表示自身受益。本规则绑定原用牌及声明后按自身目标判定，保持已接受动作原样。装备的预测窗口在原生安装前建立；取消时仍由原处理区实体及原用牌完成流程收尾，不能先安装再宣称取消。

秘密对应表保存在拥有者状态中，由接受过的私有选择命令重放恢复。当前选择只保存在所属程序帧。记录创建事件不含被预测者和预测目标，结果事件也不写入原预测目标；不会靠隐藏界面标记而把目标泄露到公共事件历史。快照中的预测列表仅对拥有者创建，并在既有视图冻结边界冻结。
