## 执行对应

- 每个**实际回合**按已成立的、有来源 `DamageApplied` 事实判断是否已造成过伤害。不限杀、决斗或自己回合，也不是对每名目标分别首次；无来源伤害不冒认来源。首个实际伤害即使未发动截刀，也会排除该回合后续伤害。
- 用原伤害拥有者下的来源专属 `BeforeDamageProgramWindowFrame` 选择 `0..X`；X在发行该选择时冻结，主 pending 不另挂全局状态。之后沿同一原伤害继续原生 finalizer，再进入正常受伤窗口。增加值进来源增伤阶段，白银狮子等目标防具仍按原生流程限制最终实际伤害。
- 冻结的是**选择增加的数值**，不是最终体力扣减；例如选择+2而原生伤害被白银狮子限为1，结算后目标存活仍支付两张牌。真实濒死／救援／死亡完成后才判断目标是否阵亡，不提前弃牌或以减体力代替伤害。
- 目标未阵亡时，从来源的实际可弃置手牌和装备中弃所选加值数张，不足则弃尽；原生禁止弃置和逻辑弃置改道照常处理。此不足支付解释同时见[辅助玩法说明](https://bkso.baidu.com/item/%E5%BF%99%E7%89%99%E9%95%BF/23723291)，并非另有官方FAQ。已发行的责任不因随后失去截刀而消失，付款和子移动的收据保留在原程序帧。
- 原来源选择凭证保留选择时的原目标；若后续原生转移改变目标，增加值仍属于同一伤害，伤害后弃牌按原伤害拥有者、连环游标、来源及原生转移事实绑定**最终实际受伤角色**。不会要求最终角色等于选择时的目标而漏掉转移后的责任。技能实例、内容哈希、原生伤害帧及 typed return 继续核对，未引入新的规则版本、JSON schema 或全局 pending 副账。
