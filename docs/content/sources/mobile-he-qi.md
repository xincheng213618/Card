## 实现边界

绮胄只配置既有 `equipmentSuitSkillGrants`：一个花色为马术、两个花色另有英姿、三个花色另有短兵、四个花色另有奋威。装备花色变化、能力资格、已发行技能的返回和失效处理沿用该共享机制，不增加另一套授技实现。

闪袭使用现有实际出牌阶段次数限制。材料是仍在手牌中的一张基本牌，颜色按拥有者当时的有效花色计算；原生弃牌限制继续适用。目标必须为攻击范围内有手牌或装备牌的其他存活角色。

执行顺序为真实支付本人的红色基本牌，原生选择并弃置目标的一张手牌或装备牌，完成该弃牌产生的子窗，再观看当前手牌。敌方手牌选择沿用隐藏位置选择，支付前不会因选择卡牌而公开其手牌。观看依据本次原技能帧的实际 logical-discard 凭证与所弃原实体；如果没有实际完成目标弃牌，不制造观看结果。弃置闪时贺齐观看目标手牌；弃置其他牌时目标观看贺齐手牌。查看内容仅出现在相应观看者的私有视图，由该观看者确认后继续；公开事件只记观看方向和数量。

待确认的查看内容保留在原技能帧，使用只读集合，沿用现有命令校验、冷恢复、回放与视图投影边界。未改变全局规则 epoch、回放格式、技能 JSON schema 或内容包版本。

OL 版绮胄的技能组合为短兵、英姿、奋威、澜疆；其闪袭为反向攻击范围条件下的共同展示、弃闪与获得未展示牌。该规则不与本条目的移动版合并。
