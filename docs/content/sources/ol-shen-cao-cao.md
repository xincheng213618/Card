## 正式规则

**归心**：每受到一点伤害，可以从每名其他角色的区域里随机获得一张牌，全部结束后翻面。每次发动只选择一个优先区域，所有角色共用此次优先序：

| 首选区域 | 回退次序 |
| --- | --- |
| 手牌 | 手牌 → 装备 → 判定 |
| 装备 | 装备 → 手牌 → 判定 |
| 判定 | 判定 → 手牌 → 装备 |

随机仅发生在依此次序找到的首个有合法牌的区域内，不是将三个区域合并后随机；也不逐个角色重新询问选牌。

**飞影**：锁定技，其他角色计算到你的距离增加一。

## 实现边界

复用移动版归心所用的真实受伤点窗口、角色席次冻结、合法区域牌筛选、原生逐人移动及移动子窗、最后翻面。新增的统一优先区域与逐人随机发票均留在原 `ProgramSkillFrame`：暗牌候选、选中实体和内部 RNG 状态只在可信恢复状态中保存；公开自定义事件不含这些内容。不会在已完成一人取牌后重掷、重付或提前翻面。两点伤害仍产生两个独立可选发动机会，可重新选择第二次的优先区域。

本条不收录活动模式的随机整区域获得，也不把经典均匀混合区域随机取牌或移动版逐人选择区域、公开牌和暗手牌位的流程当作 OL 规则。
