# 欢乐三国杀·神华佗

`happy:shen-hua-tuo`，欢乐规则 `sanguosha-happy` / `happy-god`，神势力，男，初始体力与体力上限均为 1。与移动版“五灵/游医”、十周年“静域/滤心/寰道”是不同规则的正式角色。

## 采用规则及解释

- **济世**：开局得到三个药，数量最多三个。任一角色进入濒死时，可以移去一个药，使该角色回复至一点体力。自己实际回合外每失去一张红色手牌，增加一个药。手牌上限加三。技能没有锁定技标签，保留既有技能失效语义。
- **桃仙**：一张红桃牌可以作为桃使用；其他角色实际使用桃时，自己摸一张。没有增加“纯打出桃”的能力。依“牌”而非“手牌”的用语，材料采用通常的手牌和装备区实体牌，不包括判定区牌或任意私有牌堆；救援中的桃是使用，走现有原生救援使用路径。
- **神针**：自己的实际回合开始时，可以移去 X 个药，随后选择回复或失去体力，并指定恰好 X 名不同角色，各执行一次一点体力变化。可以指定自己。根据当前未限定正数的 X 及首发辅助文本的“任意个”，保留选择零枚的合法无效果分支；零枚不制造药付款、回复或失去体力事实。没有查到明确排除零的同产品官方裁定。正数 X 上限同时受可支付药数与当前可选角色数约束，不将“X 名”改成“至多 X 名”。

## 实现边界

回合外红色手牌损失在原生移动当时冻结原持有者的有效花色、原始手牌区和真实回合拥有者；之后获得药时读取该原始移动，不按之后的装备或技能状态重新计算颜色，也不把同一张牌的处理区后续移动再次计算。药上限为三。

济世保存当前原生濒死帧、进入窗口、实际候选、技能实例及已付药收据，先支付再通过原生回复至一点。神针只为数额和目标菜单保留原 `ProgramSkillFrame` 收据；药已支付后恢复不会再次扣除。目标数量与每个目标序号有真实标量事实，后续回复、逐目标失去体力和濒死子流程复用原有指令及类型化回口。新增事件、移动事实扩展均为标量，没有新增公开的私有手牌候选集合。

聚合行为检查覆盖真实标记费用、零枚无效果、不同目标与回复/失去体力、代表付款后冷恢复、红桃装备或手牌的原生救援使用及他人桃使用摸牌；不重复现有通用救援、输入拒绝或配置快照矩阵。
