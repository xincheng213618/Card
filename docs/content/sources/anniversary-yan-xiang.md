## 当前完整规则

**谕诤**：出牌阶段每个选项各限一次，你可以令一名角色选择一项：1. 将手牌数调整至与全场最少角色相同，本轮下 X 次使用或打出牌后摸两张牌（X 为以此法弃置的牌量）；2. 摸等同于体力上限张牌（至多为 5），本轮增加等量手牌上限，且本轮至多可以再使用等量张牌。

**邃识**：一名角色的结束阶段，若其手牌数大于等于体力值，你可以声明一种伤害牌牌名，其可以将一张牌当此牌使用，若此牌造成伤害，受到伤害的角色不能使用与造成伤害的牌颜色相同的牌直到其回合结束。

## 实现口径

- 谕诤由阎象选择一名存活角色，**由该角色选择**本真实出牌阶段尚未使用的选项；各项次数属于阎象及其技能实例，跨目标共享，新的实际出牌阶段重新计算。
- 选项一在目标选择该项时确定全场存活角色最少手牌数，目标自行选择可弃的手牌支付。该目标也在最少值计算范围内，因此调整只需要弃置。遵守现有弃牌保护，能弃多少弃多少；X 复用 `NativeLogicalDiscardMaterialCompletedEvent` 与原始调用凭证，按本次实际完成的手牌弃置数量计算，不按期望弃牌量或普通使用后的进弃牌堆数量计算。
- 选项一奖励按本轮后续真实使用或打出的**完成**事件发行原生摸二；响应使用的闪／无懈等属于使用，也可能经过打出完成窗，同一租约与动作 ID 只扣一次、奖励一次。奖励开始前冻结本次应结算的租约，原生摸牌及移动子窗回到原帧后继续，不会恢复后重新支付已完成成本。
- 选项二以发动时 `min(体力上限, 5)` 为 N，发行原生摸 N，同时得到本轮手牌上限加 N 与后续最多再使用 N 张的限制。按“等量”解释，后两项取请求摸牌数 N，摸牌替代或牌堆不足不会另外改写该额度；这是按正文作出的实现解释，未找到官方 FAQ 对替代摸牌另作规定。
- 使用额度复用现有实际使用声明账本，包含响应使用，不包含纯打出。已经获准的第 N 次真实使用可以完成其原生流程，不能因为声明已入账而在同一次使用的后续校验中拒绝自己。原生使用者替换按既有实际使用者链归属，不将供牌人简单当作使用者。
- 已发行轮次效果独立于原技能是否仍在身上，不授予或替换技能。多份选项二手限加成相加，各自的剩余使用限制分别有效，不能用后一份刷新前一份剩余额度；多份选项一各自消耗后续动作并奖励。此处按多份已生效效果并行解释，未宣称存在官方叠加裁定。
- 邃识使用真正的 `TurnEnding` 结束阶段入口，包含阎象自己与其他存活角色的结束阶段；不替换成 `AfterTurnEnded`。阎象声明牌名后，结束阶段角色自行决定是否使用、自选一张手牌／装备牌与原生合法目标；阎象不会替其他角色选择暗手牌。
- 伤害牌牌名沿用本项目刘理、刘永等同产品术语口径，并参考[伤害牌术语页](https://wiki.biligame.com/sgs/%E4%BC%A4%E5%AE%B3%E7%89%8C)。此页属于二级术语来源，**不是官方 FAQ**。基础环境提供杀（含三种杀的外观）、决斗、南蛮入侵、万箭齐发、火攻；武庙洪流、奇正相生仅在本局确实存在该牌环境时加入。延时锦囊闪电不列入该术语范围。
- 所有邃识用牌经过原生实体付款、使用、目标／无懈／响应、伤害与整张牌完成流程；多目标伤害牌保持完整原生目标组，杀沿用现有距离、目标数与禁止规则，未添加无距离限制。支付实体保留实际有效花色、点数与颜色，不以直接伤害或虚构无素材牌代替。
- 造成真实正伤害时按这张原生使用的最终 `Action.EffectiveIsRed` 发放受伤角色的同色使用禁止。无色牌不凭材料伪造颜色；已改变为无色的转换外观按最终外观判断。限制只针对使用，纯打出仍按原规则处理；有效期到受伤角色自己的实际 `ActualTurnCursorReturnedEvent`，不会因另一角色回合结束而提前失效。
- 所有待定状态、目标与材料计划、原生摸牌结果及使用返回在原 `ProgramSkillFrame`；使用子帧保留 typed origin，集合在写入时冻结。原生付款与完成事件匹配原帧、使用 ID、动作 ID 与材料来源；静态形状在 loader 校验，续接复用内容哈希、当前原父帧与动态成本校验。
