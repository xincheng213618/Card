## 完整正文

**诛佞**：出牌阶段限一次，你可以交给一名其他角色任意张牌，这些牌标记为“隙”，然后你可以视为使用一张不计次数的【杀】或伤害类锦囊牌，然后若此牌没有造成伤害，此技能本阶段改为“出牌阶段限两次”。

**封乡**：锁定技，当你受到伤害后，手牌中“隙”唯一最多的角色回复1点体力（没有唯一最多的角色则改为你摸一张牌）；当有角色因手牌数改变而使“隙”唯一最多的角色改变时，你摸一张牌。

## 补充解释的层级

- [同产品 BWIKI 伤害牌术语](https://wiki.biligame.com/sgs/%E4%BC%A4%E5%AE%B3%E7%89%8C)（2026-07-30 更新）明确：杀包含火杀、雷杀；伤害类锦囊不包括延时锦囊。故这里提供原生伤害杀族及当前牌环境的伤害普通锦囊，不提供闪电；这一术语补充为二级图鉴，非官方专项 FAQ，也非因实现所用 builder 名字而缩小范围。
- [同产品 BWIKI 刘永](https://wiki.biligame.com/sgs/%E5%88%98%E6%B0%B8)补充：唯一最多的改变包括产生、消失、转移。没有正数“隙”时也没有唯一最多者。
- [2022 玩家解析转载](https://game.xiaomi.com/viewpoint/1125686238_1643625798829_134)将“隙”解释为直到离开最初受赠者手牌区；[同产品实战攻略](https://a.4399.cn/gl/53837646_127670.html)的给闪、响应失闪、再摸一张例子与此一致。实体离开原受赠者手区时移除这一标记，之后回手不会自动重获。未找到官方专项清除 FAQ，文档不将二级解释称作官方裁定。
- 官网写“任意张”且未写至少一张，采用可选零张的字面解释；零张仍须指定其他存活角色，并且只有后来实际使用的牌无伤害，才增加本阶段发动上限。拒绝使用不会凭空增加次数。
- 原生杀不计次数，但保留技能用牌目标合法性和攻击范围验证；不是直接造成一次技能伤害。普通锦囊保留原生目标模板、响应、取消、真实伤害与整牌完成过程。
- 未造成伤害以这一次真实牌使用的完整履历判定：转移、连环传导、决斗反向伤害等属于该牌时仍计；其他独立技能伤害不借祖先关系冒认为该牌伤害。增加的额度最多使本阶段上限变为两次，不无限刷新。
- “隙”实体身份与私有待选清单不写入公共规则事实；持久牌标记为可信角色状态，待选、交付和原生用牌回执均在原 ProgramSkillFrame。公开事实只含来源、角色、数量、批次及公开的用牌结果。出牌阶段次数绑定真实阶段实例。
