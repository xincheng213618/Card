# 神太史慈（移动版正式技改）

采用移动版 2022-05-11 正式版本，4点体力，神势力，男性。内容标识 `mobile:shen-taishi-ci`，规则集 `sanguosha-mobile`，变体 `mobile-god`。

来源核对于 2026-10-22：

- [移动版官方技改公告，2022-05-10](https://www.sanguosha.cn/pc/news-detail-1213.html)：明确新版上线日期，逐条列出新版笃烈、破围、使命成功/失败及神著。此公告为采用版本的规范来源。
- [移动版官网神太史慈武将页](https://www.sanguosha.cn/pc/hero-detail-332.html)：笃烈与破围正文与正式技改一致；玩法概述中仍有旧版“杀无次数限制”的过时文案，神著采用上面的正式技改正文。

规则落实：笃烈只对体力严格更高的来源判红桃；围在太史慈自己的回合开始时同时前移一次，绕过太史慈本人，伤后移除。围持有者的回合开始时，可弃一张真实手牌造成伤害，或在其体力不高于自己时获得其一张隐藏手牌；只有实际执行后才授予该回合的单向攻击范围关系。使命成功授予神著；失败仅一次，回复至1、清围、弃装备。神著只接真实非转化杀的使用结束，二选一分别提供额外使用次数或禁止本回合继续使用杀。

不混用 2022 年技改以前的“杀击围防伤、无次数限制神著、荡魔”版本。
