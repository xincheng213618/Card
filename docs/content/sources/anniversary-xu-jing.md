## 完整正文

**赏誉**：锁定技，游戏开始时你获得一张【杀】并标记之，然后将之交给一名角色。此【杀】造成伤害后你和使用者各摸一张牌；进入弃牌堆后你将之交给一名本回合未以此法指定过的角色。

**才瑕**：当你造成或受到伤害后，你可摸至多X张牌（X为游戏人数且最多为5）。若如此做，你无法发动此技能，直到你累计使用了等量的牌。

## 实现口径与证据界限

- 赏誉标记是最初获得的真实实体，不是任意后来使用的【杀】。牌从牌堆取得、原生使用结算、进入弃牌堆、再次转交都有真实移动；技能不凭空重造牌。属性【杀】也按【杀】牌名族处理。开局在牌堆现存杀中随机获得一张，采用二级[玩家技能解析](https://www.bilibili.com/read/cv27671624/)的“随机获得”补充说明；官网未规定牌堆中具体取牌顺序。牌堆无杀时不伪造实体。
- 每次真实伤害触发一次整次奖励；使用者取真实用牌人而非被改写的伤害来源。许靖自己使用时，“你和使用者各摸一张”按两次顺序各摸一张保留。弃牌堆领取先等原生牌移动完成，同一实际回合的接受指定名单独立于此前开局、其他回合。
- 才瑕 X 取开局游戏角色数，上限5，不随死亡减少。可选择1至X张；不发动等价于不选择正数。此次选择的请求摸牌量 N 在原帧冻结，随后须累计真实使用 N 张牌。牌堆不足、摸牌替换时是否应按实得量计，未找到官方专项 FAQ；本实现按选择的请求量计，不把这个解释声称为官方裁定。
- 才瑕在真正使用声明／原生响应使用时累计；不把技能发动、纯打出、获得牌或摸牌当使用。触发才瑕之前已声明的当前牌不追溯支付新限制。恢复资格发生在第 N 张真实使用之时，故该牌后来造成伤害时可再次发动。
- 后续程序暂停在原 ProgramSkillFrame，实体与收牌人、请求摸牌量、真实用牌欠额和原生子返回分别有冻结回执。没有新规则版本门槛或独立 pending 侧表。
