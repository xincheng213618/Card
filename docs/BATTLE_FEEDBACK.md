# 战斗反馈与手牌延续

牌桌对已提交的公开行动显示飞牌、目标连线、伤害与回复数字、技能、判定、回合、濒死和阵亡反馈。表现层按出牌、攻击到达和结果安排动画，规则结算与玩家操作即时生效，动画不提交命令或自动确认响应。

## 牌桌表现

公开使用牌与响应牌从对应武将处进入中央，显示有效牌型与「使用／打出」说明。群体牌和后续响应分区呈现；关闭动画仍可查看静态公开牌。转化牌保留实体牌面与当作使用的牌型之间的区别。

普通摸牌与额外摸牌阶段显示牌背从牌堆飞向手牌区或角色，提示实际数量；其他玩家的新手牌牌面保持隐藏。判定反馈区分请求、改判和最终结果，并使用公开的有效花色。血条立即显示当前体力，受伤余量和回复亮起属于短暂表现。

少量目标用连线提示，群体效果标记对应角色。中央有选牌或响应内容时，反馈避开操作区；小窗口优先为公开牌与候选保留可滚动空间。设置中的「预览战场特效」可以重播各类效果和出杀组合，预览不改变牌局或存档。

动画默认开启，随独立本机偏好保存。关闭动画、读档和换局清理活动效果，重新开启不重播历史；控件卸载后停止绘制计时器。声音设置见 [`BATTLE_AUDIO.md`](BATTLE_AUDIO.md)。

## 数据与生命周期

`MainViewModel` 在命令提交后捕获新增事件。`BattleCueProjector` 将允许展示的事件与玩家快照转换为表现数据；涉及摸牌的宿主移动事件只提取公开数量，私有候选和他人暗牌不会进入动画。公开用牌、响应、判定与技能反馈使用各自的去重和显示边界。

`BattleFeedbackLayer` 不接收命中或焦点，只在加载且存在活动效果时运行表现计时器。动画、声音和最近公开牌列表都从已提交结果构建，读取存档重建静态状态并重置游标。

手牌按实体 ID 更新：仍在手中的 `CardViewModel` 与内容容器尽量保留，只更新可用性和选中状态。整理后的顺序在刷新与弃牌后延续，新摸牌追加；替换整局引擎时清空旧手牌对象。
