# 牌桌目标选择

## 唯一合法目标

选中杀、顺手牵羊、过河拆桥、火攻、决斗等单体牌或对应转换牌后，若当前只有一个合法角色目标，会自动选中，仍由主按钮或 Enter 确认使用。顺手与过河的具体牌区、公开目标牌继续由玩家选择。判断使用完整的合法候选，包含自己；不会按敌我关系替玩家猜目标。

单体主动技能同样自动填入唯一合法目标；材料影响目标合法性时，换材料后重新判断。技能结算中的单人目标询问也会默认选中，保留确认和可选的放弃操作。多名合法目标、有序双人组合、多目标牌与重铸等替代操作保留原来的选择流程；新手演练沿用教学步骤。

## 过河拆桥与顺手牵羊

选择目标手牌区时，若结算时只剩一张暗牌，界面自动提交该唯一牌位，不再弹出第二次选牌。若有多张暗牌，仍需选择牌位。自动选择沿用原生选牌命令，保留无懈响应、牌区变动检查与存档回放。

火攻展示、攻心观看等牌面信息只在对应结算窗口中显示，结束后收起。持有者可以重新排序手牌；之后使用过河拆桥或顺手牵羊时仍显示暗牌位，不根据历史展示记录持续公开牌面或标识牌位。技能需要的“展示过”记录仅供内部计数。

## 铁索连环

选中铁索连环后，直接点击一到两名亮起的存活武将，包含自己，再通过主按钮或 Enter 确认。再次点击已选武将可以取消，选满后其他武将不再高亮；先取消一个即可更换。

操作提示显示已选数量，目标武将显示金色边框与「已选定」。指南列出每个已选武将会进入或解除连环。Esc、换牌和确认使用会清理选择；整理手牌、关闭指南、取消新对局和退出新手演练保留当前选择。读档与真正开始新局按既有规则重建牌局，清空尚未提交的选择。

红色铁索通过武圣当作杀使用时，必须只选择一个合法攻击目标，并显式选择转化操作。选择两个目标只能使用铁索连环。提交使用 Core 提供的规范目标顺序，点击顺序不改变规则，也不会直接花掉手牌。

不选目标时可使用独立的「重铸换牌」按钮，Enter 不会隐式重铸。合法目标与牌效由 Core 判定，详见 [`IRON_CHAIN_RECAST.md`](IRON_CHAIN_RECAST.md)。
