# 铁索连环的牌桌点选

选中铁索连环后，直接点击一到两名亮起的武将，主按钮或 Enter 确认。再次点击已选武将可以取消，选满后其他武将不再高亮；先取消一个即可更换。中央不再展示所有双目标组合。

操作提示显示已选数量，目标武将显示金色边框与「已选定」。指南列出每个已选武将会进入或解除连环。Esc、换牌和确认使用会清理选择；整理手牌、关闭指南、取消新对局和退出新手演练保留当前选择。读档与真正开始新局按既有规则重建牌局，清空尚未提交的选择。

红色铁索通过武圣当作杀使用时，必须只选择一个合法攻击目标，并显式选择转化操作。选择两个目标只能使用铁索连环。提交使用 Core 提供的规范目标顺序，点击顺序不改变规则，也不会直接花掉手牌。

规则版本 6 的新局允许自选，也支持独立重铸操作；版本 5 及更早的存档仍只允许其他存活角色。合法目标与牌效由 Core 判定，详见 [`IRON_CHAIN_RECAST.md`](IRON_CHAIN_RECAST.md)。以下验证数据记录最初的牌桌点选增量，最新结果见重铸文档。
