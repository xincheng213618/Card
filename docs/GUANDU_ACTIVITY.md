# 官渡之战 · OL 2023

本批采用[2023年6月官渡公告](https://www.sanguosha.com/news/20230607_4391_3117)，页面发布日期为2023年6月8日，活动于6月9日至20日开放。不能与2019官渡将池或其他客户端版本混用。

## 两军与主帅

曹、袁各四席。官方为四名玩家对四名AI；本地由一名玩家与三名AI同袍对抗四名AI敌军。开局可选曹操军或袁绍军，并选部将或主帅，默认部将。主帅固定界曹操、界袁绍，额外增加1点体力上限并拥有对应主公技。官方曹操固定一号位并先行动；本地牌桌随人类位置旋转，因此桌面号位可能变化，仍由曹操先行。界面显示实际主帅号位。

击败敌方主帅获胜，不要求清空部将。牌堆耗尽则玩家方失败；界面持续提示此条件，实际失败状态来自Core公开快照。敌军击杀奖励为获得死者全部手牌；误杀同军则弃置凶手所有牌。死亡、奖励及技能子结算须真实完成。

公告给出了两军专属将池，并说明随机采用五种座次，但未逐席公开五种排列，也未给出候选数量。项目将具体五种排列及部将六选一作为明确本地约定，随种子固定并保存在可重放对局中。主帅不进入普通部将候选；其他人的候选与手牌不因此公开。

## 随机事件

每局开局抽取一种，整局生效，桌面显示实际事件及轮数。下表是说明性转述，具体结算由Core实现。

| 事件 | 效果 |
| --- | --- |
| 十胜十败 | 整局每第十张使用牌，非装备和延时锦囊时，对仍合法的原目标再次结算。 |
| 火烧乌巢 | 无属性伤害转为火焰伤害。 |
| 粮草匮乏 | 摸牌阶段少摸1；用牌造成伤害后摸1，每张牌只奖励一次。 |
| 斩颜良诛文丑 | 回合开始选择另一角色，视为对其使用决斗，否则失去1体力。 |
| 坚守待战 | 可把杀当闪使用或打出；每轮首次如此做，下个弃牌阶段手牌上限减1。 |
| 两军相持 | 前四轮按轮数增加手牌上限；之后己回合首次使用杀造成的伤害加1。 |
| 徐图缓进 | 出牌阶段未使用或打出杀，下回合摸牌阶段多摸1。 |
| 以弱胜强 | 受伤者体力高于来源时，伤害加1。 |
| 恃宠而骄 | 结束阶段体力唯一最多则弃1牌；弃牌及其触发完整结算后，独立比较手牌，最多（含并列）则失去1体力。第二条件不依赖第一条件成立。 |

官方未公布事件概率，不能把本地种子抽样称为官方概率。实际轮数由回合计划推进，不以行动回合数除以八推算。

## 专属牌

军争牌堆移除木牛流马，以酗酒、屯粮、援军、勠力同心替换公告指定旧牌；不擅自混入2019版其他卡牌方案。酗酒为对敌单目标基本牌，不是普通酒或濒死救援。屯粮可选一至三名角色，援军可选一至两名已受伤的其他角色。勠力同心按完整己军或敌军选择目标，并保留独立重铸动作。

界面所有合法目标、转换来源和逐目标无懈均取自Core发布的动作；勠力同心点选一名角色即选中其整军的合法目标集合，不能伪造子集。屯粮、援军允许逐个添加或取消目标。霹雳车是刘晔生成的专属装备，实际生成、装备与销毁遵循本局规则。

## 本地五阶与边界

沿用用户选择的本地玩家五阶：体力及上限增加2、起手增加1、出杀次数增加1、摸牌数增加1，并有一次濒死回复3及摸3的涅槃。主帅另享官方上限增加1。这是本地统一设定，2023公告没有该等阶表。

不模拟网络组队、商城体力、活动奖励、账号逃跑与投降计时。官方的开局前逃跑平局、五分钟后单人投降属于网络参与规则，不能由本地“结束出牌”触发。

存档保存实际阵营、主帅或部将身份、五种布局索引和本局事件。跨配置加载后使用存档对应内容包，再战继续所选阵营与身份；未知或不匹配内容不得静默替换。


## 武将版本与补充依据

2023公告逐一给出许攸、韩猛、辛评、张郃、淳于琼、刘晔与臧霸的活动技能。高览、审配、荀谌采用[旧官渡官方技能说明](https://www.sanguosha.com/news/20171128_3592_1319)；该页面现标注发布日期为2019-07-24，不根据URL推断发布日期。田丰的随势、死谏采用[2016年OL官方介绍](https://sanguosha.com/news/20160526_5424_5316)。所有活动变体使用独立的 guandu: 标识，保留普通模式当前版本。

谋识限定受赠者的下回合，在该回合每个实际出牌阶段按受伤角色分别判断首次伤害。若下回合的出牌阶段被跳过，关系随该回合结束，不顺延到更晚的回合。

其余公告只给出姓名与部分势力改动，运行时复用当前库的明确版本。完整映射保存在 StandardGuanduActivityPackage.OrdinaryVersions；未列入映射的十一位使用专门活动定义。陈琳与界刘备按公告改为群，张绣改为魏；阵营队伍与武将势力分别计算。

公告未列霹雳车的花色、点数，本地生成实体补为方块9；攻击范围9、失去装备区实体后销毁及伤害后弃防具与防御坐骑的效果来自公告。花色点数会影响武圣等转换，属于明确的本地补足。

两军均沿用用户要求的五阶普通武将设定。十胜十败在首次整张牌结算后重新核对原目标集合；不重复支付原使用牌的材料、不重复声明或扣使用次数，火攻等每次效果要求的额外弃牌仍分别支付。原目标集合不再合法则不追加整张牌的效果。徐图缓进不会被同回合追加的摸牌阶段提前消耗；坚守待战若在弃牌阶段内发动，其手牌上限代价留待下一个实际弃牌阶段。
