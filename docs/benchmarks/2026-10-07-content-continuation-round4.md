## 共享能力

- `cardActionActualTurnUseOrdinalIs` 在原使用声明或真实响应使用接受时记录正序号；原第二张的完成窗口不会被嵌套第三张改号。真实无懈、防御杀时使用的闪计入；决斗中打出的杀、箭雨中打出的闪和提供给他人的响应排除。按实际回合及实际角色隔离，回合结束后的用牌不发行序号。
- `grantTurnSkills` 新可选 `targetRef: actor`、`expiry: actualTurnEnd`。实际 HE 弃牌子窗口返回后才授技；不同来源保留独立 GrantId，同时复用同名有效技能实例及阶段状态。精确 TurnEnded 之后、AfterTurnEnded 子窗口之前删除到期来源，永久技能保留。省略新字段的旧授技路径保留原来源、实例和事件形状。
- 旧零实体杀和濒死酒保留声明及伤害、回复时的原 Action 行为；依赖新序号能力的目录在完成时以精确暂停指令、来源、物料及原声明事实建立完成动作。濒死酒的延后返回放在所属 CardUseFrame，完成子窗口返回后推进原程序一次。回复后的 HP 子窗口使用精确虚拟酒表示，不查找实体卡 0。

新条件和可选字段为独立 opt-in，旧 JSON 的 GameplayHash 不变。规则版本、规则 JSON schema 和包版本保留原来源中的值，本轮没有新增涨版、提交、推送、发布或打包操作。
