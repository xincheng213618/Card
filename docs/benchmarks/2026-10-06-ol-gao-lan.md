# 高览单武将批次

当前 OL 高览（群势力、4 体力）接入：袭阵（出牌阶段开始时，你可以选择一名其他角色，视为对其使用一张【杀】或【决斗】。此牌结算结束后，当你本阶段使用的牌被响应时，该角色回复1点体力，然后若其已受伤，则你摸一张牌，否则你摸两张牌）。官方立绘 46100 已离线入库并登记图鉴/映射。来源见[来源档案](../content/sources/ol-gao-lan-2026-10-06.json)。

| 技能 | 实现口径 |
| --- | --- |
| 袭阵 | launch：playPhaseStarting 可选触发 → selectTarget otherLiving → chooseOption（杀/决斗）→ 分支执行 useVirtualCard（normalSlashTarget）/ startVirtualDuel → 最后一条指令落 xiZhen 标记（在虚拟牌结算完成后，故虚拟牌自身的响应不结算收益）。收益：cardResponseAccepted 强制触发（ownerRelation observer）+ 本批新增条件 `cardActionOpponentIsOwner`（响应动作的 OpponentSeat 即被响应牌的使用者）+ ownerIsTurnPlayer → 新 op `xiZhenResponseBenefit`（7163）：唯一存活标记持有者回复 1 点，其后仍受伤则你摸 1 否则摸 2。过期：turnEnding（otherLiving）eventTargetMarkerCount ≥1 → 移除（谋识模式）。 |

## 共享能力扩展

- `startVirtualDuel` 支持触发路径：playPhaseStarting 触发下单选对手、技能拥有者担任决斗源；经典双目标激活路径（离间）不变。组合校验器新增 `ReadVirtualDuelPair` 资源，同时覆盖激活（initialTargetSetCount≥2）与触发（selectTarget 先行）两种形状。
- `useVirtualCard` 与 `startVirtualDuel` 的 effect 条件放宽为 Always|ChoiceIs（选项分支门控）。
- 触发条件 `cardActionOpponentIsOwner`（1026）：动作事实新增 `CardActionOpponentIsOwner`（按 UsesTriggerCondition 门控填充）。
- op `xiZhenResponseBenefit`（7163）：descriptor/handler/host 反射注册；引擎内联既有恢复流程（TryQueueRecoveryReplacement → BeginRecovery），被恢复替代技接管的罕见路径下跳过后续摸牌。

## 边界口径

- “视为使用一张【杀】”采用普通距离与次数口径（normalSlashTarget，区别于流矢的无限距离）。
- 收益以“标记持有者”为恢复对象；标记在其回合结束时效移除，且 ownerIsTurnPlayer 门控保证收益只发生在发动回合的出牌阶段。
- 决斗中标记持有者（对手）死亡时收益自然失效（唯一存活持有者查找为空即跳过）。
