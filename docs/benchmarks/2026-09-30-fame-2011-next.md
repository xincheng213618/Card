# 一将成名 2011 第二批：法正、马谡

本批按 OL 官网当前普通版本接入法正（恩怨、眩惑）和马谡（散谣、制蛮），加入正式选将池及“一将 · 一”图鉴。规则正文、版本差异、官方立绘地址及哈希见 [来源记录](../content/sources/fame-2011-next-2026-09-30.json)。新增内容不调整全局规则、JSON schema 或内容包版本；版本来源继续以源码为准。

法正恩怨按一次移动中同一其他存活来源角色汇总手牌及装备，至少两张才允许回馈一次摸牌；受到多点伤害时逐点决定交手牌或失去体力。眩惑替代摸牌，让目标摸两张后，由法正指定其攻击范围内另一名角色，目标实际使用合法杀或交出两张手牌／装备。

马谡散谣的体力值最多及手牌数最多分支各有独立的出牌阶段次数，可以选择自身及并列角色，用手牌或装备支付。制蛮在作为伤害来源时可防止对其他角色的整次伤害，再取得其手牌、装备或判定区的一张牌；空区域仍可防止伤害。

## 公共机制

- `perSourceOwner` 移动触发汇总只用于取得牌窗口；不改原有按批次、按牌触发。
- `requestSlashAgainstChosenTarget` 支持实体杀、单牌及多牌转换、丈八，以及通过实际主公技请求势力供牌。由实际出杀者产生用牌事件，供牌者支付实体卡；不计入通常出牌阶段杀次数。供牌成功或耗尽均返回原程序并恰好提交一次结果。
- `takeSelectedTargetCards` 先私下选择牌槽，选齐后原子移动。手牌提示不公开对手牌身份；装备移除保留装备技能、白银狮子及木牛流马等既有边界。
- 最高体力／手牌目标筛选与伤害来源防止窗口均为公共能力，未添加人物专用执行器。
- 潜袭弃牌被落英取得时，旧结算依赖弃牌区当前位置而报错。本批添加选择支付的 `freezeMovedCardSuit` 及限制的 `useFrozenSuit` 可选节点，仅潜袭内容启用；旧节点默认语义保留。

## 验证范围

聚焦检查使用既有 runner：`Fame 2011`、`Assisted faction provider`、`Qianxi`。法正检查包括实际杀／火杀／丈八支付、拒绝取牌、同源两牌、逐点偿还与暂停选择；马谡检查包括非法目标拒绝、独立次数、装备支付、制蛮三区域及空区域。势力供牌检查包括成功、全拒绝、仅限使用的单牌和双牌火杀转换。

上述行为场景均比较 checkpoint 恢复和完整命令 JSON 重放后的状态、类型化事件及牌移动。法正的混来源汇总及暂停状态篡改另用限定的白盒检查；不把这些白盒注入称为实际对局验收。

全量首次验证发现，制蛮取得牌后等待移动观察者时，伤害防止窗口的断言只认可直接栈顶，错误拒绝合法的嵌套移动窗口。修复使用逐层匹配父帧 ID 和窗口类型的有效祖先，不跳过无关联帧；天妒旧检查原样复测通过。新增制蛮行为检查同时覆盖实际杀、取得最后一张手牌及观察者暂停。

立绘补全另见 [素材来源](../content/sources/missing-artwork-2026-09-30.json)。高达一号为独立自制立绘，[内置 image_gen 提示词和哈希](../content/sources/gao-da-yi-hao-art-2026-09-30.json)已归档。鬼龙斩月刀原牌面和三张装备条已恢复；赤血青锋、刑天破军斧的原牌面仍缺，未用不明来源图代替。
