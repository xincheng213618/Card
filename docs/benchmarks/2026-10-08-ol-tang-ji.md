## 边界口径

- 抗歌对象是公开信息："歌"标记在目标身上、快照可见；一个唐姬全局至多一个对象（选择触发 usageScope game 1）；候选=其他存活角色（"一名其他角色"）。
- "获得手牌"按官网正文口径：进 Hand(gainer) 的获得全部计入（牌堆摸牌、处理区结算、他人交予等）；OL 专站"获得牌"更宽措辞未采用（来源档案 observations 记录）。无来源归属要求的移动也算获得；对象在自己回合内获得不触发（"回合外"）。
- "每回合至多三张"是摸牌总量上限：每张获得对应候选摸 1，账本按当前 `_turnNumber` 对已提交证据求和，满 3 静默跳过；额外回合按独立回合号计。抗歌自己的摸牌进自己手牌，不再触发自身（无递归）；节烈赠送使对象回合外进手牌时按本口径一阶联动。
- 濒死回复："每轮限一次"账本只记已确认的回复（被拒/落空不消耗）；确认时受害者已脱离濒死（提示与确认之间被救）则本次触发无效果落空；回复至 1 点受最大体力约束；dyingEntering subject any 的强制触发靠 op 内标记过滤，非对象濒死不弹任何提示。
- 死亡代价：弃置范围= 手牌+装备区+判定区（"所有牌"标准三区，不含私有延展区）；先弃置后失去体力；体力归 0 进入濒死按平台规则。对象死亡后的标记仍留存（其死亡已触发代价；此后抗歌摸牌/回复自然不再命中）。
- 节烈：选择与失去体力的顺序按官网正文（防→选花色→失去X→赠送）；专站变体顺序差异记录于来源档案。失去 X 点体力归 0 时：被救回后完成赠送；死亡则程序按平台取消，赠送不再执行。对象在防伤确认与赠送之间死亡时赠送作废。弃牌堆所选花色不足 X 张时全部获得。
- 证据与重建：五个 Program* 事件均为公开标量记录；获得的牌进私人手牌，暗手牌 id 不进普通快照；"每回合至多三张""每轮限一次"账本均由已提交事件推导，冷恢复确定性重建；"歌"标记为玩家状态，随 checkpoint/重放保持。
