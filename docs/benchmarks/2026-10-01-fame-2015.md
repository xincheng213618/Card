# 一将成名2015：十名武将整合与验证

本批按三国杀 OL 当前普通版补齐曹叡、曹休、钟繇、刘谌、夏侯氏、张嶷、孙休、全琮、公孙渊、郭图逢纪。技能、正式选将池和十张官方立绘已接入；“一将 · 五”图鉴连同已有朱治、沙摩柯共十二人。技能正文、版本裁决、原图尺寸和 SHA-256 见[来源档案](../content/sources/fame-2015-2026-09-30.json)，公共能力见[2015能力记录](../content/skill-composition/FAME_2015_CAPABILITIES.md)。

## 行为与整合修复

技能通过公共描述符、host 能力与 JSON 组合执行。新增机制覆盖下回合收益、势力供牌／回复、受益者与来源者分离、实体重铸、双方展示、手牌比较、参与者摸牌后置顶、永久攻击范围及手牌上限查询。没有为武将添加人物专用执行器。

- 默书只接受“使用”基本牌：本人面对杀使用闪和濒死使用桃／酒可以转化；万箭、护驾的打出闪及决斗、南蛮的打出杀不能转化。真实费用牌置顶后可能被嵌套技能重新摸走，清理不能再把它当作处理中牌弃置。
- 补齐普通出牌酒和濒死救援的独立费用边界；默书杀下面的原生闪及可选观察技能暂停必须分别验证其真实费用区域。非法回答原子拒绝，实体支付／清理各执行一次。
- 装备先完成目标窗口，再安装到真实装备栏，最后进入用牌承诺窗口。避免观察技能在装备尚未安装时读到错误状态。
- 怀异真实展示的全部手牌在选择颜色期间通过公共牌投影显示，卡牌身份、花色、点数来自实际区域；其他角色看不到私有选择。支付结束后展示退场，既有 WPF 公共牌控件可直接显示。

规则纪元调整对应以上同内容指纹下的结算语义修复，依据仓库版本源，不是逐武将递增。旧开发存档会按现有版本门禁拒绝恢复；规则 JSON schema 不变。本会话没有进行内容发布或 Git 提交、推送。
