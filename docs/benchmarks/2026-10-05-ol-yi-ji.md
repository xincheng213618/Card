# 伊籍单武将批次

当前 OL 伊籍（蜀势力、3 体力）以官方页当前文本接入：机捷（出牌阶段限一次，观看牌堆底的一张牌然后交给任意角色）+ 急援（一名角色进入濒死状态或你交给一名其他角色牌时，可令其摸一张牌）。官方立绘 50300 已离线入库并登记图鉴/映射。来源见[来源档案](../content/sources/ol-yi-ji-2026-10-05.json)。

| 技能 | 实现口径 |
| --- | --- |
| 机捷 | 出牌阶段限一次激活，激活目标即接收者；新操作 `giveDrawPileBottomCard`（7160）把牌堆底移动到其手牌，走移动公共窗口路径。日志不点牌名以免泄露，“观看”的私有可见性产物留待提示层。 |
| 急援 | 濒死分支：dyingEntering subject any + selectTarget(eventTarget)+draw(selectedTarget)。给牌分支：cardsMoved 新增 movementOccurrence `perOwnerSourceHandGain`（763）——观察者自己的手牌进入他人手牌时逐张触发，TargetSeat=接收者，同样 selectTarget(eventTarget)+draw。 |

## 共享能力扩展

- `SkillProgramEffectOp` 新增 `GiveDrawPileBottomCard = 7160`（`ProgramYiJiOperations.cs`：descriptor + public handler + `IYiJiProgramHost`；Resources=ReadSelectedTarget，target 必须 selectedTarget）。
- `SkillProgramMovementOccurrence` 新增 `PerOwnerSourceHandGain = 763`：cardsMoved 边界的“自己给牌”观察语义，校验要求 cardsMoved 窗口；复用 762 的双座上下文（SourceSeat=来源、TargetSeat=接收者），收集器按 From.OwnerSeat==观察者过滤；与 762 同样被计数环排除防双触发。
- 未改动既有窗口、收集器与效果语义。
