## 实现与工程边界

- 缓释先由技能拥有者选择发动或跳过，再由实际被判定者私下观看拥有者手牌并选择其一张可转移手牌/装备；材料范围是对“一张牌”的明确工程解释，固定武将武器排除。待选择状态保存在原判定帧，绑定原候选、来源实例、内容指纹、原判定实体。真实改判和装备卸载、移动、回复观察者排完后返回原判定游标。私有牌面仅在实际选择窗口授权给被判定者，其他玩家不获得该手牌；选择后授权结束。AI 使用实际选择者的 `CreateSnapshot`。WPF 复用既有授权牌面与 ChoiceId 提交流程，此批未启动界面。
- 弘援针对一次真实取得至少两张手牌的批次，可交当前可转移手牌/装备给至多两名不同其他角色，各一张。手牌/装备材料及零张不消耗额度为明确工程默认。每实际阶段额度在第一笔真实赠牌时发行，按拥有者、技能、真实阶段锁定，失技、重获与重置不刷新该阶段额度。内部处理区回迁不能伪造新取得。每笔付款排完移动、装备回复等子流程后才继续下一笔，已付材料不重复支付。
- 明哲在拥有者自己的实际出牌阶段之外，按实际失去实体冻结的拥有者有效红色展示并摸牌；别人出牌阶段仍可触发。有效色时点、同拥有者区域间转移不算失去，以及逐红实体展示并摸一的落点是记录在案的工程解释。只公开已失去实体的牌面，保留其印刷快照；不在先行观察者移动牌或改技能后重算颜色。逐次真实摸牌排完子流程再继续，不制造空牌堆的实体摸牌。新增移动资料仅由新能力启用，旧无该能力的路径保留空属性。
- 甚贤采用原始基本牌实际弃置事实，即使先行观察者已经取得该实体仍能识别；使用、响应的清理不算弃置。在拥有者实际回合之外，其他角色弃置基本牌时可摸一；每实际回合最多发行一次。额度按拥有者和技能保留，重置或重获不刷新；接受后即使空牌堆实际摸零张仍消费已发行额度，跳过不消费。
- 枪舞采用真实公开判定的最终实体点数 X，判定替换与取得沿用成熟流程，每实际出牌阶段限一次。本实际回合中有效点数严格小于 X 的杀无距离限制，严格大于 X 的杀不计普通次数，等于 X 或没有有效点数时保持普通规则。物理牌、单材料转化、提供者及附加目标菜单与实际执行共同核对有效点数；无既有点数定义的多材料杀不虚构求和点数。每次实际使用在原使用帧冻结本次 X、有效点数与距离/次数权限，孩子中出现新判定不会改变已发行使用权限。已发放政策不依赖继续持有技能；同实际回合额外出牌阶段发放的新 X 替换后续使用的旧 X，两者为明确工程默认。玩家视图仅公开 X 与实际回合。
- 引兵在自己的结束阶段通过逐张选择及完成按钮存入任意数量的可转移非基本手牌/装备，允许零张，无子集枚举和人为小数量上限。实际实体进入来源绑定的公开牌区。受到真实杀族或决斗造成的伤害后，选择并真实移去一张；依据实际有效伤害牌种，排除未造成伤害的尝试与非匹配牌。
- 绝地在自己的准备阶段独立触发；没有引兵技能或没有牌也保留合法选项。选项一真实移去全部牌并排完孩子，再按此时上限及手牌一次摸至上限。选项二冻结原数量，将全部牌实际交给体力不大于自己的其他角色，排完赠牌孩子，再请求回复一点并排完回复孩子，最后摸原数量。零张转移仍可请求回复，摸牌数量为零。已付后继不再次支付；受益者死亡或真实终局关闭尚未发行的后继，保留已付诊断。

新增带集合付款事实在 `CommittedEventProjection` 冻结；帧中的列表在构造和 init/with 时保存只读副本。真实移动区间、来源和实际父帧均参与静态审阅。引兵的木牛流马卸载使用完整多来源移动调用返回后冻结凭据，清粮记录包含在该已付区间，不能套用前批先冻结成本区间的不同形状。
