## 共享能力扩展

- 新增 EffectOp 7325–7327（分配段 7325–7332 内；7320 既有占用、7300–7304 刘宏批已用、7308–7324 王双/田豫批在制，取号前逐一核实空闲）；描述符按反射目录自动注册；AI 语义复用既有 Gift / GainCards / DiscardSelected，未新增 `ProgramOperationAiSemantic` 成员。未新增 PlayerMarkerKind、TriggerFactKind、ConditionKind、触发窗口或 schema 节点。
- `EstimateCompositionForAi` 新增一条通用目标发布行：援资类"回合开始窗口赠送"技能把窗口 `SourceSeat`（回合角色）作为已发布受赠者，使共享 `ScoreProgramTarget` 计价受赠者收益（行内以 `YuanziResolve` op 存在性 + 窗口/座位条件门控，不影响既有技能路径）。
- `ProgramAiEstimateContext`（partial）新增估值钩子 `AllHandTurnOwnerGift`（受赠者手牌增益 + 拥有者整手损失 + 同回合摸牌先验），配套 `YuanziResolveDescriptor` 的 Gift 语义 AI 策略；仅新增方法，不改动既有估值逻辑。
- 其余全部为既有共享口径复用：其他角色的准备阶段窗口（turnStartBeforeNormalFlow + turnOwnerScope）、每轮限一次（usageScope round）、可选触发通用激活提示、弃任意张摸等量（制衡 selectOwnedCards/moveBoundCards/draw(boundCardCount) 声明式组合）、随机弃其他角色手牌（杨婉追还 `_random` 口径）、cards-moved 窗口续接（TryBeginCardsMovedProgramWindow）。

## 边界口径

- 援资发动门槛：拥有者至少一张手牌（compare(currentHandCount >= 1)）；零手牌时"交给其所有手牌"无可执行内容，按不可发动处理（官方无明确裁定，来源档案如实记录）。
- "每轮限一次"以 usageScope=round/1 表达，在接受发动时消费、仅查看不消耗；文本未写明拒绝是否消耗，按本仓可选触发既有语义实现。
- 援资 payoff 的"本回合"按回合号 + 回合座位双重匹配；同回合多次伤害各提示一次（文本无每回合限次）；手牌比较在伤害时点取公开手牌数。
- 烈节激活后至少弃一张（minimumCards=1）；"至多三张"字面允许 0 张但 0 张时两子句均无效，按制衡最小 1 张既有口径实现。
- 烈节第一子句弃置区域为手牌+装备区（拥有者自己的牌）；文本仅写"牌"未限区域，按 selectOwnedCards zones 既有口径。
- 烈节第二子句为"从伤害来源手牌随机弃置"（拥有者选档位 1..min(X, 来源手牌数)）；不打开来源装备区、拥有者不查看来源手牌——本仓隐藏手牌信息边界（杨婉追还同款）；OL 客户端同类效果若允许跨区域挑选，该部分未表达，通用缺口已记 `docs/content/CORE_API_REQUESTS.md`。
- 致命伤害时序：濒死后被救回的伤害窗口完成后 AfterDamageApplied 照常开放、烈节可结算；受击即死亡时不再提示（引擎触发窗口通用语义）。
- 冷恢复：援资武装由已提交 `ProgramYuanziInvokedEvent` 推导，烈节弃牌集由命令重放的帧内绑定重建；全部证据事件为标量/id 列表记录，无暗手牌 id 进普通快照。
