## 共享能力扩展

- 新增 EffectOp 7316–7318（分配段 7316–7319 内；7320 既有占用未触碰，7321–7324 留空未用）；描述符按反射目录自动注册；AI 语义复用既有 ChooseOption/SelectTarget，未新增 `ProgramOperationAiSemantic` 成员。未新增 PlayerMarkerKind、TriggerFactKind、ConditionKind、触发窗口或 schema 节点。
- **新增共享能力：定向距离减免授予（directed distance grant）**。`ProgramDirectedDistanceGrantedEvent(FrameId, SkillId, BindingId, SkillInstanceId, OwnerSeat, TargetSeat, Amount)` + `ProgramDirectedDistanceRevokedEvent`（通用命名，任意"令我与某角色的距离±N 直到某条件"内容技能可复用）+ `EvaluateDistance` 一处通用串联 `ApplyProgramDirectedDistance`：按（来源, 目标）有序对读取已提交授予事件、扣除已撤销者，Add 贡献计入 outgoingDistance、下界 1，置于坐骑/加法贡献同层、先于 FixedDistanceOne/InspectedHand/HpOrdered 三个 Set 型 overlay；依赖 `HasTriggerOperation(zhuitaoMarkTarget)` 门控，冷恢复从事件史推导，无运行期私有映射。此前引擎仅有声明式 outgoingDistance modifier（全局条件，无"对特定角色、可撤销"表达）、TurnCardUseEffects 回合级距离授予、FixedDistanceOne（出牌阶段发动+回合结束弃牌债）与两个 Set 型 overlay，没有"事件驱动、按对、持续到伤害"的定向减免；追讨①需要该能力。缺口已补记 `docs/content/CORE_API_REQUESTS.md`。
- 其余全部为既有共享口径复用：加目标变异（原始目标追加/卡牌增强既有 UpdateLifecycleCardUse+CloneRoleAction 管线）、多目标展开（顺序锦囊机制 + 增强杀游标）、目标合法性（CurrentCardExtraTargets/CanAddIssuedOriginalTarget 同款检查）、"对其他角色造成伤害后"（执笏条件口径）、准备阶段窗口（代讨同款）、optional 触发提示与组合估值（共享 EstimateCompositionForAi 路径）、共享 ScoreProgramTarget 目标计价。

## 边界口径

- 扫狄"之间的角色"按座位短弧（死座跳过、目标端点恒计入弧长），两弧等长取并集；sgsol"最短距离路径"口径未采用（版本差异记录于来源档案）。追加目标不受攻击范围限制；仍受禁止/免疫类目标检查过滤。
- 扫狄发动但之间为空或全部不合法时为无效果空转（无事件无日志）；optional 提示无法前置表达"之间非空"，AI 会在空转情形接受一次发动（+1 牌等价正计价），如实记录。
- 借刀杀人保留在 cardKinds，由引擎 designated-target 计数条件判定；无角色目标/全场 AOE 普通锦囊不入 cardKinds（不可能满足单目标+有之间角色）。
- 追讨"距离-1"为拥有者出向距离（入向不变），与 sgsol 标记版"你计算与…的距离-1"方向一致；减免在对该目标造成任意伤害后撤销（含以拥有者为来源的传导伤害），可跨回合多目标并存，撤销后可重新点名。
- 追讨撤销条件只认 afterDamageApplied 的 damageSourceIsOwner——无来源伤害（延时锦囊判定类）不触发撤销，与文本"当你对其造成伤害后"一致。
- 冷恢复：授予/撤销/追加目标证据全部为已提交标量事件；距离 overlay 与 mark 候选集均从 CompleteProgramEventHistory 推导，无运行期私有映射；暗手牌 id 不进任何事件或快照。
- AI 策略：扫狄 op 无选择（Automatic，optional 接受经 ChooseOption+Draw(1) 正计价）；追讨 mark 经 SelectTarget+Draw(1) 正计价接受、候选项按 ScoreProgramTarget(TargetHpLoss=1) 敌意计价；revoke 锁定自动 ChooseOption 空计价。
