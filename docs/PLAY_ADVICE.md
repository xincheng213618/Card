# 出牌建议

轮到自己出牌时，按 `F1` 或点击「操作提示」，在「当前操作」中点击「看看出牌建议」。面板显示一个推荐行动、涉及的手牌花色点数、目标座位及判断依据。技能行动列出建议的选牌和目标；转化用牌与铁索重铸有独立操作说明。

查看建议沿用指南的暂停与输入隔离。建议不会自动选牌、改变当前选择或提交行动；返回牌桌后由玩家决定是否改选。已提交行动、读取存档、重新开局或进入教学后，旧建议失效。新手演练有固定目标，不提供自由出牌建议；响应和弃牌阶段继续使用既有操作说明和推荐弃牌。

## 判断范围

`PlayAdvisor` 使用独立的 `SimpleAiBrain`，采用 `AiDecisionPolicy.CurrentVersion` 和固定种子，只接收普通玩家快照、Core 发布的合法行动和自己当前回合已重铸的牌。主动技能同时计算所选费用和目标，判定区转化会区分实体牌面与有效牌型。建议器不访问引擎内部 AI、牌堆顺序、他人手牌或未公开身份，也不改变实际 AI 的随机状态、观察记录或命令历史。即使开发者视图开启，入口仍取得普通玩家快照。

这是基于当下可见局面的启发式参考，并未使用历史攻击行为积累身份猜测，也不保证最优策略。身份未明时，玩家仍需结合自己的判断决定目标。界面不展示内部评分数值。
