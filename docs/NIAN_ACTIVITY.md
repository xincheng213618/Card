# 挑战年兽（OL 2016）

模式为 `activity:nian-2016`，独立内容包为 `nian-activity`。采用2016年2月2日至16日开放的三人合作版，依据是[官网完整规则](https://www.sanguosha.com/news/20151216_3119_0414)与[同日活动公告](https://www.sanguosha.com/news/20160124_9145_4514)，两篇实际发布时间均为2016年1月29日，不能仅凭第一篇URL中的2015年日期误判版本。

这是三名联合军挑战一只年兽的完整单场结构，没有随从、敌人随机等阶、五阶交替行动、生肖捕捉、护盾或2020版觉醒中断。三人对单兽是2016公告原定结构，不是裁掉2020随从后的简化版。玩家固定五阶则沿用用户确认的截图设定。

## 四席、选将与胜负

一名本地玩家和两名人机队友组成联合军，对抗12体力、神势力年兽。击败年兽获胜，联合军全部阵亡且没有完成复活则失败。年兽死亡与玩家死亡均须等待真实死亡及其技能子结算完成。

2016公告未逐席列出位置、首动角色和初始手牌数。本地约定相对本地玩家的座次为先锋0、中坚1、大将2、年兽3，由先锋先行动，然后按座次递增。普通起手四张，玩家加本地五阶后为五张；武将自己的初手技能仍生效。上述座位与起手不能称为公告逐项确认值。

可选武将来自项目当前已实现的常规池，保留神将；排除公告所列曹丕、满宠、蔡文姬、SP蔡文姬、左慈、于吉、新于吉。人物族禁将覆盖其当前变体，历史上有意保留空人物ID的定义另用精确版本ID补齐，不修改旧内容元数据。其他合法武将不因2020或2022禁将表被额外删除。

神将保持神势力，不选择魏蜀吴群；队伍归属由联合军身份决定。玩家武将复用项目现有版本，不宣称把所有技能回退到2016文本。神赵云使用现有常规OL绝境、龙魂版本 `ol:shen-zhao-yun`，不使用另存的长坂坡特殊神赵云。没有神武再世的共享神将候选或专属装备。

## 逐轮状态轮换

开局为初始形态。官网在“年兽介绍”说明第二轮开始进入四种随机状态之一，四种都经历后在下一轮重置。本地据此在第二轮起的每个正常轮次开始时，从当前组未出现的状态中随机选择一种；四种用尽后重新洗出一组。所有随机过程使用对局种子并记录事实，保存和冷重放不得另抽一次。

| 形态 | 内容ID | 附加技能 |
| --- | --- | --- |
| 初始 | `nian:initial` | 无 |
| 睿智 | `nian:wise` | 睿智 |
| 警觉 | `nian:alert` | 警觉 |
| 任性 | `nian:capricious` | 任性 |
| 暴怒 | `nian:furious` | 暴怒、兽裔 |

同一组内不重复四种状态；初始形态不会加入后续随机组。额外回合不另开正常轮次，也不多换一次形态。切换在新轮其他准备阶段效果之前生效。

公告将这些称为同一只年兽获得的“状态”，没有规定换状态时回血、清区域、补手或重置限定技。因此本地只更换状态附加技能，保留同一角色的现有体力、上限、手牌、装备、判定、翻面、横置和已使用技能账本；这项区域保留是按状态授技所作的明确解释。它不属于死亡切关，不使用驱鬼的四关重建流程，也不中断正在结算的回合。

## 基础技能与四种状态

以下来自[官网规则“年兽技能”“年兽状态”](https://www.sanguosha.com/news/20151216_3119_0414)。所有形态保留三个基础技能，只有当前状态的附加技能生效。

| 技能 | 作用与边界 |
| --- | --- |
| 影姿 | 正常摸牌阶段额外摸两张。 |
| 萌态 | 出牌阶段被跳过则跳过本回合弃牌阶段；摸牌阶段被跳过则在结束阶段开始时摸三张。没有萌态2020的乐、兵判定反转，也不会自动翻正。 |
| 冬眠 | 体力不大于六且处于开局轮次时，其他角色的牌不能再指定年兽为目标。公告写“当前回合数为1”，本地按第一正常轮解释，不缩成只有先锋的第一个实际回合。已合法指定的目标不会因后续伤害降至六而追溯取消；技能伤害不等于用牌指定。 |
| 睿智 | 其他角色准备阶段开始时，该角色选择保留一张手牌及一张装备区的牌，然后弃置其余手牌和装备牌；不是随机替玩家选择。无牌的区域不要求保留；判定区与特殊牌堆不受影响。 |
| 警觉 | 年兽的手牌或装备因弃置或被其他角色获得而失去后，回复一点体力。同一批次失去多张仅回复一次；不能把用牌、打出或任意区域移动都算作该失牌原因。 |
| 任性 | 年兽回合外，一名角色每受到一点伤害或回复一点体力，年兽摸一张；包括其他联军和年兽自己受伤的实际次数，失去体力不计作伤害。 |
| 暴怒 | 摸牌阶段改为随机摸X张，X取四与当前体力之间的整数；替换影姿的正常摸牌数量，不额外再加二。体力小于五时，杀伤害加一且不受次数限制。 |
| 兽裔 | 使用牌无距离限制，范围包括受距离限制的其他用牌，不能只对杀生效。其他目标条件和禁止目标效果仍有效。 |

暴怒公告没有额外解释当前体力小于四时的上下界。本地明确取 `min(4, 当前体力)` 至 `max(4, 当前体力)` 的闭区间，不编造“最低固定摸四”规则。

睿智原文只概括保留一张手牌及一张装备牌后弃“其余的牌”，警觉也没有逐项列出失牌区域；本地按上表明确限于拥有的手牌与装备，遵循现有可弃置及区域权限，不能把判定牌或特殊存牌当作无限制的普通自有牌。

## 共享三次协力复活

[官网活动规则第4条](https://www.sanguosha.com/news/20151216_3119_0414)明确对局共有三次复活机会，任意玩家可以帮助阵亡角色复活。复活时弃置该角色区域里的所有牌，将武将牌恢复至游戏开始时的状态，摸两张牌，将体力回复至二。

本地通过出牌阶段的“复活队友”操作展示这条规则，技能ID为 `nian:revive`；该名字是本地操作名称，不冒充官方新增武将技能。机会由全队共享，不能让每位玩家各有三次，也不因轮换年兽状态或读取存档而补充。复活恢复目标角色原本武将，清理现有区域并复原翻面、横置，摸两张真实实体牌，体力设为二且不超过现有体力上限；不刷新涅槃等限定技能的使用账本。官网没有逐项说明限定技能是否刷新或操作阶段，此处采用明确的本地账本约定及出牌阶段入口。

玩家自己的涅槃是另一项能力：每局一次，濒死时回复三点体力并摸三张，保留现有区域及状态。它不消耗共享复活次数，回复三点也不等于将体力设置为三。

## 本地五阶、美术与服务边界

玩家体力及上限加二、初手加一、出杀次数加一、摸牌阶段加一，并获得上述涅槃。年兽没有玩家五阶，其上限仍为十二；不能挪用2020版一至五阶上限16至26的表格。

五个形态使用 `tools/Build-NianBeastArtwork.ps1` 生成的项目原创几何兽符。颜色与额前星、书、眼、月、火图案区分形态，牌面标明“OL 2016 · 本地兽符”，不称为官方年兽立绘。生成器、尺寸和SHA256记录在 `docs/content/general-art-catalog.json`，五张图片都是交付资源。

官网还规定每次挑战消耗炮竹、每天赠送十支，限制点将道具，以及每局三十分钟。本地保留三十分钟实际时限：真正选将开战后开始计时，暂停自动推进仍计时，保存前结算不足五秒的尾数；加载后沿用剩余时间，关闭程序的离线时间不补计。时间通过单调时钟采样并提交为真实命令，保存及冷重放读取已记录的消耗，不重新取墙上时间。官网未明确超时的胜者口径，本地明确按联合军挑战失败处理。

不接入活动货币、商城、排名和服务器道具。保存与恢复沿用内容指纹、检查点和命令验证。

## 与后续版本区分

[OL 2020正式规则](https://www.sanguosha.com/news/20200115_8027_0516)有六席随从、一至五阶年兽、三种特殊形态、觉醒伤害后中断，以及五阶专用交替顺序；[2020正式更新](https://sanguosha.com/news/20200109_3626_4916)给16基础体力，而[此前体验服公告](https://www.sanguosha.com/news/20200113_2527_1617)给20体力。它们都不能替换本模式的12体力、四种逐轮状态。

[OL 2022年兽大作战](https://www.sanguosha.com/news/20220113_8335_3617)则是双人合作与十二生肖、捕捉、护盾及爆竹等道具技能，也不是本模式的机制来源。
