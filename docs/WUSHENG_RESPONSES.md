# 武圣红牌响应

武圣可以将符合技能条件的红色牌当杀，响应决斗、南蛮入侵和其他要求杀的询问。手牌高亮与中央候选消费同一合法响应列表；选中转化牌后主按钮显示「当作杀打出」。龙胆的杀转闪显示「当作闪打出」，原生杀、火杀和雷杀响应显示「打出杀」。

点击手牌仅进行选择，Enter 或主按钮才提交；Esc 取消选择，指南和新手演练往返保留原响应。装备区费用通过中央精确候选选择，不作为手牌显示。具体可用区域与条件由当前武将版本的技能程序和 Core 发布的 Choice 决定。

## 规则边界

- 武圣的转换只进入有效杀动作，不生成闪、桃或无懈响应。
- 国战只使用已明置且已启用的技能，主将和副将均适用；暗置武圣不能提前提供响应。
- 国战玩家可在自己的杀响应提示中先明置对应武将，刷新后仅当前响应者获得其新的私有候选。
- 每个 Choice 对应确切的费用、转换来源与响应方式，界面只提交当前询问中发布的选项。
- 响应事件记录有效牌型，实体牌移动保留原牌面和实际来源区。旧询问、旧修订号或重复提交不能再次支付费用。
- 真人和 AI 共用 Core 的候选与提交边界，其他座位看不到该响应者的私有选项。
