# 武圣红牌响应 · 2026-09-12

新对局中，武圣可以把手中的红色牌当作杀，响应决斗或南蛮入侵。中央候选和手牌高亮使用同一合法响应列表，选中转化牌后，主按钮显示「当作杀打出」；龙胆的杀转闪响应同样明确显示「当作闪打出」。实体杀、火杀和雷杀作为原生杀响应时仍显示「打出杀」。

点击牌仅进行选择，Enter 或主按钮才提交；Esc 取消选择，指南和新手演练往返保留原来的响应。没有新增快捷键。

## 规则边界

- 规则版本 9 才启用武圣红牌响应。版本 1–8 保留原有出牌转化与响应行为，旧存档不会悄悄增加可响应的牌。
- 转化仅用于要求杀的窗口，不允许武圣把红牌当闪、桃或无懈可击响应。只从实际手牌生成候选，不直接使用装备区的牌。
- 国战只检查已明置武将的技能，主将、副将均适用；暗置武圣不能提前提供响应。
- 国战玩家在自己收到【决斗】或群体牌的【杀】响应提示时，可以先明置对应武将；明置后响应 PromptId 和候选会刷新，仅当前 responder 获得新的红牌转化选项，响应链不被打断。
- 候选按实体牌生成，技能只判断该牌是否符合条件；同一张牌不会因多项技能而重复出现。
- 提交后响应事件的有效牌型为杀，移动事件仍保留原来的实体牌型。旧询问或重复提交不能再次支付代价。
- Core 统一处理真人和 AI，AI 不读取其他座位的私有候选。当前内容包指纹和存档 schema 3 不变。
