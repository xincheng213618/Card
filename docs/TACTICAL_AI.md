# AI 阵营决策与实战稳定性 · 2026-09-12

新开局使用战术策略 v3，改善身份场中的目标判断、保命与队友配合，并把火攻纳入公开攻击证据。旧存档继续使用其记录的 v1/v2，避免升级后同一命令记录重放出另一盘棋。

## 玩家可见的变化

- 忠臣和多人阶段的内奸不在主公 1 血时打出群伤；其他局面比较敌我承受伤害的净收益。
- 桃园结义只计算受伤角色，并区分敌我；不为只受伤的敌方主公白送治疗。
- 酒必须有另一张可合法打出、目标有正收益的杀来接续；不能把同一张红酒同时算成武圣的杀。1 血且缺桃时优先保留酒自救，自救时先用酒再用可救队友的桃。
- 规则 v20 起，AI 与人类共用 Core 发布的“出牌阶段每回合一次酒”合法动作；酒杀消费增伤后，第二张酒不会在本回合重新进入候选。v1–v19 的 Checkpoint 继续按旧候选集合回放。
- 规则 v21 的经典英姿沿同一私有 Prompt 边界询问 AI；额外摸牌没有成本，当前策略稳定选择发动。v1–v20 与演示模式继续走自动摸牌 modifier。
- 规则 v22 的经典天妒沿判定结果后的私有 Prompt 边界询问 AI；取得一张已公开且没有额外成本的判定牌是稳定正收益，当前策略选择发动。v1–v21 与旧经典包继续按判定牌自动弃置路径结算。
- 规则 v23 的经典反间只在公开敌对评分为正时进入候选，并把最敌对、低体力的存活角色作为目标；目标 AI 的四种花色在未知周瑜手牌时等价，使用固定方块作为可回放的公开信息 tie-break，不偷看源手牌。v1–v22 与经典包 1.0/1.1 不发布该动作。
- 规则 v24 的经典观星 AI 只读取拥有者可见的私有 Choice 元数据和公开判定区：为乐不思蜀选择红桃、为兵粮寸断选择梅花、避开闪电的黑桃 2–9，再按手牌保留/使用价值安排预计摸牌；足够的顶牌选完后把其余牌按低价值优先从最深处置底。它不直接读取引擎牌堆，v1–v23 与经典包 1.0–1.2 不发布该选择。
- 规则 v25 的经典护驾先让 AI 主公尝试无牌成本的魏势力协防；收到私有请求的魏势力 AI 只从自己的闪、转化牌和公开八卦阵中响应，并按忠臣、反贼、内奸及残局关系判断是否协助。决策思路记录公开身份关系和响应类型，不读取他人手牌；v1–v24 与经典包 1.0–1.3 不发布该选择。
- 规则 v26 的经典激将让 AI 主公在合法目标上把无牌成本的蜀势力协防作为杀候选，也会在决斗/南蛮入侵的杀响应窗请求协助；收到私有请求的蜀势力 AI 只读取自己的杀/转化牌和公开身份关系。忠臣协助，反贼拒绝，内奸在多人阶段可协助；一次主动请求全员失败后本回合不由 AI 重复尝试，避免无进展循环。v1–v25 与经典包 1.0–1.4 不发布该选择。
- 规则 v27 的经典救援不新增 AI 决策：既有濒死响应 AI 仍只按自己的身份关系和私有桃候选决定是否救援；引擎在另一名吴势力角色的桃被接受后，把孙权的恢复量从 1 修正为 2。这样不会向 AI 暴露额外手牌或身份信息，v1–v26 与经典包 1.0–1.5 保持原恢复量。
- 规则 v28 的奇袭动作直接复用过河拆桥的公开目标评分；AI 从自己的私有手牌和公开装备中识别物理成本，对已装备牌扣除公开机会成本，并继续只按目标公开手牌数、身份关系、装备与判定区评分，不读取目标暗牌。
- 规则 v29 的克己只在已满足“本回合 Play 阶段未使用或打出杀”的公开结算状态下出现；发动没有额外成本且严格优于同一时点的普通弃牌，因此 AI 固定选择发动，不读取任何额外暗牌或身份信息。
- 规则 v30 的突袭 AI 只消费 Prompt 发布的一人/两人公开座位组合、公开手牌数量和既有阵营/怀疑度模型；每名目标按敌对度、公开手牌数和替代普通摸牌的机会成本计分，不读取目标牌面或牌堆。实际获得哪张牌由引擎的确定性随机源结算。
- 规则 v31 的裸衣 AI 只检查许褚自己的私有手牌是否持有杀或决斗，并据此发动或跳过；不读取目标暗牌、牌堆顺序或宿主帧。伤害加成由 Core 根据原始用牌者和实际伤害来源统一结算，AI 不预测或篡改决斗响应结果。
- 规则 v32 的强袭 AI 只从典韦自己的已发布手牌/装备区武器候选中选择最低价值成本，并只按公开体力、敌我关系和合法攻击范围目标评分；没有武器时可支付体力，但会避免在 1 体力时为非终结收益自损。不读取目标暗牌、牌堆顺序或宿主伤害帧。
- 规则 v33 的断粮 AI 只从徐晃自己的已发布黑色基本牌/装备牌转换中选择成本，并复用兵粮寸断对敌方摸牌阶段的公开收益评分；目标集合完全来自引擎发布的距离 2 合法动作，装备成本按实体牌保留价值计价，不读取目标暗牌或后续判定牌。
- 规则 v34 的洛神 AI 在每次公开黑色判定后继续发动，红色结果由规则链自动停止；倾国只从甄姬自己的已发布黑色手牌候选中选择闪响应成本，沿用闪的保留价值，不读取牌堆后续判定牌或其他角色暗牌。
- 规则 v35 的集智 AI 固定从黄月英本人已发布的私有发动/跳过 Choice 中选择发动；它不会读取即将摸到的牌、其他角色暗牌或无懈候选。摸牌后仍由引擎恢复原普通锦囊或无懈反制游标，奇才继续只消费公开距离合法性。
- 规则 v36 的铁骑 AI 固定从马超本人已发布的私有发动/跳过 Choice 中选择发动；它不会读取牌堆顶、鬼才手牌或目标的闪。判定与是否禁止闪由引擎公开结果决定，马术继续只消费公开战斗距离。
- 规则 v37 的烈弓 AI 固定从黄忠本人已发布的私有发动/跳过 Choice 中选择发动；Choice 是否存在只由公开目标手牌数、黄忠当前体力和公开攻击范围决定，不读取目标手牌身份或是否持有闪。
- 规则 v38 的旧版狂骨是锁定技，没有 AI 决策入口；引擎只消费已经公开的实际伤害来源、伤害量、双方体力与战斗距离，自动按伤害点数回复，不读取任何手牌身份。
- 规则 v39 的无双是锁定技，没有独立 AI 发动入口；AI 仍在每一个公开的闪/杀响应窗使用原有响应评分。引擎只公开当前是第几次响应，不会为评估下一张响应读取其他角色暗牌。
- 武圣、龙胆比较转化成本；同一目标能用普通杀时保留桃，低血量时提高最后一张闪的保留价值。
- 马术不增加新的隐藏输入：AI 直接消费 Core 发布的距离型合法动作，距离一的顺手牵羊、规则 v18 的兵粮寸断和杀目标会随公开距离修正自然出现；奇才同样只通过公开合法动作放宽顺手牵羊与兵粮寸断的距离目标。
- 规则 v19 的火攻自选动作同样由 Core 发布；既有敌对评分会把攻击自己的动作压到负收益，AI 的展示/同花色弃牌选择仍只读取本座手牌和当前公开展示牌，不读取其他暗牌。v1–v18 的合法目标和牌区路径按 Checkpoint 版本保留。
- 濒死救援、遗计、节命、援护采用同一阵营判断，避免一边攻击对手、一边为其补血补牌。
- 无懈区分有益与有害效果，不取消自己主动打出的摸牌、治疗等锦囊，可以用反无懈恢复有益效果。
- 公开攻击和阵亡会更新有限的阵营置信度；残局结合身份场公开配比与已揭示身份判断剩余敌人，不把曾经协助击杀反贼的内奸永久当作队友。
- 拆除乐不思蜀等判定牌按帮助该角色计算；不会把替敌人解除限制当作拆除敌方装备的收益。
- 苦肉在体力大于 0 且仍有出牌机会时按主动合法动作评分；降至 0 时先进入共享濒死救援窗口，AI 仍只按自己的私有救援选择继续推进。制衡按本座快照从合法候选中稳定选择最低保留价值的牌；规则 v17 经典身份的候选包含自己的手牌与公开装备，旧规则/演示模式仍只含手牌。青囊按公开受伤状态选择恢复收益最高的合法目标，并从自己的手牌选择最低保留价值的弃牌；回春按公开受伤状态稳定选择所需的 2–3 名目标，并从自己的手牌选择两张最低保留价值的弃牌。AI 通过本座快照权衡公开体力/牌差收益，不读取牌堆顺序或其他玩家暗牌。
- 国战明置现在不再把主将/副将视为同分动作：AI 会在自己的视角中比较双将技能与当前机会，例如红牌转杀、杀转闪、突破杀次数限制和空手防护；明置信息成本只作小幅扣分，所有评分和思路仍不读取牌堆或其他玩家暗牌。同一 seed、策略版本和快照会得到相同的明置选择。
- 国战 M3 追加有限公开证据推断：战术 v2/v3 通过 Core 的 `PublicAttackEvidence` 只记录杀、决斗、群体攻击和火攻中“公开己方攻击隐藏座位”或“隐藏座位攻击公开己方/敌方”的弱信号，调整隐藏势力的攻击与濒死救援评分；已公开势力仍以 `FactionId` 为准，信号限制在 [-6, 6]，不会读取隐藏势力、暗牌或牌堆顺序。v3 另外把身份局火攻接入同一公开攻击观察入口；v1/v2 保持身份局火攻的旧行为。公开攻击后的中途 Checkpoint 会重放出相同 AI 知识与暂停 Prompt。

上述均为小型确定性启发式。仍无搜索树、跨局学习、难度分档或复杂阵营平衡；未知身份判断仍可能出错。AI 的输入只有自己的手牌、身份、已公开信息与合法动作，不读取他人暗牌、隐藏身份或牌堆顺序。

## 实战中修复的结算问题

1. 目标把最后一张手牌作为无懈打出，随后效果被反无懈恢复时，过河拆桥/顺手牵羊原先会尝试选择空手牌而抛异常，火攻也会要求从空手牌展示。现在在响应后重新检查目标，发布 `CardEffectSkippedEvent`、弃置已使用的锦囊并结束父结算；不会改选另一张牌或留下空询问。
2. 刚烈反杀主公时，如果伤害触发窗口后面还有援护等候选，原先会留下 `Winner = Rebels`、`Status = Running` 和处理区中的杀，无法继续。现在在胜负确定后关闭剩余候选与父伤害，清理用牌并发布一次终局。

三个空手牌场景使用真实受控牌堆、合法出牌、AI 消耗最后一张无懈、人类反无懈和命令重放；不通过反射修改引擎。致命刚烈使用实际五人牌局 seed `1112031`。

## 存档契约

`GameOptions.AiPolicyVersion` 默认 1，供缺少字段的既有 JSON 恢复；WPF 新牌局显式设为 3。引擎将该值传入每个 `SimpleAiBrain`，检查仅支持 1/2/3。Checkpoint SchemaVersion 仍为 3，规则行为版本单独由 `RulesVersion` 标记，缺少该字段的旧 JSON 按 v1 恢复；外层存档 FormatVersion 仍为 1。v3 保留 v2 的战术与国战公开证据语义，并新增身份局火攻公开证据；v1/v2 的既有命令日志和 Checkpoint 不被新观察入口改写。

`tests/CardGame.Core.Tests/Fixtures/legacy-ai-checkpoints.json` 在改动 AI 前捕获，不应重新生成来适配实现。它含三场旧版全 AI 完整牌局及一份真实 WPF 暂停存档；测试比对可信完整快照和全部事件负载 SHA-256。WPF 另测试缺少版本字段的文件能够读取、继续、再次保存为 v1，然后新开局切到 v3；非法版本文件保留原游戏。

同一策略版本的评分和随机调用顺序属于回放行为。今后再改变 AI 决策时应新增策略版本，不能悄悄改动已发布的 v2 或 v3。内容指纹只覆盖内容定义，不替代此策略版本。

## 验证结果

固定 64 个 seed（`724000 + index × 7919`），分别跑五人和八人桌、v1 和 v2，共 256 场。均采用实际交互开局和全 AI，400 回合上限；检查每场完成、结算栈与处理区为空、90 张实体牌唯一且守恒。v3 沿用 v2 的既有战术评分，并额外覆盖身份局火攻公开证据的确定性回归。

| 观察项 | v1，128 场 | v2，128 场 |
| --- | ---: | ---: |
| 正常胜负结算 | 128 | 128 |
| 达到回合上限的平局 | 0 | 0 |
| 忠臣/多人内奸在主公 1 血时群伤 | 26 | 0 |
| 反贼桃园仅回复敌方主公 | 6 | 0 |
| 酒效未用于杀，在回合末失效 | 110 | 0 |
| 内奸有桃却不救多人局主公 | 26 / 26 次机会 | 0 / 18 次机会 |
| 自救有酒仍优先花桃 | 4 | 0 |
| 平均回合数 | 36.5 | 31.4 |
| 最长牌局回合数 | 126 | 116 |

统计在游戏结束后根据类型化事件重建公开体力、存活状态及可信手牌移动，仅用于诊断，绝不作为 AI 输入。策略改变后后续局面也不同，分母因此不同；自我对弈的阵营胜率不能证明对人类的棋力或模式平衡。完整逐局记录在 `artifacts/ai-review/simulation.json`。

完整 Release 构建零警告/错误；早期 AI 基线为 Core **116/116**、WPF **23/23**，当前全量为 Core **171/171**、WPF **51/51**。规则版本 4 的 AI 目标牌选择只使用脱敏手牌数量和不透明 slot 候选；规则版本 5 的致命伤害后触发仍由 AI 自己的玩家视图决定，不读取目标暗牌或宿主栈；WPF 五场不同人数与身份的完整对局通过实际界面命令出牌 51 次、回答响应 31 次，均验证终局恢复。

新增扩展内容的主动/被动技能观察和 Core 结果回读也通过离屏控件回归。正式黄盖复用既有苦肉评分与私有救援选择，激将另覆盖 AI 阵营协助与提供者/有效使用者分离，救援保持原 AI 救援决策，奇袭复用过河拆桥评分并对装备成本计价，克己在无成本跳过弃牌时固定发动，突袭只按公开座位关系和手牌数选择组合，裸衣只读取许褚自己的杀/决斗持牌情况，强袭只读取典韦自己的武器候选和公开目标/体力，断粮只读取徐晃自己的已发布黑色牌候选和公开目标/距离，洛神固定继续公开判定而倾国只读取甄姬自己的已发布黑色手牌候选，集智只从黄月英自己的私有选择发动且不读取牌堆顶，铁骑只从马超自己的私有选择发动且不读取牌堆顶、鬼才手牌或目标暗牌，烈弓只从黄忠自己的私有选择发动且条件仅使用公开手牌数量、体力和攻击范围，狂骨则无 AI 选择并只读取公开伤害来源、伤害量、体力和战斗距离，无双仅让 AI 在公开的连续响应窗中复用原闪/杀响应评分，不读取其他角色暗牌；咆哮复用已发布的出杀合法动作与张飞自己的持牌视图，不新增暗牌读取或独立评分入口。

正式赵云的龙胆继续复用既有转化成本策略：AI 只在自己的已发布合法动作和响应候选中比较实体杀/闪的保留价值，不读取目标或其他响应者暗牌，也不因经典内容 ID 新增一套评分入口。

国战 M3 新增测试覆盖公开攻击对隐藏势力置信度的有界更新、公开势力优先级、新 AI 实例隔离，以及含公开攻击证据的中途 Checkpoint/Replay；v3 另覆盖身份局火攻公开证据，同时验证 v1/v2 的旧行为不漂移。真实控件还覆盖存档、手动弃牌、音效与动画路由。没有显示或操作桌面窗口，因此不宣称真实鼠标、键盘、多 DPI 或扬声器试听已验收。

本次新增的策略与结算区域及完整方案均通过格式检查。
