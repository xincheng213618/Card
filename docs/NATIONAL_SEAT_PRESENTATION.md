# 国战双将牌桌 · 2026-09-12

国战座位改为并排双肖像：左侧主将、右侧副将，各自显示姓名和暗置／明置标记。自己可以看见两名暗将，其他角色的未明置槽位显示暗将。悬停单个肖像显示该将的技能说明和启用状态，悬停座位其余区域可查看双将说明。

势力公开后，右上角和座位编号旁显示「同伴」或「对手」；未公开时显示「未明」，自己显示「自己」。关系标签只使用玩家已知的自身势力和其他角色已公开的势力，体力、选将记录或 AI 思考不参与推断。先明置副将也可以公开势力，但主将肖像继续保持暗置。

两个肖像仍属于同一个座位按钮，点击任意一侧均用于选择该角色作为目标。手牌数、体力、装备、距离、连环、判定和当前行动标记继续显示在原座位范围内。没有增加新的游戏命令或改变合法目标集合。

## 状态与隐私

- 新的 `GeneralSlotViewModel` 只投影所属玩家可见或已经公开的槽位。即使传入含暗将资料的可信调试快照，未公开的他人槽位也不会取得肖像、姓名或技能详情。
- 国战座位在开发者模式下仍从普通玩家快照构建；诊断数据不用于提前分配同伴／对手标签。
- 规则版本 7 及以后，暗置技能显示未启用，明置后显示启用。规则版本 1–6 的提示仍遵循主将技能生效、副将技能未启用的历史行为；没有技能的武将单独说明。
- 明暗状态由快照标记驱动，读档后重建；不新增存档字段。当前规则版本为 9，国战内容包保持 1.1.0。
