# 国战双将牌桌

国战座位并排显示双肖像：左侧主将、右侧副将，各自显示姓名和暗置／明置标记。自己可以看见两名暗将，其他角色未明置的槽位显示暗将。悬停单个肖像查看该将技能与启用状态，悬停座位其他区域查看双将说明。

势力公开后，座位显示「同伴」或「对手」；未公开时显示「未明」，自己显示「自己」。关系标签只使用玩家自己的势力与其他角色已公开的势力，体力、选将记录与 AI 思考不用于推断。先明置副将也可公开势力，主将肖像继续暗置。

两个肖像属于同一座位按钮，点击任意一侧都选择该角色作为目标。手牌数、体力、装备、距离、连环、判定和行动标记按座位显示。

`GeneralSlotViewModel` 只投影本人可见或已公开的槽位。国战座位在开发者模式下仍使用普通玩家快照，不从诊断资料补出暗将身份或关系。暗置槽位的技能显示未启用，明置后按实际技能状态显示；每个槽位展示完整有序技能列表。

明暗标记来自玩家快照，读档后重建。规则与隐私边界见 [`NATIONAL_WAR_EXPERIENCE.md`](NATIONAL_WAR_EXPERIENCE.md)。
