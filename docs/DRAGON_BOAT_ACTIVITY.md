# 龙舟争渡 · 2018双端八人四队

`activity:dragon-boat-2018` 采用官网2018年6月13日发布的[龙舟争渡规则](https://www.sanguosha.com/news/20180529_3733_5713)。这是一局两轮的八人四队竞分玩法。一个真人与一名AI组成船队，另外六名AI分别组成三支对手船队。

它与十周年2020年的三人对首领、左右鼓和天气玩法不同，也不加入2021年的争渡标记或2023年的主动擂鼓。

## 四队与选将

魏、蜀、吴、群各两席。玩家在大厅选择自己的船队，只能从对应势力的六名候选中选一将。队友的候选也在选将界面公开展示，其他船队的候选仍然隐藏。选将可见不代表可以查看队友手牌。

四位专属武将使用2018活动文本，分别为群吴苏飞、蜀魏黄权、蜀群刘琦、魏吴唐咨，不能用普通模式同名技能的现行文本替换。

| 活动将 | 技能 |
| --- | --- |
| 苏飞 | 联翩：自己或队友于出牌阶段连续使用牌指定相同目标后，可令该目标摸牌。 |
| 黄权 | 点虎：开局指定目标，自己或队友对该目标造成伤害后按点数摸牌；谏计：出牌阶段限一次，令队友摸一张牌并可使用该牌。 |
| 唐咨 | 兴棹：本队至宝达到2枚时双方获得恂恂，4枚时使用装备牌摸牌，6枚时跳过弃牌阶段；12枚时终局本队优先第一。 |
| 刘琦 | 问计：出牌阶段开始时可取队友一牌，本回合同名牌不能被其他角色响应；屯江：友方回合内未造成伤害，回合结束时可令该角色或自己摸两张。 |

官方禁将：左慈、标袁术、SP贾诩、SP步骘、SP灵雎、黄皓、荀攸、郭皇后、张让、袁绍、李儒、曹丕、满宠、蔡文姬、徐晃、大乔、界大乔、张春华、诸葛恪、黄盖、韩浩史涣。具体将池由活动包按实际角色和版本编号建立；普通武将复用项目已有版本，不宣称全体回退到2018年的技能版本。

## 至宝与终局

开局四队均为0枚至宝。角色对非本方角色每造成1点实际伤害，本队增加1枚，上限12枚。失去体力、未造成伤害的尝试，以及对自己或队友造成的伤害不计分。四队至宝、实时名次和同分到达先后均公开。

第二个实际轮次结束，且当前伤害、技能与移动子结算全部完成后，按至宝由多到少确定四队名次。同分时，先到达当前分数的队伍领先。额外回合属于实际回合，不等于新增一个轮次。

唐咨的12枚特例只改变终局排名，不会在达到12枚时提前结束。所有参与者随所属船队获得名次；战报与历史战绩中的名次是船队名次，不是个人阵亡名次。

## 艾叶守护

每名角色开局获得永久艾叶标记，不会在过程中失去。每次进入濒死状态时，将体力回复至1。这是可反复触发的模式规则，不是一次性复活。本地五阶的涅槃仍然保留，两者经过真实濒死结算，不直接删除伤害或模拟回复。

## 专属牌堆

以军争实体牌堆为基础，保留被替换实体的编号、花色和点数：桃替换为粽，酒替换为雄黄酒，无中生有替换为同舟共济，五谷丰登与桃园结义替换为力争上游，南蛮入侵与万箭齐发替换为逆水行舟。移除兵粮寸断、乐不思蜀和闪电。连弩采用额外允许三张杀的活动规则。

| 牌 | 效果 |
| --- | --- |
| 粽 | 出牌阶段对自己或队友使用，回复1点体力。 |
| 雄黄酒 | 出牌阶段对自己使用，本回合下一张杀伤害+1。 |
| 同舟共济 | 指定自己或队友，生效后本队双方各摸牌；本队至宝并列最多也算最多，每人摸2张，否则每人摸1张。 |
| 力争上游 | 对所有角色使用，使用者摸等于本队至宝数的牌、至多5张，其他角色各摸1张。 |
| 逆水行舟 | 对一名其他势力角色造成1点伤害，再按本队至宝是否最多或最少执行弃牌、摸牌。 |

## 明确的本地补充

以下是离线实现所需的约定，不冒充官方逐项规定：

- 八席按魏、蜀、吴、群、魏、蜀、吴、群排列，并依真人座位和所选船队旋转；先手由对局种子随机决定。
- 普通起手4张，玩家和AI统一套用用户截图的本地五阶：体力及上限+2、起手+1、出杀次数+1、摸牌阶段摸牌数+1，并保留一次濒死回复3、摸3的涅槃。因此通常起手为5张。
- 开局固定八份各六名候选，48名候选按角色家族不重复。四专将使用两种合法势力匹配中的一种，再各自在所属船队的一席出现一次；其余普通角色家族均匀抽取。公告只说专将出现概率高，没有公布概率。本项目明确采用此保证出现的算法。选将期间不开放额外完整将池。
- 两种专将匹配为：魏唐咨、蜀黄权、吴苏飞、群刘琦；或魏黄权、蜀刘琦、吴唐咨、群苏飞。每队再由种子随机选择一席放入该队专将，四位专将各只出现在一份候选里。
- 开局四队同时0分时，以魏、蜀、吴、群作为最终排序兜底；后续以实际到达记录比较同分。
- 同舟共济指定一个友方目标，经过一次无懈结算后对同队两人依次摸牌，在生效时判断是否至宝最多，包含并列。
- 逆水行舟先完成真实伤害及所有子结算，再冻结本队是否最多和最少。先按最多弃1张并完成弃牌子结算，再按已冻结的最少摸1张。四队同分时可以两项均执行，不在弃牌子结算后重新判断。
- 不接入网络匹配、每日活动体力、VIP、商城、账号积分或奖励兑换。玩家手牌、候选和回放仍遵循各自投影边界。

## 桌面呈现与恢复

大厅有四个船队选项。选将界面展示本人的六名候选和队友候选；牌桌四船榜显示当前实际轮次、至宝数、名次、同分到达先后与唐咨终局优先提示。战报保存四队公开排名，并将相同船队的两位角色列在一起。

存档包含活动包、模式定义、至宝到达事件与命令日志。恢复时重新投影同一份公开排名和私有选将信息，不从可信诊断栈提取其他角色的私有信息。跨配置恢复后再战继续使用存档对应的活动内容。
