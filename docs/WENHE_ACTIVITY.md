# 文和乱武 · 十周年2019八人生存

本项目的 `activity:wenhe-2019` 对应十周年2019年7月公告中的八人生存玩法。它与三人对抗首领的「讨逆」是不同模式。一个真人与七名AI各自求生，没有队友或阵营合作；角色阵亡后获得个人名次，最后存活者第一名。

轮次规则、内部乱武结算、五阶涅槃与志向标记以独立的永久模式授予保存。更换武将、断肠及武将压技后，这些对局规则仍然有效；它们不属于武将的印刷技能，也不参与失技数量与失技奖励计算。保护绑定到具体模式授予实例，普通同名技能仍按原有规则处理。

## 规则依据与版本

主来源是官网 [2019年7月31日文和乱武公告](https://sanguosha.com/news/20190730_5380_1510)。采用其中的八人结构、军争牌堆替换、禁将、击杀成长、七种轮次规则、四张锦囊和冠军／前二／前四／前六志向。

[2021年4月28日公告](https://www.sanguosha.com/news/20210425_3756_1020) 只补充实体桃与转化桃的解释：宴安鸩毒改变的是实体桃，技能转化或虚拟桃仍可正常使用。不引入该公告的选将框数量、禁将差异、讨逆玩法或账号奖励。2019年8月后续公告的前三志向也不覆盖本次七月版本。

## 一局流程

从项目现有普通武将版本中选择一将，候选与完整将池仅本人可见。初始行动座位随机；正常行动按座次推进。第一轮固定乱武，往后每个实际轮次开始随机抽取一次规则并公开，允许重复抽到同一规则。额外回合仍属于实际回合，会执行对应的回合开始／结束规则；它本身不额外抽取下一轮规则。

击杀一名其他角色后，击杀者增加1点体力上限并摸3张牌。增加上限不回复体力；没有有效击杀者或自杀时没有此奖励。死亡技能和奖励子结算全部结束后才确认冠军。阵亡名次随实际死亡先后确定；已阵亡的真人可以继续观战。

| 本轮规则 | 行为 |
| --- | --- |
| 乱武 | 轮次开始时从随机角色起，所有存活角色依次向最近的其他角色使用杀；不使用则失去1点体力。包含发起此轮规则的角色。 |
| 重赏 | 击杀成长变为体力上限+2、摸6张，仍不回血。 |
| 破釜沉舟 | 每个实际回合开始时，该回合角色失去1点体力，然后摸3张。 |
| 横刀跃马 | 每个实际回合结束时，装备数量最少的全部存活角色各失去1点体力，再从牌堆随机置入一件可装备的牌。 |
| 横扫千军 | 本轮伤害增加1点；连环传播保留已确定的伤害基数，不对同一传播增量重复加成。 |
| 饿莩载道 | 实际轮次结束时，手牌最少的全部存活角色各失去等于当前轮数的体力。 |
| 宴安鸩毒 | 实体桃视为毒，不能作为通常的桃使用或救援。该实体正面朝上离开手牌区时，原持有者失去1点体力；暗中转移不触发。转化桃与虚拟桃不受此替换。 |

最近距离使用本局真实战斗距离，包括装备和武将技能。被要求出杀时走正常的实体／转化杀、合法目标与响应结算，不直接模拟扣血。

宴安鸩毒期间，实体桃在技能的输入牌名匹配中按毒处理：只允许以桃为材料的转化不能使用它，允许红牌或基本牌的转化仍按技能条件判断。转化成桃的使用与救援正常结算，公开支付毒材料造成的失去体力先于该牌效果；实体编号、花色、点数和原印刷牌名仍留在真实付款记录中。

## 活动牌堆

以军争160张实体牌堆为基础，保留对应实体的编号、花色和点数：桃园结义、木牛流马改为斗转星移；黑色无懈可击改为偷梁换柱；红色无懈可击改为李代桃僵；移除乐不思蜀；兵粮寸断改为文和乱武。毒是宴安鸩毒轮对桃的有效身份，不凭空增加一批毒牌。

| 锦囊 | 目标与效果 |
| --- | --- |
| 斗转星移 | 指定另一名角色，随机重新分配双方当前体力，双方至少为1且不超过各自上限。 |
| 偷梁换柱 | 对自己使用，重新分配所有存活角色装备区中的牌，遵守真实装备槽容量。 |
| 李代桃僵 | 指定另一名角色，随机重新分配双方当前手牌。手牌仍保持私密。 |
| 文和乱武 | 对自己使用，除使用者外的其他存活角色依座次向最近角色使用杀，否则失去1点体力。与包含所有人的轮次乱武分开处理。 |

这四张牌均进入正常用牌、目标和无懈结算。自用锦囊的公开合法动作无需人工再选择自己，内部用牌目标仍是使用者。随机分配的结果写入真实实体移动及回放，不复制卡牌。

## 禁将

采用2019年7月公告：所有神将，华佗、刘备、界刘备、于吉、左慈、徐晃、卧龙诸葛亮、曹仁、大乔、界大乔、孟获、荀攸、郭皇后、诸葛诞、陈宫、界甘宁、小乔、周泰、陆绩、诸葛瞻、董卓、兀突骨、庞统、董允、孙鲁班、蹋顿、袁绍、曹丕、满宠、贾诩、蔡文姬、灵雎、步骘、曹节、刘焉。

禁将使用项目真实角色家族编号，并补上旧定义缺少 `CharacterId` 时的精确版本编号匹配。郭皇后的两种历史家族拼写均覆盖。卧龙诸葛亮与普通诸葛亮分开；只禁界甘宁，普通甘宁仍可选。现有武将技能版本沿用项目版本，不宣称全部回退至2019文本。

## 本地约定

以下内容是为离线单机活动补充的明确约定，不能当作官方原文：

- 玩家与七名AI统一五阶，使用用户剑阁截图的累计特权：体力与上限+2、起手5张、出杀次数+1、摸牌阶段摸牌数+1，一局一次濒死涅槃，回复3点体力并摸3张牌，保留手牌、装备和武将状态。
- 初始给5名合法武将候选，可展开全部合法将池；不模拟VIP选将框、手气卡或换将卡消耗。
- 2019主公告没有逐席规定先手，项目将初始行动座位随机作为本地约定。
- 在开局面板免费选择冠军、前二、前四或前六志向。AI默认冠军。冠军志向获得一次出牌阶段摸2张的「志在必得」；志向及未使用标记仅本人可见，用后公开标记。没有乱武券、积分、账号奖励或付费结算。
- 斗转星移保持双方当前体力总和，在合法整数分配中均匀抽取；李代桃僵先均匀抽取使用者获得的张数，再打乱实体分配，并不强制均分。
- 偷梁换柱按装备槽分组，将实体随机分配到仍可用的槽位。项目后增的武将专属武器 `GeneralWeapon` 保留在原主人的装备区，不移交给其他人；槽位已废除或被专属武器占用时不能接收不合法装备。
- 同一规则先冻结本次最低装备／手牌的并列角色，再依次结算，不在每个角色受影响后重算名单。牌堆没有可用装备时不凭空制造装备。
- 当前回合角色阵亡后，等已有子结算完成，仍由存活角色承载本回合的一次横刀跃马；不因此发动死者的普通结束阶段技能。2019公告没有单列此死亡情形，这是本地明确约定。[2015年官网规则优化](https://www.sanguosha.com/news/20151112_1807_1410) 关于死亡后等待现有结算完成再结束回合的调整只作边界参考，不宣称它逐项规定了2019活动实现。
- 若一条死亡链最终使全体阵亡，则整局为平局；已按真实死亡次序确定的个人名次保留，不虚构存活冠军。

## 实现边界与验证入口

活动包 `wenhe-activity` 独立选择加入，模式元数据、包指纹和命令日志共同恢复本局。私有志向通过本人快照投影，公开战报只包含实际名次与公开使用后的标记。桌面按个人名次呈现结束结果，声音和胜负历史按真实冠军席位判断。

专项入口为 `WenhePackageChecks`、`WenheRuleChecks`、`WenheRoundRuleChecks`、`WenheRuleGrantChecks`、`WenheCardChecks`、`WenhePoisonChecks`、`WenheAiChecks` 与 `WenheActivityUiChecks`，均复用现有 `Wenhe` 名称过滤；具体已执行结果以本批验证日志为准。完整验证仍须用户明确要求。
