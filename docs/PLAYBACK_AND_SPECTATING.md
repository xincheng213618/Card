# 对局速度与阵亡观战

右下角可直接选择「从容」「标准」「快速」。自动推进逐步执行，每次需要玩家出牌、选牌或响应时停下。三个档位分别使用 1200、350、100 毫秒的计时器间隔，由 `PlaybackSpeed` 定义，仅影响界面节奏。

玩家阵亡但牌局未结束时，操作区显示观战状态，并提供「快速观战」入口。点击后启用快速自动推进；取消「自动推进」可暂停，打开指南或新对局设置也会暂停。观战继续到实际胜负确定，使用原有结算与战绩页面，阵亡本身不会被当成阵营失败。

速度以可选 `PlaybackSpeedId` 字段随手动与自动存档保存；缺少该字段时使用标准速度，未知档位会在替换当前牌局前被拒绝。教程往返和新对局保留用户选择的速度；观战存档恢复原局及自动推进设置。
