# 活动场与版本来源

活动名称不能单独确定规则。同名玩法在三国杀 OL、十周年以及不同返场年份中，会改变人数、牌堆、Boss、等阶和复活效果。本项目按下表分别记录版本；只有完成战斗规则、AI、存档和对应验证的模式才注册到大厅，研究清单不产生占位入口。

## 几个不能混用的规则

- 神武2017的撒豆成兵，对神势力是额外摸一定张数；2024的公告描述则是补牌。两者必须随模式固定。
- 神武2020的重生会清理判定、复原、补手至限定张数并回复满体力；2024公告描述为清理判定、复原、直接摸5张，体力回复至体力上限且至多5。
- 年兽2022的福神需要弃置所有牌、复原、摸3并将体力回复到3；与截图剑阁涅槃的保留现有牌、回复3点不同。
- 2018驱鬼逐邪与2020十殿阎罗虽然都是四关合作，但Boss池、登场规则、隐藏关和卡牌不同。

## 规则扩展边界

活动的座位、阵营、胜利目标、跨关流程和等阶应由活动定义驱动；不要把所有活动强行套进剑阁八席。普通武将仍使用现有技能内容，活动专属技能和牌堆独立注册。新增随机过程使用对局种子和可重放命令路径，切关必须等死亡与技能结算完成，玩家视图继续隐藏队友手牌和私有选择。
