# 单骑无双 · 单机 AI 版

单骑无双是一场独立的 1v1。山河图则是多关闯关：沿路线收集山河策、解锁战法并配置初始构筑，后续迎战更强敌人。两者可以复用已实现的战法规则和界面素材，但货币、商店价格、成长与存档分别管理；单骑不使用山河图的银两、山河策或征程解锁条件。

## 核实来源

- [2024 年 7 月官方更新公告](https://www.sanguosha.com/news/20240728_7326_3415)：单骑无双为肉鸽 1v1，含叫分抢先手与虎符商店。
- [2025 年 8 月官方更新公告](https://www.sanguosha.com/news/20250811_4808_4017)：单局最长 15 分钟。
- 2026-10-21 读取[官方公开客户端配置](https://web.sanguosha.com/220/h5_2/res/config/Config.sgs)：`hd_1v1_rogue` 给出单骑价格、商品品质、购买时间 20 秒、初始选择时间 15 秒、技能槽上限 2；以战法编号关联 `hd_roguelike.Root.Tactics` 的名称与描述。完整 194 条战法记录和配置校验值保存在 [wushuang-reference.json](content/wushuang-reference.json)。配置条目存在不代表服务器当期全部开放，也不代表已实现；没有取得服务端抽取概率。
- 用户本次实测与截图：初始免费战法三选一；自然回合收入 1，轮次收入另加 1，重合时为 2；购物结束后继续牌局；花 1 虎符刷新，整页锁定，售出位置显示“已购买”。本地基础收入采用这次实测。旧版社区攻略的收入时点不作为当前依据。

原版素材的来源 URL、切图坐标与 SHA-256 在 [wushuang-ui-assets.json](content/wushuang-ui-assets.json)。素材来自公开客户端，仅用于本项目已有的原作参考实现；未声称拥有素材版权。

## 本地规则与流程

模式 ID 为 `wushuang:solo`。玩家与一名 AI 公开敌对，复用现有选将、响应、结算与实体牌移动系统。

| 环节 | 本地实现 |
| --- | --- |
| 先后手 | 随机决定；先手 4 张、后手 5 张。不模拟叫分、付费豆子和 OL 账号资源。 |
| 初始战法 | 正式出牌前从随机 3 个候选中免费选 1 个。必须选择，15 秒未操作由本地主机选择首项。 |
| 起始虎符 | 0；每个自然回合开始双方各得 1，新一轮开始双方另得 1。额外回合不另发基础收入。 |
| 经验 | 无经验、无商店等级和付费升级；商品 `level` 指品质。旧快照相关字段保留为固定兼容值，不参与规则。 |
| 购买阶段 | 每个自然回合结束、结束阶段及其子结算完成后开放，双方依次处理；玩家 20 秒，AI 自动购买。额外回合不另开商店。 |
| 四格商店 | 1 个可用技能、2 张实体卡牌、1 个战法；候选不足以卡牌补位。可连续购买本页不同商品。 |
| 刷新与锁定 | 购买结束准备下一页；回合中可预览，回合结束的购买窗口开放同一页。花 1 虎符手动刷新；锁定保留整页及已售位置，手动刷新仍换页并保留锁定开关。 |
| 技能槽 | 原武将技能不占槽；额外技能最多 2 个，满槽购买需先明确选择替换项。战法、卡牌不占槽。 |
| 购买结束 | “结束”、Esc 或 20 秒超时提交结束购买，继续牌局；购买期间不能绕回出牌询问。回合中的预览只显示下一页，不允许购买、刷新或锁定；免费商品使用绿色按钮，虎符不足的价格标红，技能满槽显示“已满替换”。 |

当前可抽取池有 24 个已接入规则的战法：当头一棒两档、雷火势两档、连击两档、锦囊计、多多益善三档、药理四档、赌术、弱袭、妙技两档、噬血、反刺、搏命、兵权三档。使用单骑配置的价格与品质；效果复用相应山河图规则，搏命和虎符专用兵权在单骑实现。兵权Ⅰ自己的自然回合额外获得 1，兵权Ⅱ每个自然回合额外获得 1，兵权Ⅲ将自然回合收入翻倍。轮次基础奖励单独发放。

技能池为武圣、龙胆、倾国、连营、英姿、集智、制衡、咆哮、铁骑、烈弓、无双；本地暂统一 2 虎符、紫色品质。卡牌暂使用闪、杀、桃、无懈可击、决斗、无中生有；桃和无懈 1 虎符，其他 0 虎符。这部分是有限本地商品池，尚未复现全部官方技能/卡牌表与刷新概率。已拥有的技能和同编号战法不会重复进入候选。AI 使用同一资源、价格和技能槽约束，每页优先购买一个可负担的战法或技能。

## 范围与尚未复现部分

已核实的 194 条配置不等于 194 个可用战法。截图中的拂衣去、愈战愈勇、衡锋已有来源记录，尚未加入可抽取池。客户端另有“进入激战阶段，每回合获得虎符增加”的文本，但未核实激战触发轮次与数值，本地暂不臆造该阶段。经典牌堆仍保留坐骑和延时锦囊，尚未复刻 OL 专用牌堆和全部活动武将池。

全局限时 15 分钟，商店和思考期间继续计时；经过时间由主机命令记入日志，离线时间不补计。时间到按本地体力比例、体力值、手牌数依次比较，完全相同则平局，没有模拟官方 MVP 公式。超时关闭未完成子结算，已经支付的牌不重复支付或退回。

## 存档与验证

单骑自动与手动存档在 `%LOCALAPPDATA%\CardGame\Saves\Wushuang`，与普通对局和山河图分开。初始选择、购买、锁定、刷新、获得战法和计时均由原生命令与所属结算帧恢复；按玩家视角投影，私有商店不会暴露给对方。

针对性检查使用现有名称过滤器 `Wushuang mode`、`Wushuang UI`；例行检查由 `tools/Test-Changed.ps1` 选定范围。完整检查只在用户明确要求时运行。
