# 牌桌与玩家功能

WPF 客户端以牌桌为中心：其他角色围桌落座，玩家和手牌在底部，中央显示公开用牌、判定与当前询问，战报和开发者工具位于侧栏。规则通过正式命令提交，界面快照、提示与效果从已提交结果重建。

## 开局与基本操作

默认大厅提供五人经典身份、八人经典身份、2v2 阵营和六人国战 M3。开局设置控制本次新局预览，确认开始才替换牌局。身份选将支持候选、同人物版本预览和完整允许武将名录；国战依次选择同势力双将。选将后可重新随机本人的起手牌，确认后进入对局。

可用手牌和目标高亮，点击选中项可以取消；Enter 确认，Esc 取消，数字键选牌，Ctrl+Enter 结束出牌。回合末按实际手牌上限选择准确数量的牌，推荐弃牌只代选候选，仍由玩家确认。声音、动画和皮肤独立保存为本机偏好。

## 实现边界

`DiscardCardsCommand` 验证当前玩家、PromptId、Revision、准确数量、重复项和所有权后统一移动牌。普通玩家视图只包含自身私有信息与公开状态，表现层不会因动画、建议或指南取得其他玩家暗牌。

自动推进只执行可推进步骤，遇到玩家选将、出牌、响应或选牌即暂停。模态面板隔离牌桌输入并暂停推进，关闭后按原设置恢复。未提交的手牌、目标和技能选择属于界面状态，磁盘存档保存已接受的命令。

游戏为离线本地实现；2v2 与国战包含明确的简化边界。启动和包装方式见 [`LOCAL_PLAY.md`](LOCAL_PLAY.md)，规则模式见 [`MODES_AND_RULESETS.md`](MODES_AND_RULESETS.md)，AI 见 [`TACTICAL_AI.md`](TACTICAL_AI.md)。
