# 本地开玩

这是支持 Windows x64 的离线单机卡牌游戏，已包含 .NET 8 运行时。解压整个 ZIP，双击 `CardGame/CardGame.Wpf.exe` 即可进入游戏，无须安装开发工具。保留程序旁的文件和 Assets 文件夹。

在源码目录内，双击根目录的 `Play.cmd` 可打开最近一次验证通过的本地游戏包。

如果源码目录尚未生成游戏包，`Play.cmd` 会使用项目要求的 .NET SDK 构建并启动 Debug 开发版，无须先打包。已有游戏包时仍优先启动游戏包。`tools\Start-Game.ps1 -VerifyOnly` 只检查现有启动路径，不执行构建。

## 第一局

1. 在开局面板选择模式或队伍，开始对局并选择武将。身份场只有五人和八人两种，默认随机身份，也可在开局设置、身份揭示或选将面板中自选身份；主公为 1 号位，沿右手方向依次编号。主公、内奸各有 13 个候选（上 7 下 6），忠臣、反贼各有 8 个候选（上 4 下 4）。右侧可切换同人物版本，切换不增加候选数量，确认出征才提交该版本。
   身份场先由主公选将并公开，本地玩家接着选，其余 AI 随后暗选，进入牌局时公开其余武将。队伍场由本地玩家先选，国战先选完本地双将，再由 AI 暗选；首回合顺序仍按模式规则决定。
   点击「自选武将」可搜索当前模式允许的完整武将库，预览后确认出征；身份场名录会排除已公开的主公武将。「返回候选」回到原来的候选列表。搜索框外的数字键 1–9 按当前搜索结果顺序预选，并将焦点移到对应武将；列表行获得焦点时，Enter 先预览该武将，再按一次确认。改选身份会重新准备本局的身份与选将。国战确认主将后清空搜索词，副将可从同势力的剩余武将中重新搜索。
   选将完成后，起手牌等待你确认。点击「重新随机手牌」将自己的起手牌放回牌堆，洗牌后重新抽取同样数量；其他玩家手牌不变。点击「进入牌局」才开始对局，之后不能再改身份或重新随机起手牌。
   切换同人物版本后，版本按钮保持键盘焦点；选将中读档后，焦点回到当前候选。
   在当前窗口刷新或重新加载同一选将询问时，各候选已切换的版本都会保留；新的候选询问从默认版本开始。
2. 初次游玩可先进入「新手演练」，练习出杀、出闪、回复和弃牌。
   教学目标尚未完成时，结束出牌会提示继续练习，并保留已选的牌和目标。
   从牌桌进入演练再返回，会保留原来的选牌、目标顺序、已选技能和选将版本预览；回到牌桌后确认才提交操作。
   开局前即可调整音效、音量和动画；首次启动默认开启动画，右侧「动画效果」可随时切换。设置在下次启动时保留，读档也不会覆盖当前静音状态。
3. 点选底部手牌，再点目标座位，按主操作按钮确认。闪、杀、救援、无懈和火攻响应可直接选择亮起的手牌，再点击下方确认；「取消」放弃本次可跳过的响应。技能、装备或多牌响应仍在中央选择，火攻展示不能跳过。
   木牛流马中的粮牌若可用于唯一的单牌响应，也会在底部亮起，可点选或按数字键预选，再按 Enter 确认；Esc 只取消选牌，响应区的「取消」放弃本次响应，不支付预选的粮牌。
   切换对局速度或往返设置、指南时，当前中央响应选项保持键盘焦点；读档后按钮只绑定当前询问的选项。
   回合末「推荐弃牌」只选中当前允许弃置的牌，可以取消或调整后再确认；手牌上限以当前询问提示为准。
   技能费用的同花色或不同花色要求会显示在操作提示中；技能允许的装备也可作为费用，不满足花色要求时确认按钮保持不可用。
   剑合的费用须选至少两张同名牌（普通杀、火杀、雷杀均视为同名），或全部选装备；混选其他牌名时确认按钮不可用，调整选牌后即可继续。
   直谏、结姻等装备费用选好后，目标高亮会随所选装备更新；更换费用后若原目标不再合法，确认按钮不可用，点击原目标取消再改选即可。
   缔盟选定一名角色后，另一目标的高亮会按合法组合更新；点击已选目标取消后可以换组。
   折妇等技能选人可直接点桌上的武将卡，选中只加边框，再用下方「确定」执行；多人选择按技能要求选齐，需要区分先后时按点击顺序选择。「取消」清空必选目标的预选；允许放弃的选人则取消本次选择。Esc 只清空预选，武将卡尺寸保持不变。
   技能选人期间切换速度，中央「完成选择」等当前选项保持焦点；读档后旧按钮参数失效。
   铁索连环可直接点选一到两名武将（新局允许自己），选满后先取消一个再更换；选好目标后才确认出牌。新局也可不选目标，点击「重铸换牌」将铁索换成一张新牌。重铸等补充按钮显示在固定操作区上方，选牌、选人和取消均不挤占武将卡的空间。
   同一张牌有技能转换方式时，先在中央选择对应技能，目标高亮和多人组合会随所选方式更新；只有该方式允许重铸时才显示「重铸换牌」。
4. `Enter` 确认当前操作，`Esc` 取消选择，`Ctrl+Enter` 结束出牌阶段；`F1` 打开指南，`F5` 手动保存，`Ctrl+M` 切换静音。
    `Ctrl+Enter` 只在出牌阶段结束出牌；在响应、选将、身份提示、起手牌提示和结算页不会执行当前焦点按钮。
    焦点位于「取消」「结束」等操作按钮时，`Enter` 执行该按钮；焦点在已选手牌或目标上时，`Enter` 确认已完成的预选。移到另一张可用牌或合法未选目标后，`Enter` 先预选该项；选齐后再按 `Enter` 确认。
    选将时，焦点移到另一候选或同人物版本后，`Enter` 先预览该项；再次按下确认。数字键预选也会将焦点移到对应候选，可接着按 `Enter` 确认。
    自选武将搜索框中的数字与 `Enter` 用于输入，不触发选将确认。身份和起手牌按钮可用 `Tab` 移动焦点，再按 `Enter` 执行。`Shift+Enter` 也执行当前身份或换牌按钮，不会误触默认的「继续」或「进入牌局」；长按不会重复换牌或连续确认国战主、副将。
    数字 `1–9` 依次选择手牌或预览候选武将，并将焦点移到对应牌或候选；这些快捷键每次按下只执行一次，长按不会反复切换选择、重复保存或确认后续询问。`Shift+Esc` 也只关闭当前最上层面板，长按不会继续关闭保留的图鉴详情或下层面板。
   起手牌展示期间打开设置、指南、战绩、武将图鉴或新对局面板，键盘先操作上层面板；`Esc` 返回时不会误关闭底层起手牌提示。图鉴详情先关闭详情，再返回牌桌。
   成功读档会撤下上一局的身份和起手牌提示；进入新手演练时暂时收起，返回正式牌局后恢复原来的开局步骤。
   新局起手牌确认不自动倒计时，关闭动画仍可查看和重新随机手牌。旧存档的起手牌动画在设置、历史、武将库、指南、大厅或战报覆盖时暂停倒计时；关闭动画会取消这类展示，教学返回也遵守当前动画设置。
   多个面板并存时，`Esc` 只处理最上层，返回图鉴会保留原详情；设置和战绩中的 `Ctrl+M` 仍可切换静音。
   身份揭示结束后，焦点进入候选武将区；选将完成后，起手牌提示取得焦点。关闭面板会恢复当前可操作区域，快速关闭再重开也保留原来的返回位置。
   打开或关闭面板期间，已选中的当前可用控件会保留键盘焦点。
   手牌横向溢出时，鼠标点选可见牌保持当前位置，便于继续点击或双击；用键盘选择屏幕外的牌仍会自动滚入视野。
   出牌阶段可在指南的「当前操作」中查看出牌建议。判定区牌合法转化时，建议会区分实体牌面与当作使用的牌；查看建议不会改选牌、目标或提交行动。
   建议会按技能的完整费用与目标组合选择；新建牌局的 AI 也遵守这些组合约束。读档保留该局原有的 AI 策略版本，以维持回放一致性。
   使用牌和打出的响应牌会从对应武将的位置飞入中央，牌下标注武将名与「使用／打出」。群体锦囊保留在左侧，后续响应依次放在右侧；关闭动画仍显示这些公开牌。普通手牌响应时，中央牌区与提示同时可见。
   普通摸牌及额外摸牌阶段会显示牌背从牌堆飞出，并提示实际摸牌张数；自己的牌飞向手牌区，其余牌飞向对应角色，不会展示其他角色的新手牌。手牌即时可操作，关闭动画、读档或重新打开牌桌不会补播旧摸牌。在特效预览中点「摸牌」可重播。
   开启动画后，公开牌沿弧线飞入桌面并亮起落牌描边，杀的刀光到达目标边缘；实际受伤时才显示冲击与伤害飘字，闪则显示残影护盾。同一段快速结算按出牌、攻击到达、结果的顺序呈现，操作与规则结算即时生效。火雷伤害、回复和公开技能发动显示对应特效。在「设置 → 预览战场特效」中可逐项重播，也可预览「出杀 → 命中」和「出杀 → 闪避」；预览不改变对局或存档。
   武将头像底部的血条即时显示当前体力，低体力时转为暖红色。受伤后红色余量短暂回落，回复时新增部分亮起；连续结算以最新的体力结果为准。关闭动画或读档仍保留当前血条，不重播旧的受伤、回复过程。
5. 可调慢、标准、快速三档对局速度。阵亡后可加速观战，也可暂停查看牌桌；结束后查看战绩并重新开局。
   打开战报时自动推进暂停；收起后按原来的自动推进设置继续。

使用武圣时，新局遇到决斗或南蛮入侵可以选择亮起的红色手牌，点击「当作杀打出」完成响应。红色的闪、锦囊等均按同一规则判断；黑色非杀牌不能这样响应。旧存档保留原来的可用响应范围。

南蛮入侵和万箭齐发的普通响应只需选择底部亮起的杀或闪，再点下方确认；「取消」放弃本次响应。击杀反贼的存活伤害来源会摸 3 张牌，不受其自身身份限制。

国战依次选择两名同势力武将。主将卡片显示基础体力，副将候选显示组合后的上限：两将基础体力平均、向下取整，开局满体力。自己的出牌阶段可分别明置主将、副将，对应技能才生效；在【决斗】或群体牌的【杀】响应窗口内也可以明置，系统会只刷新自己的响应候选；明置不回复体力。旧版国战存档仍使用固定 4 点体力，游戏内指南会说明当前规则。

选择「国战 M3」时，系统分配魏 3、蜀 2、野心家 1，野心家是唯一一席的独立势力；最后存活势力获胜。这是三方人数实验，不包含完整野心家规则、阵法、围攻、变更副将或国战专属牌堆。大厅不再提供国战张角、Lite、界限突破身份或技能演示入口。

拆、顺和技能选择他人的暗牌时，中央显示牌背，点选对应牌背即可；可以查看的牌显示正面。规则要求随机取牌或弃牌时，直接结算，不弹选牌界面。
同一暗牌询问刷新时，键盘焦点返回原牌位的当前按钮；读档后的旧按钮参数失效，仍显示牌背。

自动和手动存档位于 `%LOCALAPPDATA%\CardGame\Saves`。更新游戏包不会删除存档；不兼容的旧规则存档会提示拒绝读取。所有版本共用同一存档目录。

声音和动画另存于 `%LOCALAPPDATA%\CardGame\preferences.json`。如果没有本机偏好，首次读档会导入旧档中的设置；其后保持当前本机设置。对局速度与自动推进仍随牌局恢复。

开局面板、牌桌右上角和结算页均可打开「历史战绩」，回看最近 50 场正式对局的结果和全员统计。战绩保存在 `%LOCALAPPDATA%\CardGame\History`，重新开局后仍保留；同一终局重复加载不会重复计入，新手演练不计入。查看时暂停推进，按 `Esc` 返回原来的牌局。
尚无战绩时，键盘焦点只在「返回牌桌」「刷新战绩」之间循环；刷新读到记录后即可进入列表和详情。

当前为简化规则的本地游戏，部分技能存在演示差异，详见游戏内指南与卡牌图鉴。尚不支持联机。

## 从源码重新打包

开发者需要项目 `global.json` 指定的 .NET 8 SDK；首次恢复运行时包可能需要网络。在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-GamePackage.ps1
```

默认打包运行时为 8.0.31，可用 `-RuntimeVersion 8.0.x` 指定实际存在的 .NET 8 补丁版本。脚本每次创建独立输出，保留之前的游戏包和构建产物；仅在 ZIP 解压、实际程序启动、运行时、界面渲染和音效文件检查通过后更新 `Play.cmd` 使用的指针。检查不会显示桌面窗口，也不会读取或写入玩家存档。它不代表真实鼠标、键盘、多 DPI 或声音实听验收。

输出位于 `dist/releases/<构建编号>/`：完整游戏目录、ZIP、SHA-256 校验文件、验证报告和开局预览。脚本逐一对比发布目录和已恢复运行时包中的 DLL，再校验 ZIP 解压后的全部文件；游戏目录内保留 `package-files.json` 文件校验清单。使用 `tools\Start-Game.ps1 -VerifyOnly` 可检查启动路径而不打开游戏。
