# 本地开玩

这是支持 Windows x64 的离线单机卡牌游戏，已包含 .NET 8 运行时。解压整个 ZIP，双击 `CardGame/CardGame.Wpf.exe` 即可进入游戏，无须安装开发工具。保留程序旁的文件和 Assets 文件夹。

在源码目录内，双击根目录的 `Play.cmd` 可打开最近一次验证通过的本地游戏包。

## 第一局

1. 在开局面板选择模式、身份或队伍，开始对局并选择武将。
2. 初次游玩可先进入「新手演练」，练习出杀、出闪、回复和弃牌。
   开局前即可调整音效、音量和动画；设置在下次启动时保留，读档也不会覆盖当前静音状态。
3. 点选底部手牌，再点目标座位，按主操作按钮确认。需要响应时，按中央提示选择手牌或选项。
   铁索连环可直接点选一到两名武将（新局允许自己），选满后先取消一个再更换；选好目标后才确认出牌。新局也可不选目标，点击「重铸换牌」将铁索换成一张新牌。
4. `Enter` 确认当前操作，`Esc` 取消选择，`Ctrl+Enter` 结束出牌阶段；`F1` 打开指南，`F5` 手动保存，`Ctrl+M` 切换静音。
   出牌阶段可在指南的「当前操作」中查看出牌建议。它只作参考，不会自动改选手牌或提交行动。
5. 可调慢、标准、快速三档对局速度。阵亡后可加速观战，也可暂停查看牌桌；结束后查看战绩并重新开局。

使用武圣时，新局遇到决斗或南蛮入侵可以选择亮起的红色手牌，点击「当作杀打出」完成响应。红色的闪、锦囊等均按同一规则判断；黑色非杀牌不能这样响应。旧存档保留原来的可用响应范围。

选择「国战 Lite」时，系统分配魏或蜀势力，依次选择两名同势力武将。主将卡片显示基础体力，副将候选显示组合后的上限：两将基础体力平均、向下取整，开局满体力。自己的出牌阶段可分别明置主将、副将，对应技能才生效；在【决斗】或群体牌的【杀】响应窗口内也可以明置，系统会只刷新自己的响应候选；明置不回复体力。与同势力角色合作，消灭另一势力即可获胜。旧版国战存档仍使用固定 4 点体力，游戏内指南会说明当前规则。

选择「国战 M3」时，系统分配魏 3、蜀 2、野心家 1，野心家是唯一一席的独立势力；每名玩家仍依次选择两名同势力武将。该模式沿用 Lite 的双将暗置/明置、私有视图、AI 和回放语义，最后存活势力获胜；这是三方人数实验，不包含完整野心家规则、阵法、围攻、变更副将或国战专属牌堆。

自动和手动存档位于 `%LOCALAPPDATA%\CardGame\Saves`。更新游戏包不会删除存档；不兼容的旧规则存档会提示拒绝读取。所有版本共用同一存档目录。

声音和动画另存于 `%LOCALAPPDATA%\CardGame\preferences.json`。如果没有本机偏好，首次读档会导入旧档中的设置；其后保持当前本机设置。对局速度与自动推进仍随牌局恢复。

开局面板、牌桌右上角和结算页均可打开「历史战绩」，回看最近 50 场正式对局的结果和全员统计。战绩保存在 `%LOCALAPPDATA%\CardGame\History`，重新开局后仍保留；同一终局重复加载不会重复计入，新手演练不计入。查看时暂停推进，按 `Esc` 返回原来的牌局。

当前为简化规则的本地游戏，部分技能存在演示差异，详见游戏内指南与卡牌图鉴。尚不支持联机。

## 从源码重新打包

开发者需要项目 `global.json` 指定的 .NET 8 SDK；首次恢复运行时包可能需要网络。在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-GamePackage.ps1
```

默认打包运行时为 8.0.31，可用 `-RuntimeVersion 8.0.x` 指定实际存在的 .NET 8 补丁版本。脚本每次创建独立输出，保留之前的游戏包和构建产物；仅在 ZIP 解压、实际程序启动、运行时、界面渲染和音效文件检查通过后更新 `Play.cmd` 使用的指针。检查不会显示桌面窗口，也不会读取或写入玩家存档。它不代表真实鼠标、键盘、多 DPI 或声音实听验收。

输出位于 `dist/releases/<构建编号>/`：完整游戏目录、ZIP、SHA-256 校验文件、验证报告和开局预览。脚本逐一对比发布目录和已恢复运行时包中的 DLL，再校验 ZIP 解压后的全部文件；游戏目录内保留 `package-files.json` 文件校验清单。使用 `tools\Start-Game.ps1 -VerifyOnly` 可检查启动路径而不打开游戏。
