# 三国杀规则与体验覆盖边界

当前项目提供本地身份局、公开阵营 2v2、国战 Lite 及独立势力实验。判断某条规则是否完成，需要对照对应产品线的实际内容与原生结算；单个武将加入图鉴或某批检查通过，不代表完整官方规则集已经覆盖。

## 尚不能据此宣称完成的范围

完整国战包含超出 Lite/独立势力实验的模式规则与内容组合；应按当前模式定义逐项验证。项目也不以当前武将目录代表官方全量图鉴，不把同名经典、界、SP、谋或不同产品线技能视为等价实现。

每项复杂技能都可能涉及独立来源版本、时序及工程默认值。当前规则与配置见人物目录；需要补齐的能力应给出具体缺失入口和可复现条件，写入[能力请求](content/CORE_API_REQUESTS.md)。

## 校对与开发标准

- 文案准确描述当前注册与运行行为；规则来源原文、官方 FAQ 与工程解释分别标明。
- 优先复用已有原生用牌、牌区、伤害、回复、死亡与子结算返回。新共享能力保持提交、隐私、集合冻结和牌数边界。
- 行为检查使用现有名称过滤；纯配置由现有加载、Registry 和机制检查覆盖。例行范围取 `tools/VerificationScopes.psd1`，完整检查仅在明确请求时运行。
- 离屏画面、程序化输入与人工前台操作是不同证据；性能描述应写明测量对象与环境，不用历史测试数量或临时截图路径作为现状。

界面核对入口见[牌桌呈现与交互](../design-qa.md)，内容维护入口见[内容开发工作清单](LUNA_CONTENT_BACKLOG.md)。
