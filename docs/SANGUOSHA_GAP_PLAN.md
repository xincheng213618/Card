# 三国杀差距评估与 Sol 持续迭代计划

评估日期：2026-09-18。基线提交：`f607ece`。本报告由当前源码、完整构建、Core/WPF 回归及官方基础牌说明交叉核实。

## 结论与目标边界

当前项目是可玩、可存档、有 AI 和桌面交互的三国题材卡牌原型。单机体验骨架已经较完整，但距离规则较完整的经典三国杀单机版仍有明显距离：当前内容混合了经典规则、演示简化和原创技能。优先补规则一致性与真实武将组合，才能使后续内容积累有效。

不将所有功能折算成一个完成率：基础工程、单机交互较成熟；经典规则和内容仍处中段；完整国战只完成部分切片；真人联网系统尚未建立。测试全绿证明当前实现符合现有测试，不能直接证明符合三国杀。

默认近期目标是**经典身份玩法的本地可玩版本，逐步支持标准内容及军争扩展**。每批必须声明所采用的规则版本，不能混用标准、界限突破、国战和线上活动规则。现有演示包与历史存档继续兼容。完整国战、局域网/在线对战排在身份玩法稳定之后；账号、商城和运营服务不属于近期迭代目标。

## 已确认的高优先级证据

1. **乐不思蜀、兵粮寸断已按正式花色版本化。** 规则 v11 起，乐不思蜀仅红桃通过、否则跳过出牌阶段；兵粮寸断仅梅花通过、否则跳过摸牌阶段。`JudgmentResolvedEvent.Succeeded`/`DelayedCardResolvedEvent.JudgmentSucceeded` 对这两张牌表示“命中安全花色”，跳阶段由独立字段表达。鬼才按具体判定类型、目标阵营和当前公开结果选牌；v1–v10 保留历史红黑行为与 AI 路径，WPF 指南也按存档规则版本切换文案。
2. **酒已按正式濒死规则版本化。** 规则 v12 起只有濒死者本人能从自己的私有候选中使用酒自救；其他角色仍可使用桃。规则 v3–v11 的跨座位酒救援由 `UsesHistoricalCrossSeatAlcoholRescue` 保留，Prompt、AI、事件、牌区移动和恢复流程继续按旧存档版本执行；v1/v2 原本也只允许自救。
3. **武器牌面攻击范围已版本化。** 规则 v13 起，诸葛连弩攻击范围为 1 且仍允许出牌阶段使用任意数量的杀，青釭剑攻击范围为 2 且直接杀无视防具；`EquipmentDefinition.WeaponAttackRange` 表达牌面范围。v1–v12 继续按旧实现回放：连弩基础范围 +1、青釭剑沿默认范围 1。Standard 包内容签名保持冻结，Core 规则日志和 WPF 卡牌说明按存档规则版本投影。
4. **防具效果与响应时机已版本化。** 规则 v14 起，八卦阵在当前实现所有需要闪的路径（直接杀与万箭齐发）都可发动；群体判定成功/失败写入 `GroupResponseEvent`，但不伪造物理闪。仁王盾不再从合法目标列表移除黑色杀，而是在杀声明、目标确定后发布 `ArmorEffectAppliedEvent` 并令效果无效；青釭剑仍无视防具。v1–v13 保留直接杀八卦阵和仁王盾目标过滤。
5. **空城的杀/决斗目标限制已版本化。** 官方标准诸葛亮原文同时禁止空手角色成为杀或决斗目标。规则 v15 的经典身份局通过通用 `ProhibitsCardTarget` 查询过滤三类杀与决斗，合法动作、AI、WPF 目标和命令复核共用同一结果；v1–v14 与演示模式保留原先只禁杀的行为。
