# 使用中实体牌的续接边界

一次使用的实体材料、当前所在牌区和有效牌名分别由使用帧、牌区系统及动作上下文持有。技能合法取得使用中的牌后，原效果仍可继续；不能因为材料离开处理区就丢失原使用，也不能在收尾时再次移动已领取的实体。

`IsClaimedUseCardEntity(useId, cardId)` 统一检查领取来源。调用者必须提供当前原生使用的精确 ID，领取凭据必须能匹配该使用的动作及真实移牌事实。单凭“实体现在在手牌区”或技能名称，不能豁免处理区校验。

- 顺手牵羊、过河拆桥的暗牌选择继续保留原使用和不透明牌位。取得锦囊材料不会公开目标手牌，也不会改变实际选择次数。
- 多目标锦囊继续使用原实体与原使用身份，依次推进被冻结的目标游标。已经领取的材料不需要重新进入处理区。
- 借刀杀人的父锦囊和子杀分别核对材料。父牌被合法领取或没有实体时，子杀自己的未领取实体仍须完整留在处理区；不能把父牌与子牌混作一次支付。
- 群体伤害、群体恢复和五谷丰登分别保留原使用材料的领取证明。五谷丰登新展示的牌仍必须完整留在处理区，按实际选择逐张移出。
- 收尾只处理属于本次使用且仍未被合法领取的材料。领取后的再次移动、阵亡清理或其他子结算不会授权原使用重复弃置、重复取得或重复支付。

转换锦囊的目标调整来自当前已发布的合法动作。执行入口捕获其精确目标，转换路径复核基础使用选项，`BeginCardUse` 再消费这一次授权。重新查询基础选项时不能丢弃已确认的增减目标，也不能接受未发布的目标组合。

响应实体交换需要原锦囊的已接受使用事实。即使内容包没有其他最终目标订阅者，交换能力也必须启用这条事实路径，避免完整内容包中的无关技能掩盖缺失依赖。

行为检查关注真实领取、父子结算暂停、多个目标、暗牌隐私、单次效果和移牌、命令前缀冷恢复，以及错误动作 ID 的领取凭据被拒绝。故障后的可变帧只用于诊断，恢复始终从可信命令前缀重建。
