# 武将图鉴分类与布局

图鉴使用顶部系列页签、系列子分类、分组卡墙、势力筛选与搜索，点击武将查看详情。分类属于 WPF 展示数据，武将 ID、技能和模式池仍由内容注册表决定。

## 分类与筛选

| 系列 | 子分类 |
| --- | --- |
| 全部 | 按系列分组展示可见武将 |
| 标准 | 标准版 |
| 神话再临 | 风、火、林、山、阴、雷 |
| 一将成名 | 一至七 |
| 界限突破 | 标准及神话再临的界限突破版本 |
| 界一将 | 一将成名的界限突破版本 |
| 神武将、SP、谋、友、乐、武庙 | 各自单独展示；乐为正音雅乐系列 |
| 其他扩展 | 尚未指定系列的正式条目 |

`GeneralGalleryCatalog` 按完整武将 ID 指定归属，并通过 `IsVisible` 筛选展示条目。正式版本独立归类；合成占位与机制、国战试验条目不进入图鉴和搜索总数。不能仅凭 `classic:` 或 `standard:` 前缀判断所属系列。

神将按实际规则去重，不按平台数重复计数。已核对等价的版本在选将池和图鉴中只保留一个武将，其他立绘归入其皮肤；历史内容 ID、技能定义和素材来源继续保留。有实际玩法差异的版本分别显示规则标签，详情解释差异。映射与逐组核对记录见 [`content/GOD_GENERAL_RULES.md`](content/GOD_GENERAL_RULES.md)，不能只凭姓名或技能名自动合并。

系列、子分类、势力与武将名／技能搜索叠加生效。具体系列保留空分组并提示暂无武将，「全部」跳过空分组；搜索无结果时可以清除筛选。类别入口不表示其中所有版本均已注册，当前名单以注册表和 `GeneralGalleryCatalog` 为准。

系列与势力分别读取：例如周年神孙权属于神武将系列，正式初始势力为吴，详情和势力筛选均显示吴。历史正式活动武将通过规则标签和差异说明标明活动版本。

切换筛选回到卡墙顶部；小窗口顶部页签支持横向滚动与键盘焦点。卡墙按可视范围实现条目，避免一次创建全部武将控件。

## 详情、皮肤与台词

点击卡牌打开覆盖卡墙的详情。左侧大图使用武将立绘、原游戏透明卡框、势力图标和体力标记；右侧可查看技能、皮肤与台词。上一位／下一位沿当前筛选结果浏览，关闭详情后保留卡墙滚动位置。Esc 先关闭详情，再关闭图鉴。

横向原画在卡框内居中裁切，避免人物被挤到右侧边缘；原始素材保持完整，皮肤切换继续共享同一头像。

点击皮肤立即更新详情、图鉴卡、选将与已知座位的图片，不切换技能版本。`PlayerPreferences.GeneralSkins` 按规范外观键保存，失效皮肤 ID 回到默认图；暗将身份未知时不显示图片。台词页显示已核实的录音与文字，支持逐句试听，播放规则见 [`BATTLE_AUDIO.md`](BATTLE_AUDIO.md)。

经典立绘作为 WPF 资源内嵌，额外皮肤位于 `Assets/Skins/` 并随构建复制，运行时无需联网。缩略图限制解码尺寸，完整图按需加载，图像缓存使用弱引用。缺图条目明确显示暂无立绘。

## 来源与维护

- `docs/content/general-art-catalog.json` 保存武将外观键、皮肤、来源地址、尺寸和 SHA-256。
- `docs/content/gallery-ui-assets.json` 保存详情背景、卡框、徽章和体力素材的来源与 atlas 帧坐标。
- `docs/content/game-audio-catalog.json` 保存音乐、录音、台词及武将／皮肤关联。
- `docs/content/sources/` 保存具体武将版本与规则来源；技能实现状态应查对应内容和代码。
- `tools/sync_general_art.py` 同步并校验立绘，`tools/extract_gallery_ui_assets.py` 提取图鉴界面素材。

素材归属与绑定边界见 [`RESOURCE_CATALOG_DESIGN.md`](RESOURCE_CATALOG_DESIGN.md)。图鉴浏览只读取展示数据，模态打开时暂停牌局推进。
