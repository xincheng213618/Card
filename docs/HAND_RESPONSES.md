# 手牌响应与精确选择

受到杀或南蛮入侵等效果时，可以选中底部亮起的响应牌，再点击主按钮或按 Enter。救援、无懈、火攻展示与弃牌使用同样的单牌选择流程。数字键选择手牌，Esc 取消当前选牌，放弃响应需使用对应操作。

操作区与指南显示实际效果，支持武圣、龙胆、急救等转换。点击选牌不支付费用，关闭指南、取消新局设置及教学往返保留选择。手牌映射只消费本人当前询问中的完整候选；一张牌有多种效果时在中央明确选择，费用来自装备等其他区域时也使用中央精确候选。

## 武器与协助

- **借刀杀人**：持武器者的私有候选列出可用实体杀、转换、激将及「交出具体武器」。选择杀后进入普通杀响应链；若支付的装备影响攻击范围，Core 按费用支付后的范围验证目标。
- **贯石斧**：最后一张有效闪抵消杀后，来源可选择弃置自己的两张牌或不发动。候选明确列出实体牌与来源区，也可支付贯石斧本身；Core 付款后恢复原伤害链。
- **丈八蛇矛**：两张手牌合成一个有效杀候选，提交一次 Choice，Core 统一移动与结束两张实体牌。
- **雌雄双股剑**：先私有询问来源是否发动，再由目标选择弃置自己的确切手牌或令来源摸牌。
- **青龙偃月刀**：杀被最后一张闪抵消后，来源选择固定原目标的后续杀或跳过；可用转换与激将沿各自私有询问继续。原杀完整结束后创建新杀，不计普通出杀次数。
- **寒冰剑**：杀造成伤害前，来源可保留伤害或改为依次弃置目标的牌。暗手牌只显示不透明牌位，公开装备可精确选择；选择弃牌后防止伤害，目标仍有牌时继续强制选择第二张。

所有按钮只提交当前发布的精确 Choice；费用、所有权、目标、响应与后续伤害由 Core 验证和执行，界面不模拟牌区移动或伤害。其他座位看不到响应者的私有候选。

## 群体牌续接

群体结算在自己的帧中保留目标游标与伤害牌取得状态。伤害牌被技能取得后，可以合法位于手牌、弃牌堆或洗牌后的牌堆，后续目标仍由同一结算继续；未取得的牌继续受处理区归属检查约束。完成时统一收尾，不因玩家阵亡重复结束效果。
