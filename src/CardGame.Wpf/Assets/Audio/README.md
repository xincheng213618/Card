# 原创短音效

这组素材由本项目的 `tools/generate_game_audio.py` 生成，不含第三方采样、已有游戏语音或音乐。合成采用确定性噪声、衰减鼓音、泛音拨弦与金属共振，目标是短促、可辨认的牌桌提示。

音频为 44.1 kHz、16-bit、单声道 PCM WAV，峰值约 0.68，首尾淡入淡出。每个文件不超过 1.35 秒。文件名与 `GameSound` 枚举对应，随 WPF 构建和发布复制到 `Assets/Audio`，无需下载素材。

`manifest.json` 记录持续时间、峰值、RMS 和文件哈希。运行 `python .\tools\generate_game_audio.py` 可重建；`--preview <wav路径>` 生成包含所有音效的试听文件。

`stoneaxe.wav` 是 0.32 秒的低金属双击，`qinglong.wav` 是 0.30 秒的上行金属双音。两者只提示公开已发动的武器；后续出牌与伤害有各自的声音。它们不使用第三方或官方游戏录音。

只重建指定素材时运行 `python -B .\tools\generate_game_audio.py --only stoneaxe qinglong`，不会改写其余 WAV；清单中指定素材的峰值、RMS 和哈希从实际 PCM 文件读取，其余条目保留。

连续命中使用空闲声部叠加，最多同时播放四个短音效。提示声的优先级高于普通出牌和命中声；满额时优先替换较低优先级的声音，没有可用声部则放弃本次请求，避免积压后补播。每种素材保留一个主声部，额外声部共享三个缓存槽；常见命中、雷击和响应各预热一个备用声部。静音、切到后台或重置时取消待播声音并关闭正在播放的声部。
