# 群雄逐鹿 · 本地身份卡牌

本地开玩：双击根目录 **`Play.cmd`**，启动最近一次验证通过的游戏包。独立 ZIP 自带 .NET 8 运行时，解压后打开 `CardGame/CardGame.Wpf.exe`。开局、快捷键、存档位置与重新打包步骤见 [`LOCAL_PLAY.md`](docs/LOCAL_PLAY.md)。

这是一个本地运行的简化三国卡牌游戏，保留清晰的规则、事件和回放边界。当前支持：

- 五人/八人经典身份场默认使用逐批归位的正式武将：刘备（仁德）、孙权（制衡）、司马懿（反馈/鬼才）、夏侯惇（刚烈）、华佗（青囊/急救）、郭嘉（天妒/遗计）、周瑜（英姿/反间）与诸葛亮（观星/空城）；支持单将多技能、武将基础体力与主公 +1。旧技能演示池与经典包 1.0–1.2 的武将池按原内容指纹保留；
- 四人国战 Lite：魏蜀双将暗置、分别明置启用技能、按势力胜负结算，支持指南、存档与历史战绩；选副将时预览组合体力，基础体力平均向下取整。详见 [`NATIONAL_WAR_EXPERIENCE.md`](docs/NATIONAL_WAR_EXPERIENCE.md) 和 [`NATIONAL_DUAL_HEALTH.md`](docs/NATIONAL_DUAL_HEALTH.md)。
- 六人国战 M3 试验：魏 3、蜀 2、野心家 1 的三方独立势力，沿用双将暗置/明置、隐私和回放边界；只验证人数与独立势力可玩切片，不包含完整野心家规则。详见 [`NATIONAL_WAR_EXPERIENCE.md`](docs/NATIONAL_WAR_EXPERIENCE.md)。
- 国战牌桌并排展示双将肖像，各自标明暗置或明置；只依据已公开势力显示同伴／对手。详见 [`NATIONAL_SEAT_PRESENTATION.md`](docs/NATIONAL_SEAT_PRESENTATION.md)。
- 武圣在新局中可用手中红牌当杀响应决斗或南蛮入侵，转化时按钮明确显示「当作杀打出」；旧存档沿用原规则。详见 [`WUSHENG_RESPONSES.md`](docs/WUSHENG_RESPONSES.md)。
- 2v2 公开阵营可选择青队或赤队；牌桌标明队友、对手和双方存活人数，指南、存档与再战跟随实际队伍。详见 [`TEAM_EXPERIENCE.md`](docs/TEAM_EXPERIENCE.md)。
- 主动技能统一由主按钮或 Enter 确认，显示所需牌与目标数量；指南和教程往返保留选择。详见 [`SKILL_INTERACTION.md`](docs/SKILL_INTERACTION.md)。
- 铁索连环直接点击牌桌上的一到两名武将，再按主按钮或 Enter 确认；选中数量、高亮、取消和武圣转化使用统一操作。详见 [`CARD_TARGET_SELECTION.md`](docs/CARD_TARGET_SELECTION.md)。
- 新开局的铁索可选择自己，或不选目标点击「重铸换牌」；AI 支持重铸，旧存档继续按原规则运行。详见 [`IRON_CHAIN_RECAST.md`](docs/IRON_CHAIN_RECAST.md)。
- 杀／闪响应、救援、无懈和火攻可从手牌选择后确认，转化效果明确显示；修复反馈取得群体牌后阵亡导致后续结算中断。详见 [`HAND_RESPONSES.md`](docs/HAND_RESPONSES.md)。
- 响应区持续显示效果来源、受影响角色与完整说明，濒死救援标明武将和体力。详见 [`DECISION_CONTEXT.md`](docs/DECISION_CONTEXT.md)。
- 结算页展示全员伤害、承伤、回复、救援和击败数据；历史战绩在重启与再战后保留最近 50 局，重复加载同一终局不会重复计数。详见 [`MATCH_HISTORY.md`](docs/MATCH_HISTORY.md)。
- 对局速度可选从容／标准／快速，阵亡后可快速观战并随时暂停；速度随存档保留。详见 [`PLAYBACK_AND_SPECTATING.md`](docs/PLAYBACK_AND_SPECTATING.md)。
- 服务端式的纯规则核心与玩家可见状态；
- 杀、火杀、雷杀、闪、桃、酒、决斗、无中生有、南蛮入侵、万箭齐发、桃园结义、五谷丰登、过河拆桥、顺手牵羊、火攻、乐不思蜀、兵粮寸断和七种装备牌的使用与响应/即时效果；普通杀、火杀、雷杀共用杀的响应路径，未打出闪时分别产生普通、火焰、雷电伤害；酒在出牌阶段每回合限使用一次，使本回合下一张直接杀伤害 +1，濒死时仅濒死者本人可使用酒自救回复 1 点体力，决斗支持双方交替出杀，南蛮入侵按座次逐个请求出杀，万箭齐发按座次逐个请求出闪，桃园结义按座次逐个恢复存活角色，五谷丰登公开翻牌后按座次私有选牌，过河拆桥由使用者选择目标的一个不透明牌位移除手牌或精确选择一张公开装备/判定区牌，顺手牵羊按战斗距离一由使用者选择目标的一个不透明牌位取得手牌或精确选择一张公开装备/判定区牌，火攻可选择包括自己在内的一名有手牌角色，展示牌仍留在目标手牌中，并通过同花色弃牌进入火焰伤害链，乐不思蜀将牌置入目标判定区并在其下回合判定、非红桃跳过出牌阶段，兵粮寸断对战斗距离为 1 的其他角色使用（奇才忽略距离）、置入其判定区并在下回合判定，非梅花跳过摸牌阶段；装备按五类槽位公开替换，诸葛连弩攻击范围为 1 且杀不受次数限制，青釭剑攻击范围为 2 且使直接杀无视目标防具，赤兔/绝影影响战斗距离，玉玺影响摸牌，八卦阵在需要使用或打出闪时可选择红色判定视为闪，仁王盾使黑色杀在指定目标后无效；

- 经典司马懿的反馈在伤害后发布私有来源牌选择：暗手牌只暴露不透明槽位，公开装备按实体牌选择；发动后通过 `DamageSkillCardTakenEvent` 与 `skill.feedback.take-source-card` 精确转移一张牌。旧演示包中的反馈仍取得处理区伤害牌，并保留 `DamageCardClaimedEvent` 与历史回放顺序。
- 郭嘉的遗计在受伤后由 `DamageSkillFrame` 记录两张私有摸牌，AI 或人类从合法的牌/目标组合中选择一张交给其他存活角色；`DamageSkillCardsDrawnEvent`、`DamageSkillCardGivenEvent` 和 `skill.yiji.*` 移动原因只属于可信宿主，普通观察者不会看到候选牌面。
- 规则 v22 的经典郭嘉在自己的公开判定牌生效后获得私有天妒发动/跳过选择；发动时同一实体牌按 `Judgment(owner) → Hand(owner)` 与 `skill.tiandu.claim-judgment` 移动，`JudgmentCardClaimedEvent` 记录结果，答复后继续原八卦、延时牌或刚烈结算。v1–v21 与旧 `standard-classic-generals@1.0.0` 存档保持原自动弃置路径。
- 规则 v23 的经典周瑜在出牌阶段通过目标选择发动反间；目标只先看到四种花色 Choice，确认后才按确定性随机数选择、转移并公开周瑜的一张手牌。实体牌按 `Hand(source) → Processing → Hand(target)` 与 `skill.fanjian.give-card` 移动，`FanjianCardRevealedEvent` 记录选择和牌面；花色不同时复用普通伤害、受伤触发与濒死链。v1–v22 与经典包 1.0/1.1 保留旧单技能周瑜。
- 规则 v24 的经典诸葛亮在准备阶段先私有选择发动或跳过观星；发动后观看 `min(5, 存活角色数)` 张牌堆顶牌，先按“下一张最先被判定/摸取”的顺序选择置顶牌，再按“第一张最深”的顺序选择置底牌。重排只改变同一牌区内的顺序，不生成伪造的跨区移动记录；公开事件只包含观看、置顶和置底数量，牌面及顺序仅观星者可见。v1–v23 与经典包 1.0–1.2 仍使用旧单技能诸葛亮。
- 荀彧的节命在受伤后由同一 `DamageTriggerWindowFrame` 发布私有目标 Choice；目标只按公开的存活状态、手牌数量和体力上限筛选，补入的牌通过 `DamageSkillCardsDrawnEvent` 与 `skill.jieming.draw` 移动原因记录，普通观察者不会看到牌面。
- 援护者在其他角色受到正伤害后由同一 `DamageTriggerWindowFrame` 发布私有弃牌 Choice；发动时将拥有者的一张手牌移入弃牌堆，再通过 `RecoveryFrame` 令固定的受伤目标回复 1 点体力，`DamageSkillCardDiscardedEvent`、`RecoveryAppliedEvent` 和 `DamageSkillResolvedEvent.EffectTargetSeat` 记录可信宿主结果，普通观察者不会看到被弃牌的 ID。
- 经典夏侯惇受到正伤害后由同一 `DamageTriggerWindowFrame` 发布私有发动 Choice；发动后判定牌进入公开的 `Judgment` 区，结果不为红桃时向伤害来源发布仅其可见的弃两张手牌/承受 1 点伤害 Choice。旧演示模式保留原“红色成功”语义。
- 鬼才拥有者在判定牌生效前收到只对自己可见的逐张替换/跳过 Choice；替换时旧判定牌先结束，新牌经 `Hand → Processing → Judgment(target)` 进入同一判定帧，最终红/黑结果和判定结束移动对所有观察者一致。

刚烈的判定结果公开，但伤害来源的两牌组合和手牌身份只在来源自己的快照与可信宿主事件中出现。

## 运行

需要 Windows 和 .NET 8 SDK。项目已经用 `global.json` 固定到本机的 .NET 8.0.408。

```powershell
dotnet build .\CardGame.sln -c Debug
dotnet run --project .\src\CardGame.Wpf\CardGame.Wpf.csproj
```

不依赖测试框架或第三方 NuGet 包的核心自测：

```powershell
dotnet run --project .\tests\CardGame.Core.Tests\CardGame.Core.Tests.csproj -c Release
```

## 怎么玩

你固定坐在底部，并在默认配置中担任主公。其他身份默认隐藏，阵亡或开启“开发者视图”后才显示。

1. 在开局面板选择人数、身份和是否自己弃牌，点击“开始对局”；然后选择一名武将，候选只对你可见。对局中的“新对局”先打开设置，取消可以继续原局；
2. 点击一张可用手牌；
3. 使用杀、火杀或雷杀时，再点击绿色描边的合法目标；若你是关羽，红色非杀牌会显示为可按杀使用的转化动作；若你是赵云，闪会显示为可按杀使用的转化动作；
4. 点击“出牌”或按 Enter 确认；Esc 取消选择，1–9 选择手牌，Ctrl + Enter 结束出牌；
5. 桃会自动选择自己；酒可在出牌阶段使用并公开显示酒效，使本回合下一张直接杀造成 2 点伤害，酒效在直接杀声明时消费，未消费则在回合结束失效；规则 v20 起出牌阶段每回合限使用一次酒，即使酒效已被杀消费也不能在同回合再次饮酒，v1–v19 存档保留旧行为；规则 v12 起只有濒死者本人可用酒自救并回复 1 点体力，v3–v11 存档继续按旧跨座位救援语义回放；闪只能在响应杀、火杀、雷杀或万箭齐发时使用，火杀/雷杀未被闪避时分别造成 1 点火焰/雷电伤害；无中生有不需要目标，使用后摸两张牌；南蛮入侵不需要目标，所有其他存活角色按座次依次响应杀或承受 1 点伤害；万箭齐发不需要目标，所有其他存活角色按座次依次响应闪或承受 1 点伤害；桃园结义不需要目标，所有存活角色按座次依次回复 1 点体力，满血角色跳过恢复；五谷丰登不需要目标，公开展示等同于存活人数的牌，所有存活角色按座次各选一张，选择 prompt 只对当前选牌者可见；决斗在规则 v15 的经典身份局中不能选择空手且拥有空城的角色，v1–v14 回放保留旧目标集合；过河拆桥选择一名有手牌、公开装备或公开判定区牌的其他角色，手牌目标由使用者在私有不透明牌位按钮中选择，公开区域牌可在中央按钮中逐张选择；顺手牵羊只能选择战斗距离为 1 且有手牌、公开装备或公开判定区牌的其他存活角色，手牌目标由使用者在私有不透明牌位按钮中选择，公开区域牌可逐张选择且取得后只对使用者的手牌视图可见；规则 v19 起火攻选择包括自己在内的一名有手牌角色，目标私有选择并公开展示一张仍留在手牌中的牌，攻击者再选择同花色手牌弃置后造成 1 点火焰伤害；自选时不能只剩正在使用的火攻本身，展示牌也可作为同花色弃牌；v1–v18 保留只能选择其他角色且展示牌进入弃牌堆的历史语义；装备牌在出牌阶段无目标使用，按武器、防具、进攻坐骑、防御坐骑、宝物五类槽位公开显示并替换同槽装备；规则 v13 起诸葛连弩攻击范围为 1 且杀不受次数限制、青釭剑攻击范围为 2 且使直接杀无视目标防具，v1–v12 存档保留旧范围数值；规则 v14 起八卦阵覆盖直接杀与万箭齐发的闪响应，仁王盾在黑色杀指定目标后令其无效，v1–v13 存档保留直接杀八卦阵与黑色杀目标过滤；赤兔/绝影修正战斗距离，玉玺使摸牌阶段额外摸一张；
无懈可击会在可抵消的锦囊效果结算前按固定座次进入有限多层响应窗口；当前 responder 才能看到自己的无懈牌选项，无懈之间可以继续互相抵消，链结束后才恢复或清理原锦囊效果。乐不思蜀和兵粮寸断会把牌公开放入其他存活角色的判定区，在其下回合摸牌前进入判定；规则 v11 起，乐不思蜀仅红桃不跳过出牌阶段，兵粮寸断仅梅花不跳过摸牌阶段。规则 v18 起兵粮寸断以战斗距离 1 为目标条件，奇才可忽略该距离，目标手牌是否为空不影响使用或无懈后的置入；v1–v17 保留“目标有手牌”的历史条件，v1–v10 另继续按历史红黑判定语义回放。
6. 结束出牌后，若手牌超过体力，选择需要弃置的牌并确认；“推荐弃牌”只帮你选择，仍由你确认。AI 默认自动推进，并在需要你的出牌、弃牌或响应时暂停；可关闭“自动推进”，再到“战报 / 存档”中单步观察；
7. AI 对你使用杀、火杀、雷杀或万箭齐发时，用底部按钮或中央精确响应选项选择打出闪或不响应；AI 对你使用决斗或南蛮入侵时，按钮会切换为打出杀；若你是关羽，选择红色非杀牌和合法目标后可用独立按钮按【杀】使用；若你是赵云，杀/闪响应会在中央列出物理牌与转化牌型，选择杀也可以当闪打出；若你是经典孙权，发动制衡后可直接点选手牌，并在中央按钮中点选自己的公开装备；若你是曹操并受到牌造成的伤害，中央会显示只对你可见的奸雄取得/跳过选项；若你是司马懿并受到伤害，中央会显示只对你可见的伤害来源手牌槽位/装备牌反馈选项；若你是郭嘉并受到伤害，中央会显示只对你可见的遗计牌/目标组合按钮；若你是经典郭嘉且自己的判定牌已经生效，中央会显示天妒获得/跳过选项；若你是荀彧并受到伤害，中央会显示只对你可见的节命目标/跳过按钮；若你是援护者且其他角色受伤，中央会显示只对你可见的援护弃牌/跳过按钮；若你拥有鬼才并出现判定，中央会显示只对你可见的替换判定牌/跳过按钮；若进入濒死，中央会显示使用桃救援或让其阵亡的选项；只有你本人濒死且持有酒时才会额外显示酒自救；经典华佗只在自己的回合外把红色非桃手牌显示为“当作【桃】”。五谷丰登出现时，中央会显示公开牌和你的私有选牌按钮；过河拆桥或顺手牵羊选中后，中央会列出目标公开装备的逐张选择按钮，盲手牌仍只需点击合法目标。

刚烈者受到正伤害时，中央会显示只对其可见的发动/跳过选项；红色判定后，伤害来源会看到只对自己可见的精确两牌弃置/承受 1 点伤害选项，反制伤害的濒死处理完成后仍会回到原结算帧。

同样的内容、规则选项、AI 策略版本和种子会产生相同的初始局面与 AI 决策；存档同时记录这些条件和玩家命令。普通“新对局”使用系统安全随机数产生不可预测的种子；为避免据此重建暗身份和牌堆，当前种子只会在开发者视图或游戏结束后显示。测试则显式注入固定种子，便于复现。

## 有意保留的简化

为了让第一次阅读能顺着一次调用走到底，目前实现座位环距离、死亡角色缩圈和坐骑修正的最小战斗距离查询，以及五类公开装备槽位。经典身份包已经支持单将多个有序技能、基础体力和主公 +1；旧包仍使用原版本投影。普通杀、火杀和雷杀共用杀的可暂停响应路径，并通过 `DamageNature` 区分伤害类型；武圣、龙胆、鬼才、铁索等既有入口不变。规则版本 10 只在 `identity:classic-*` 模式启用正式反馈、刚烈、急救与武将体力语义，规则 v15 通过通用牌型目标禁止查询补齐空城对决斗的限制，规则 v16 把经典奸雄扩展为任意仍在处理区的伤害牌并改为可选触发，规则 v17 再补齐经典制衡的装备区候选和每阶段一次限制，规则 v18 将兵粮寸断改为战斗距离 1 的正式目标条件并复用奇才距离豁免，规则 v19 使火攻可选择自己并将展示建模为“不离开手牌的公开牌面”，规则 v20 补齐出牌阶段酒每回合限一次，规则 v21 将经典英姿改为可暂停的发动/跳过选择，规则 v22 将经典郭嘉换为天妒+遗计双技能并在判定结果后暂停询问，规则 v23 将经典周瑜换为英姿+反间双技能并在目标选花色后随机交牌，规则 v24 将经典诸葛亮换为观星+空城双技能并在准备阶段提供私有多步牌堆排序；旧规则版本继续按各自历史行为回放。当前仍未实现主公技、完整标准武将池、完整实体牌堆、复杂装备失效/卸载和更深的多层伤害嵌套。

这些简化没有写死在窗口里。当前 WPF 已经通过 `CardGame.Content.Standard` 创建不可变内容 Registry；后续继续增加牌、武将和模式数据时，仍由 Core 提供稳定契约，WPF 只消费玩家快照并提交动作。

伤害后触发的座位关系现在由 Core 的 `DamageTriggerScope`/`AfterDamageTriggerScope` 显式表达：默认技能只匹配受伤者，援护声明 `OtherLivingPlayer`，未来技能也可以声明任意存活角色。当前实际开放的跨座位效果包括援护的弃牌恢复和刚烈的来源反制；鬼才属于独立的判定前窗口，更复杂的跨座位触发效果和多层伤害仍未实现。

伤害后技能当前统一走可暂停的候选窗口：Core 按稳定顺序冻结 `DamageTriggerCandidate`，压入带 `CandidateIndex` 的 `DamageTriggerWindowFrame`，再为可选技能创建 `DamageSkillFrame`。经典奸雄可选择取得仍在 `Processing` 的伤害牌；经典反馈从来源的暗手牌槽位或公开装备精确取得一张牌；旧奸雄与反馈分别保留自动取得杀类伤害牌和取得处理区伤害牌的历史语义。遗计、节命、援护继续使用原有的私有牌/目标 Choice；经典刚烈以“非红桃”为成功条件，旧演示刚烈仍以红色为成功。AI 通过自己的快照决定，人类通过 `AnswerPromptCommand` 选择，完成后继续同一候选游标。

内容扩充的边界和待开放的锦囊、装备、技能入口见 [`docs/CONTENT_BACKLOG.md`](docs/CONTENT_BACKLOG.md)。当前 90 张基础演示牌堆已包含 18 张杀、2 张火杀、2 张雷杀、18 张闪、10 张桃、2 张酒、4 张决斗、2 张无中生有、2 张南蛮入侵、2 张万箭齐发、2 张桃园结义、2 张五谷丰登、2 张过河拆桥、2 张顺手牵羊、2 张火攻、2 张乐不思蜀、2 张兵粮寸断、2 张闪电、2 张无懈可击、2 张铁索连环、2 张诸葛连弩、1 张八卦阵、1 张青釭剑、1 张赤兔、1 张绝影、1 张玉玺和 1 张仁王盾；装备槽位、换装、规则 v13 的武器牌面攻击范围、v1–v12 旧范围兼容、规则 v14 的正式防具响应时机、v1–v13 旧防具兼容、青釭剑无视防具、仁王盾黑色杀无效和八卦阵直接杀/万箭齐发判定防御、过河拆桥/顺手牵羊公开装备或判定区牌目标选择、无懈可击有限多层响应、铁索连环公开标记与火/雷伤害传导、乐不思蜀/兵粮寸断公开判定区及正式花色阶段效果、闪电命中/转移、阵亡清理已接入，其他复杂装备仍按对应类型化入口继续扩展。
